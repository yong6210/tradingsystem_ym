# BTC 연구 재설계 — 여기서 시작

상태: **E005 실제 BTCUSDC 2년·1,000 USDC·6후보×2비용12회 비교 완료. 신규 채택 모델 없음. E006 손실·청산 진단 완료, 관련113개 검사 통과. 실체결·계정 조건·전진 모의 운용은 미완료.**

최신 결과는 [E005 비교 보고서](experiments/E005_RESULTS_2026_09_17.md), 현재 작업 순서는 [현재 우선순위](CURRENT_PRIORITIES.md)를 따른다.

[최초 진단 결과와 검증 범위](experiments/E001_RESULTS_2026_09_17.md). 원 설계와 등록 기록은 수정하지 않고 보존했다.

우리가 확인할 것은 특정 매매 스타일의 우열보다, 어떤 정보와 의사결정이 비용 이후에도 유리한지다. 장세별 손실과 거래하지 않는 선택까지 평가한다. 현재 어느 전략도 실거래 채택을 승인한 상태가 아니다.

## 전체 상세 계획

[전체 실행 계획 v2](MASTER_PLAN.md)를 기준으로 [전략 후보](STRATEGY_SPECS.md), [실행·회계 계약](ENGINE_SPEC.md), [검증 절차](VALIDATION_PROTOCOL.md), [요구사항 추적표](TRACEABILITY.md)를 함께 읽는다. 상세 계획 작성과 모델 구현/수익성 입증은 별개다. 신규 단계는 미구현 또는 미등록 상태다.

2. [설계와 개발 규칙](ARCHITECTURE.md): 책임 분리, 시간·원장 계약, 코드 스타일, 이전 코드의 이관.
3. [E001 진입 정보력 진단](experiments/E001_ENTRY_INFORMATION.md): 첫 질문, 대조군, 측정·제외 기준, 해석 한계.

## 초기 단계 구상과 완료 조건

아래 표는 E001 시점의 단계 구상이다. 표의 E002~E004 예정 이름은 이후 실제 등록 ID와 달라졌으며, 실행 상태는 최신 우선순위 문서와 아래 실제 실험 기록을 기준으로 본다.

|---|---|---|---|---|

앞 단계에서 실패하면 진단 결과를 남긴다. 전략을 통과시키기 위해 뒷단계를 붙이지 않는다. 약한 진입을 확인한 경우 다른 진입 가설은 새 실험 ID로 등록한다. 모든 기간에서 반드시 수익이 나야 한다는 뜻은 아니며, 예상한 실패 조건과 실제 실패가 일치하는지도 평가한다.

## E001 당시 구현 범위

- 구현: 표준 라이브러리만 사용하는 엄격한 설계 명세 로더, 데이터/코드 해시 검사, 경로·기간·준비 구간·지표·중복/미지정 값 검사, 테스트.
- 문서화: 경제적 가설, 대조군 선정 절차, 비교 조건, 연구 단계, 코드 책임과 이전 계획.
- 추가 구현: 공통 분봉 로더, 가격 반응 계산기, 과거 대조군 매칭, 탐색적 블록 구간, 등록·실행·보고서.
- 미구현: 새 매매 엔진, 실거래 어댑터. 통계 구간 전체의 독립 구현 재현은 미수행.
- 기존 실험 엔진·결과·실거래 설정은 보존한다. 새 검사기의 통과를 전략 수익성 검증으로 해석하지 않는다.

## 명세 검사

프로젝트 루트에서:

```bash
python3 scripts/check_research_plan.py configs/research/e001_entry_information.json
python3 -m unittest tests.test_research_foundation
```

검사기는 주문·백테스트·네트워크 호출을 하지 않는다. 현재 `design` 상태만 허용하며, 등록/실행기로 오해하지 않도록 의도적으로 역할을 제한했다. 전체 ZIP 내용 검사는 기존 자료 검증기의 책임이다. 이 검사기는 해당 검증 기록과 참조 코드가 바뀌지 않았는지 확인한다. 실제 실행은 별도 `scripts/run_entry_information.py`를 사용하며 등록 해시·진행/실패 상태를 남긴다.

[후보 재검토와 확장 연구 지도](CANDIDATE_REVIEW.md): 기존 여섯 후보의 중복을 구분하고 S07~S13을 연구 목록으로 추가했다. 첫 후속 명세 대상은 S01/S02/S05/S07/S08이며 S04는 기존 대조로 유지한다. 추가 후보의 수익성은 미검증이고 현재 실행 등록은 하지 않았다.

## E003 후보 진입 탐색 완료

[결과와 한계](experiments/E003_RESULTS_2026_09_17.md), [실행 전 명세](experiments/E003_CANDIDATE_SCREEN.md). E001 통계 12개 그룹 독립 재현 및 신규 후보 5개+기존 회귀 대조를 고정 규칙으로 진단했다. 추세 매칭은 부족하고 나머지 주 지표는 네 연도 모두 탐색 구간이 0을 포함했다. 실제 매매 엔진/계좌 수익률 검증을 대신하지 않는다.

## 추세 비교와 소액 운용 재설계

[상세 재설계](TREND_AND_CAPITAL_REDESIGN.md): 비신호 매칭을 동일 시간 정책 비교로 대체하는 새 실험과 최소 필요 자산 계산을 분리한다. 후속 자금은 1,000 USDC로 변경하고 0.5% 위험 비율은 유지한다. 이 설계의 고정 수량 추세 비교는 아래 E004에서 실행했다.

최신 운용 자금은 사용자 요청에 따라 1,000 USDC다. 문서의 E003/100달러 결과는 과거 실험의 조건이며 수정하지 않는다.

## 최신 연구 방향: 매매 방식 제한 해제

사용자 요청으로 순환매를 필수 구성에서 제외했다. [방식에 제한을 두지 않는 탐색 계획](STRATEGY_DISCOVERY.md)을 따른다. 1,000 USDC·Binance BTCUSDC 실행 조건 아래 단독/복합 전략을 같은 기준으로 검토하며, 수익성이 검증된 방식은 아직 없다.

## 1→2→3 기준 모델 개발 완료

[E004 결과](experiments/E004_RESULTS_2026_09_17.md): 고정 수량 원장, 비용 포함 수량 제한, 분봉 시장가 대용 체결·보호 손절, 세 정책의 고정 비교를 구현했다. 기본 단순 추세 전체 +10.20%, 스트레스 +1.67%이나 사전 기간 일관성 기준 미통과. 이는2023-04~2026-08 전체 수익이며 연 수익이나 실거래 결과가 아니다. 관련51개 테스트와30실행 원장 검산 통과.

## 최신 실행 우선순위와 시장가 전환

[현재 우선순위](CURRENT_PRIORITIES.md)를 따른다. 사용자 결정으로 일반 미체결 지정가는 지연 시 취소 확정 후 잔량을 시장가로 전환한다. 신규 진입은 신호/시장가 비용 포함 위험을 재검사하며 위험 청산은 별도 우선 경로다. 판단·영속 기록·모의 전송 복구 관련24개 테스트를 통과했다. 실제 거래소 연결과 운영 경보는 미완료다. 기존 E004 시장가 기준 실험은 변경하지 않았다.


## E005 실제 BTCUSDC 비교

[실행 전 설계](experiments/E005_BTCUSDC_COMPARISON.md), [결과](experiments/E005_RESULTS_2026_09_17.md), [입력 계약·결측 처리](BTCUSDC_EXECUTION_CONTRACT.md). 2024-09~2026-08 전체730일의6고정 후보를 실제 펀딩과 시장가 비용 시나리오로 비교했다. EMA 추세가 상대적으로 낫지만 모든 후보가 사전 필요조건 미통과다. 반복 튜닝/최종 결합 모델 생성은 하지 않았다. 실제 체결·청산 검증은 여전히 별도 과제다.


## E006 손실·청산 규칙 진단

[등록 설계](experiments/E006_LOSS_AND_EXIT_DIAGNOSTICS.md), [전체 결과](experiments/E006_RESULTS_2026_09_17.md). 기존12개 원장에서 매매손익·수수료·펀딩·출구·진입 장세·보유시간·같은 방향 재진입을 분해했다.24개 고정 조기 청산 대안 중 후속 선별 기준을 통과한 것은 없다. 수정 전략의 계좌 백테스트가 아니라 원 진입 목록의 짝지은 진단이다. F0의 목표 설정 시점과 시간봉 종가 확인 청산을 명시하고 회귀 검사로 고정했다.
