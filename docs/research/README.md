# BTC 연구 재설계 — 여기서 시작

상태: **E005~E011 고정 비교/진단에 이어 E012 위험 축소·최소 주문 제약 8회 진단 완료. 신규 채택 모델 없음. 관련 226개 검사 통과. 최근 8실험의 기록 해시 714회 대조 일치, 70개 계좌의 회복·일별 꼬리 지표 추가 검산 완료. 실제 체결·계정 조건·전진 모의 운용은 미완료.**

[이번 검증 기록](../../reports/validation/evaluation_execution_contract_20260917/verification.json): 신규26개 포함226개 검사 통과, 기존714개 해시 대조 일치, 실제 주문0.

최신 추가 작업: [전진 평가 정책·등록 검사](FORWARD_ACCEPTANCE_CONTRACT_V1.md), [시장가 위험 재승인 오프라인 통합](FALLBACK_RISK_INTEGRATION_V1.md). 정책은 초안/등록 차단이며 T0 정밀도 진단에서2년의 충분성을 확인하지 못했다. 일반 시장가 전환의 부분 체결·비용/예약 위험·전송 재검사·위험 경고 영속화를 연결했다. 보호 청산·실제 계정·경보 통합·전진 모의는 남아 있다.

최신 판단은 [진행 방향·허점 검토](RESEARCH_REVIEW_2026_09_17.md), 최신 진단은 [E012 결과](experiments/E012_RESULTS_2026_09_17.md), 작업 순서는 [현재 우선순위](CURRENT_PRIORITIES.md)를 따른다. **다음은 후보 추가보다 경제적 채택 기준과 주문/위험 통합 계약 보완이 우선이다.** 아래 단계별 기록의 ‘예정/다음/미완료’는 해당 작성 시점 상태이며 최신 진행 위치를 대신하지 않는다.

[최초 진단 결과와 검증 범위](experiments/E001_RESULTS_2026_09_17.md). 원 설계와 등록 기록은 수정하지 않고 보존했다.

우리가 확인할 것은 특정 매매 스타일의 우열보다, 어떤 정보와 의사결정이 비용 이후에도 유리한지다. 장세별 손실과 거래하지 않는 선택까지 평가한다. 현재 어느 전략도 실거래 채택을 승인한 상태가 아니다.

## E001 당시 구현 범위

- 구현: 표준 라이브러리만 사용하는 엄격한 설계 명세 로더, 데이터/코드 해시 검사, 경로·기간·준비 구간·지표·중복/미지정 값 검사, 테스트.
- 문서화: 경제적 가설, 대조군 선정 절차, 비교 조건, 연구 단계, 코드 책임과 이전 계획.
- 추가 구현: 공통 분봉 로더, 가격 반응 계산기, 과거 대조군 매칭, 탐색적 블록 구간, 등록·실행·보고서.
- 미구현: 새 매매 엔진, 실거래 어댑터. 통계 구간 전체의 독립 구현 재현은 미수행.
- 기존 실험 엔진·결과·실거래 설정은 보존한다. 새 검사기의 통과를 전략 수익성 검증으로 해석하지 않는다.

## 명세 검사

프로젝트 루트에서:

```bash
python3 scripts/check_research_plan.py configs/research/e001_entry_information.json
python3 -m unittest tests.test_research_foundation
```

검사기는 주문·백테스트·네트워크 호출을 하지 않는다. 현재 `design` 상태만 허용하며, 등록/실행기로 오해하지 않도록 의도적으로 역할을 제한했다. 전체 ZIP 내용 검사는 기존 자료 검증기의 책임이다. 이 검사기는 해당 검증 기록과 참조 코드가 바뀌지 않았는지 확인한다. 실제 실행은 별도 `scripts/run_entry_information.py`를 사용하며 등록 해시·진행/실패 상태를 남긴다.

사용자 요청으로 순환매를 필수 구성에서 제외했다. [방식에 제한을 두지 않는 탐색 계획](STRATEGY_DISCOVERY.md)을 따른다. 1,000 USDC·Binance BTCUSDC 실행 조건 아래 단독/복합 전략을 같은 기준으로 검토하며, 수익성이 검증된 방식은 아직 없다.

## 최신 실행 우선순위와 시장가 전환

[현재 우선순위](CURRENT_PRIORITIES.md)를 따른다. 사용자 결정으로 일반 미체결 지정가는 지연 시 취소 확정 후 잔량을 시장가로 전환한다. 신규 진입은 신호/시장가 비용 포함 위험을 재검사하며 위험 청산은 별도 우선 경로다. 판단·영속 기록·모의 전송 복구 관련24개 테스트를 통과했다. 실제 거래소 연결과 운영 경보는 미완료다. 기존 E004 시장가 기준 실험은 변경하지 않았다.
