# E055 — 여러 시간대·여러 기간의 실제 체결 매물대

사용자가 승인한 방향에 따라 일봉·4시간봉·1시간봉·15분봉의 방향 문맥과 1·3분봉의 매물대 반응을 결합했다. 기존 동결 실험은 변경하지 않았다. 계좌 전체 증거금의 1/10 배정과 5→2~3 축소 구조는 유지하되, 추가·축소·청산을 고정 ATR 간격 대신 매물대 반응으로 판단하는 별도 연구 버전이다.

## 실제 자료와 범위

- Binance BTCUSDC USD-M aggTrades 2026-06~08 월별 원본 세 개, 공식 SHA256 일치. 합계 41,776,321개 집계 체결이며 체결 ID 누락 0, 중복 및 시간 역전 검사 통과. 개별 원체결 건수와는 다르다.
- 체결 가격을 50 USDC 고정 구간으로 나누고 실제 BTC 수량을 합산했다. 캔들 전체 거래량을 고가~저가에 나눠 넣지 않았다. 15분 단위 8,832구간×관측 가격구간 476개로 압축했다.
- 분봉 거래량과 총량이 1,254.181 BTC(약 0.0339%) 다르고, 132,480분 중 2,078분에서 0.000001 BTC 초과 차이가 났다. 이를 전체 체결 완전 복원으로 부르지 않고 공개 aggTrades 범위의 프로파일로 사용했다. 미확인 차이를 임의 배분하지 않았다. 차이는 양수 759분·음수 1,319분으로 양방향이며, 절대 차이 합계는 1,649.761 BTC다. 순차이 0.0339%를 모든 분의 정확도로 해석하지 않는다.
- 공식 aggTrades 설명은 시장 체결 집계이고 보험기금·ADL 거래는 제외한다고 명시한다. 이것이 이번 차이 전부의 원인이라는 증거는 없으므로 원인은 미확정이다. [공식 데이터](https://github.com/binance/binance-public-data), [공식 API 설명](https://developers.binance.com/en/docs/catalog/core-trading-derivatives-trading-usd-s-m-futures/api/rest-api/market-data).
- 과거 거래 집중 구간이지 현재 미체결 주문 잔량이나 보유자의 실제 평균 단가를 직접 관측한 것은 아니다.

## 시간대와 주문 기준

|구분|고정한 첫 시험 규칙|
|---|---|
|큰 방향|일봉·4시간봉 종가와 EMA20의 위치. 두 방향이 반대면 신규 위험을 늘리지 않음|
|중간 확인|1시간·15분봉도 같은 방향일 때 신규 진입·추가 허용|
|매물대 기간|현재 UTC 일자, 최근 1일·7일·60일, 최근 확인된 4시간 스윙의 시작부터|
|파동 기준점|전후 두 개 4시간봉보다 낮은 저점/높은 고점. 뒤 두 봉 완료 후에만 알 수 있고 그때부터 사용|
|매물대 추출|50 USDC 구간을 인접 가중평균으로 평활화하고 떨어진 상위 국소 집중점 최대 5개. 각 집중점 전후 한 구간을 영역으로 사용|
|추가|완료 3분봉이 지지를 회복하거나 저항에서 밀리고 1분봉도 확인. 직전보다 유리한 별도 매물대에서만 1/10 추가|
|5/10 이후 축소|반대 매물대 반응 시 손실이어도 약 3/10으로 축소|
|부분 손절|최근 추가의 근거 매물대를 완료 3분봉 두 개가 이탈하면 보유가 2/10 초과일 때 약 2/10으로 축소|
|전량 손절|진입 때 고정한 더 깊은 주간/60일 근거 매물대 이탈. 해당 구간이 없으면 진입 매물대를 사용|
|익절|반대 매물대에서 비용 초과 평균 단가 이익 확인. 장기 매물대거나 최초 한 단위면 전량, 그 외 한 단위 상당 축소|
|롱숏 전환|반대 상위 방향과 반대 매물대 반응이 모두 확인되면 먼저 청산 후 신규 조건을 확인|
|시간·계좌 중단|최대 24시간 보유, 3분 조절 간격, 고점 대비 4% 중단은 임시 연구 가정|

가격대 선정의 겹침 횟수는 서로 다른 기간 수를 세지만, 기간들이 중첩되므로 독립된 여러 증거로 해석하지 않는다. 지표는 완료 봉만 사용하며 매물대도 완료 15분 구간에 1분 전달 지연을 적용한다. 과거 스윙을 미래 정보로 소급 확정하지 않는다.

비용 여유를 진입 조건에 넣었기 때문에 기본/스트레스의 주문 경로가 다르다. 스트레스에서 손실 거래 일부가 발생하지 않아 순익이 상대적으로 높아질 수 있으며 비용 증가 자체가 이익을 낸다는 뜻이 아니다. 매물대 기간 변경 역시 진입·보유·노출을 함께 바꾼다. E054와는 규칙 여러 개가 달라 직접 성과 차이를 매물대 효과 하나로 귀속할 수 없다.

## 사용자 방식과 아직 다른 부분

- 여러 기간 모델 3배 기본의 보유 시간은 36.07%, 최대 배정량은 3/10이었다. 5/10까지 쌓고 줄이는 행동이 이 실제 재생에서 발생하지 않았다. 구현된 방어 분기와 시장에서 관측된 행동을 구분한다.
- 3배 기본에서 롱 37회·숏 9회 시작했지만 즉시 방향 전환 조건은 발생하지 않았다. 거의 항상 보유하는 사용자 방식이 구현됐다고 주장할 수 없다.
- 다섯 단위 후 세 단위 축소/전술 구간 실패 후 두 단위 축소 분기는 이번 실제 경로에서 실행되지 않았다. E054 컨트롤러의 상태 테스트는 통과했지만 이 새로운 신호와 결합한 해당 분기의 실제 시장 검증은 남아 있다.
- 14,880개 3분 판단 시점 중 상위 방향과 중간 확인을 통과한 시점은 5,670개(38.10%)였다. 이것만으로 보유율 감소의 원인을 확정할 수는 없지만 행동 차이를 점검할 구체적 조건이다.
- 상위 네 시간대의 동시 확인, 매물대 추출 방식, 별도 구간에서만 추가하는 조건은 연구자 가정이다. 사용자 재량을 그대로 복제했다는 뜻이 아니다.
- 실제 레버리지·증거금·청산, 부분 체결·지정가 대기열·실주문 복구, 새 자료 전진 검증은 미완료다. 고점 대비 4% 신호가 4% 또는 5% 손실 상한을 보장하지 않는다.

## 검증

- 새 매물대/인과성 테스트 8개 및 기존 10분할 컨트롤러 테스트 8개, 총 16개 통과. 미래 체결량 변경 불변성, 60일 전량 확보 조건, 완료 봉 지연, 스윙의 늦은 확인을 검증했다.
- 18개 계좌·1,343체결을 Decimal 평균 단가 회계로 재계산했고 원본 분봉 체결 기준 가격, 원장 시간 순서, 수량 단위, 프로파일 공개 시각, 추가 없는 대조, 등록 소스 해시를 확인했다.
- 펀딩 원장 403행의 부호·수량·가격·정산율·추가 비용 산술을 별도로 재계산했다.
- 원본 첫 15분의 5,395개 집계 체결을 독립 Decimal CSV 집계로 다시 계산했다. 여섯 가격 구간·398.368 BTC가 압축 히스토그램과 일치했다. 전체 기간 독립 가격 구간 재집계를 했다는 뜻은 아니다.
- 12개 체결행(비교 경로 중복 포함)은 해당 분 거래량의 10%를 초과했다. 고정 슬리피지 결과이며 실제 체결 가능성을 보장하지 않는다.

판정: 구현·계산 검증 범위에서는 재현 가능하나, 수익 모델로는 미채택. 우선 확인할 것은 지지·저항 반응의 판정과 축소/재진입 근거가 사용자 행동을 제대로 표현하는지다. 새 가정을 바꿀 때에는 별도 버전으로 동결하고, 여러 시장 구간·새 시장 전진 자료에서 다시 비교해야 한다.
