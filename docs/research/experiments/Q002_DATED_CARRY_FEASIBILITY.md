# Q002 — 만기형 현물·선물 캐리의 경제적 근거와 비용 여유

2026-09-19. 상태: **경제적 질문 1개 선정, 공개 계약·현재 표시 가격 선행 진단**. 완결된 성과 실험이나 실운용 후보 채택이 아니다. Q001의 비용 가정을 낮춰 실패 전략을 재구제하지 않는다.

## 질문과 근거

현물 BTC 매수와 같은 BTC 수량의 선형 만기 선물 매도를 결합했을 때, 최초 가격차 수입이 거래·정산·환전·운영비와 분리 담보 위험을 보상할 여지가 있는가?

[BIS Crypto carry 연구](https://www.bis.org/publications/working-paper-1087-crypto-carry)는 레버리지 상승 노출 수요와 제한된 차익거래 자금이 현물·선물 가격차와 연결된다고 설명한다. 이는 원리의 외부 근거이며, 현재 Binance 계약의 비용 후 수익을 검증한 자료가 아니다. 중간 증거금·청산 위험이 가격차가 남는 이유이기도 하므로 무위험 수익으로 부르지 않는다.

기존 E026/E028의 S10은 무기한 선물의 미래 펀딩 현금흐름에 의존했다. 이번 질문은 **만기가 정해진 선형 계약의 최초 가격차**에 관한 것이다. E028의 실패 조건·손실중단·현물 수수료 가정을 고치거나 그 결과를 재계산하지 않는다. E037/E043의 방향성 펀딩 신호와도 다르다. 다만 캐리 계열의 추가 시도이며, 완전히 독립적인 연구 이력으로 세지 않는다. docs/research에서 만기형 규칙의 별도 실행 기록은 찾지 못했지만 모든 과거 시도의 부재를 증명한 것은 아니다.

## 공식 계약 확인과 범위

2026-09-18 23:12:32 UTC 공개 exchangeInfo를 먼저 확인했다. BTCUSDC는 PERPETUAL만 있고, BTCUSDT_260925와 BTCUSDT_261225가 TRADING인 선형 만기형 계약이다. 두 계약의 LOT_SIZE/MARKET_LOT_SIZE 최소·증분은 0.001 BTC, MIN_NOTIONAL은 5 USDT, 가격 틱은 0.1이다. 현재 메타데이터이며 역사적 필터나 실제 계정 승인 근거로 쓰지 않는다.

[공식 USDⓈ-M 만기형 계약 규격](https://www.binance.com/en/about-legal/contractspecs-usdsmquarterly)의 2026-01-05 PDF를 보존했다. 해당 심벌의 정산 자산으로 현금 정산하며 만기 정산 수수료가 taker와 같다고 명시한다. 일반 FAQ의 COIN-M 역수 손익 산식을 선형 USDT 계약에 복사하지 않는다. 계정별 적용 약정과 유지증거금·요율은 아직 확인하지 못했다.

사용자 기존 자금 1,000 USDC와 BTCUSDC 운용 범위는 유지한다. 이번 BTCUSDT·현물 비교는 연구 범위다. USDT=USDC로 놓거나 사용자의 BTCUSDC 요율을 USDT 만기물에 자동 적용하지 않는다. 투자·환전·계정 접근·주문은 없다.

## 성과 계산 전 선행 진단 명세

이번에 실행하는 범위는 아래 단일 현재 호가 점검뿐이다. 성과 백테스트 없이 가격차 구성요소와 필요한 미확인 입력을 식별한다.

- 위 메타데이터에서 확인한 BTCUSDT 만기 계약 2개를 모두 보고한다. 가격을 보고 유리한 계약만 선택하지 않는다.
- 수량 0.001 BTC 한 개. 현물 매수 asks와 선물 매도 bids의 상위 5단계를 실제 표시 수량대로 소화한 가중 평균을 사용한다. 물량 부족 시 계산 불가로 기록한다.
- 공개 현물 BTCUSDT exchangeInfo 1회, 현물 BTCUSDT depth 1회, 두 만기물 depth 각 1회. 요청 실패·시각 품질 실패를 보존하고 다른 시간의 가격을 반복 수집해 대체하지 않는다. 기존 선물 exchangeInfo 1회와 규격 PDF 1회는 가격을 보기 전 확인한 입력이다.
- 세 depth 요청은 병행하며 전체 요청 시작~최종 수신이 2초 이내인지 검사한다. 이는 연구자가 정한 비교 적격성 기준이고 주문 지연 측정값이 아니다. 2초 초과, 미래/오래된 선물 메시지 시각, 불일치·교차·무효 호가라면 해당 점검을 부적격으로 기록한다. 현물 depth에는 거래소 시각이 없으므로 이 기준 통과도 진정한 동시성 보장은 아니다.
- 날짜·최소 물량·정렬·양수값·필터 및 raw 응답 해시를 검사한다. 선물 메시지 E/T 시각은 수신보다 최대 1초 미래 허용, 5초 이상 과거면 부적격이다. 이는 로컬 시계 정확성을 독립 검증한 기준이 아니며 계정 적격성 판단도 아니다.
- 지표: 현물 표시 지출 q×S, 선물 표시 진입 명목 q×F, 가격차 구성요소 q×(F−S), 현물 명목 대비 (F/S−1)×10,000 bp, 만기까지 남은 시간. 연환산·월 수익 환산·누적 계좌 손익은 산출하지 않는다.
- 수수료·지연·환전·정산 괴리·운영비를 임의로 0으로 확정하지 않는다. 가격차는 이 비용을 빼기 전 구성요소이며, 진입이 확정된 거래나 수익 예측이 아니다. 음수면 그 시점의 양의 가격차 수취 구조가 없다. 양수면 비용 후 가능성은 미판정이다.
- 비교: 동일 현물 기준의 두 만기물을 각각 표시한다. 하나의 현재 관측은 장기 기회 빈도, 미회복 기간, 수익 집중, 낙폭을 평가할 수 없다. 서로 다른 만기의 수입을 연환산 순위로 선택하지 않는다.
- 계산 전에 명세·실행 코드·입력·보호 파일 해시를 registration.json에 고정한다. Decimal 표시 물량 계산을 별도 Fraction 누적 구간 소화와 대조한다. 이 검산은 호가 산술 검산이며 실제 체결 검증이 아니다.

## 수익 산식 — 아직 모르는 항을 숨기지 않는다

실제 현물 순 BTC 수량 q와 선물 숏 수량 q가 같고 두 포지션이 만기까지 유지된다면, USDT 기준 최종 변화는 다음과 같다.

`q×(F_entry−S_entry) + q×(S_exit−I_settlement) − 진입/현물청산/선물정산 수수료 − 기타 비용`

첫 항은 최초 가격차, 둘째 항은 현물 청산 가격과 선물 정산 지수의 불일치다. 첫 항만 보고 확정 수익으로 부르지 않는다. USDC 계좌 결과로 옮기려면 진입·종료 환전 가격과 비용도 필요하다. 조기 청산하면 둘째 항은 현물 청산과 선물 환매 가격의 차이가 된다. 가격차 확대 시 조기 청산 손실이 최초 가격차보다 클 수 있다.

현물 수수료가 BTC로 차감되면 순수량 q가 달라져 헤지가 깨질 수 있다. 실제 순수량·주문 증분·잔량을 사용해야 한다. 현물 평가이익은 별도 선물 지갑의 사용 가능한 증거금으로 자동 이전되지 않는다. 가격 상승 또는 베이시스 확대에 따른 선물 증거금 부족을 합산 계좌 수익으로 가리지 않는다.
