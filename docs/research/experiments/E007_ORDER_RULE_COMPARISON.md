# E007 — 주문 행동 계약의 계좌 연결과 단일 축 비교

2026-09-17. 결과 실행 전 등록. E005/E006 이후 사후 연구이며 새 독립 표본이 아니다. 전체13개 후보의 검증을 대신하지 않는다.

## 실행 범위

BTCUSDC, 초기1,000 USDC.2024-09-01~2026-09-01 UTC 미만730일. E005와 같은 데이터/완전성 검사·원장·펀딩 사건 처리·가격 체결 비용. 현재 mark 시가로 최소 명목을 검사한다. 계약가격 기반 손절/낙폭이며 실제 청산 엔진이 아니다.

먼저 E005 R0/F0×기본/스트레스4회 재실행해서 기존 events/trades/daily/rejections 및 기존 지표가 일치하는지 검사한다. 이4회는 신규 모델 실험으로 세지 않는다. 불일치하면 신규 비교를 중단한다.

그다음 R0/F0×5설정×2비용 = **20회 신규 계좌 실행**. 설정은 control, fresh_signal_reentry, entry_decision_target, intrabar_market_target, structural_stop. resting_limit_target은 OHLC로 체결을 증명할 수 없어 명시적 제외하며 시장가 체결로 대체하지 않는다. 결과에 따른 추가 실행/설정 수정은 하지 않는다.

## 기존 경로와 신규 계약 차이

E005 원본은 수정하지 않는다. `order_comparison`은 기존 원장·위험 정책·펀딩을 재사용하는 신규 경로다. 새 규칙은 이미 작성한 `execution/order_rules.py`를 직접 호출한다. 지표 공급은 완료1시간봉 자료만 사용하며 관찰 가능 시각+1분에 판단한다.

R0/F0의 기존 목표 방향 정책과 무신호/반전 청산은 모든 신규 설정에 **공통으로 유지**한다. 고정 목표는 이에 추가되는 출구다. 따라서 R0의 이동 z복귀 출구나 F0의 기존 신호 종료가 더 빠르면 고정 목표 효과를 제한할 수 있다. 이번 비교가 기존 목표 방향 정책과 독립된 순수 목표 효과라고 주장하지 않는다.

공통 신호 어댑터는 완료 관찰에서 방향0 또는 방향 전환 시에만 새 episode를 생성한다. 기존 F0 내부 목표가 같은 봉에서 재설정돼 방향이 같게 끝난 경우도 별도 새 episode로 추론하지 않는다. 신호는 계좌 체결 여부와 독립적으로 생성된다.

신규 control도 E005의 정확한 재현은 아니다. 종료 확인 이후의 새 판단을 요구하고, 진입 시 목표/손절 방향·비용 적격성을 검사하고, mark 기준 수량 제약을 사용하며, 고정 목표 출구가 추가된다. control과 E005의 차이를 어느 한 규칙의 개선이라고 표현하지 않는다. 단일 축 비교의 기준은 신규 control이다.

- 공통: ATR14/3배,7일, 주기.5%/총1%, 명목1배, 일손실2%, DD5% 반위험/DD8% 중단. 최소수량.001, 현재 최소명목50, 가격tick.1. 최적 수치 주장 없음.
- R0 목표 공급: 완료1시간24종가 평균. 구조: 현재 봉 제외 이전24봉 고저.
- F0 목표 공급: 현재 봉 제외 이전12봉 고저 중간값. 구조: 현재 진입 판단 시점의 이전12봉 고저. 미래 pivot 없음.
- 목표 원천: 신호 구간 처음의 목표 vs 각 새 주문 판단의 목표. 열린 주기는 고정.
- 구조 손절: 알려진 경계 밖1tick. 수량은 그 손절과 비용으로 다시 계산하며 동일 수량을 강제하지 않는다.
- 익절은 종가 확인/장중 접촉 두 시장가 방식 비교. 같은 봉 양쪽 접촉은 보수적 손절 우선+불명 표시. 시가 목표 통과는 그 뒤 극값보다 먼저다.
- 봉 중간 체결은 시간 불명으로 기록하므로 종료 확인 시각을 봉 끝으로 둔다. 같은 봉이나 그 전에 알려진 신호로 재진입하지 않는다.
- 실제 부분 체결은 재현하지 않는다. 사전 위험 검사에서 실패하면 진입하지 않고 이유를 보존한다. 한 번 송신한 진입 의도/체결을 취소됐다고 가정하는 경로는 없다.
- 기본 비용: 수수료5bp/슬리피지2bp 각 체결+실제 방향 펀딩. 스트레스:7bp/5bp+실제 펀딩+사건마다 명목1bp 추가 지급. 실제 계정 요율은 미확인.
