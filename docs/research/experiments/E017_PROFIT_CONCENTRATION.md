# E017 — 수익 집중도와 미회복 구간의 비용 전후 손익

2026-09-19. 실행 전 범위: E014 T0 기본/스트레스 153주기씩과 일별 계좌 전체를 사용한다. E015 동일 OHLC 원장의 청산 기준가, E016에서 고정한 회복 구간을 연결한다. 2024-09-01~2026-09-01 UTC 미만, 최초1,000 USDC. 새 전략·계좌 재실행·튜닝 없음.

- 거래별 순손익을 수익/손실/0으로 분리하고 승률·평균 수익/손실·중앙값·순손익 기준 profit factor를 계산한다. 상위1/5/10 수익 거래가 양수 거래 이익 합계에서 차지하는 비중과 그 합계를 뺀 산술 잔액을 표시한다. 잔액은 실제 거래 제거 재백테스트가 아니다.
- 시간순 실제 거래에서 인접한 같은 방향 거래를 묶는다. 현금 공백을 포함할 수 있으며 신호의 독립 추세 구간이나 통계적으로 독립인 표본이 아니다. 상위1/3/5 묶음의 집중도를 별도로 계산한다. 원래 모든 거래의 소속과 합계를 보존한다.
- 이벤트 비용과 분봉 종가로 일별 체결가격 평가손익을 재구성한다. 실현손익+미실현손익 변화−수수료−역사적 순펀딩−스트레스 펀딩=일별 순손익을 확인한다. 슬리피지/tick을 더한 기준가 평가손익도 계산한다. 월 경계에서 미청산 거래 손익을 청산 월에 몰아넣지 않는다.
- UTC24개 월을 모두 보고하고 월 합계/일 합계/거래 합계를 대조한다. 두 시나리오 각각 가장 긴 고점→최저점, 최저점→회복, 고점→회복 구간을 같은 회계식으로 분석한다. 시작일 종가 이후부터 종료일 종가까지이며 시작일 비용은 재포함하지 않는다.
- 추세 전략의 우측 꼬리 집중은 그 자체로 결함이나 거래 제거 근거가 아니다. 153주기를 독립 시행153개로 가정하지 않는다. 결과에 맞춘 필터·손절·레버리지 조정은 하지 않는다. 다음 방향은 집중도와 비용 전 손익에 근거해 결정하되 새 최적 모델을 선언하지 않는다.

검증: 집중도 분모/무승자·무패자/동률, 월 경계 미실현손익, 펀딩 수취, 동일 시각 반전, 회복 경계, 누락 일자 검사. 기존 회계와 진단 검사도 실행한다. 기존 E014~E016 증거와 소스 해시를 실행 전후 대조한다. 출력은 새 디렉터리에만 생성하고 실패 기록을 보존한다.
