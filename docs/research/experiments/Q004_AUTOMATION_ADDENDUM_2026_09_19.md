# Q004 자동 관측 활성화

2026-09-19. 매일 자동 재개 제안 뒤 사용자가 계속 진행을 요청하여, 현재 작업에 연결된 heartbeat `q004`를 ACTIVE로 생성했다. 다른 세 예약은 PAUSED 상태였으며 변경하지 않았다.

한국 시각 2026-09-20~2026-12-18 매일 08:58, 총 90회 재개하도록 저장된 일정을 확인했다. 9월 19일 예측은 이미 공표됐고, 새 예측 날짜는 9월 20일~12월 17일의 89개다. 12월 18일에는 09:01 이후 마지막 결과를 평가하고 종료한다. 일정의 날짜 계산 확인이며 실제 미래 기동/성공을 확인한 것은 아니다.

각 실행은 당일 09:00 이전 prepare, 09:00:05~50 publish, 예측 감사, 09:01 이후 전날 결과 score, 읽기 전용 누적 평가 순서다. 08:58에는 UTC 날짜가 한국 날짜보다 하루 이르므로 명령의 경계 날짜는 한국 당일 날짜에 맞춘다. 늦거나 실패한 예측은 소급 생성하지 않고 실패 폴더도 덮어쓰지 않는다. 무거래·미공표·결과 미확인을 구별한다.

현재 고정한 모델·선택 문턱·수수료/슬리피지/펀딩·평가 종료일은 그대로다. 실계정 접근·실주문·새 모델 탐색·기간 연장은 범위에 없다. 첫 검산된 실현 결과, 오류/누락, 사용자 조치가 필요한 문제, 마지막 평가 완료처럼 의미 있는 변화만 알리도록 요청했다.

기존 명세/정책 JSON/평가기의 `automatic_schedule_created: false`와 '자동 일정 없음'은 v1 등록 당시 상태다. 동결 파일을 편집하지 않았으므로 현재 예약 상태는 이 문서와 [활성화 기록](../../../reports/operations/q004_daily_forward_schedule/activation.json)을 함께 읽어야 한다. 일별 출력의 해당 고정 필드를 현재 앱 예약 상태 조회 결과로 해석하지 않는다. 미래 실행 결과는 같은 운영 기록 폴더의 고유 시각 파일로 보존한다.

로컬 파일이 필요한 예약이므로 실행 시 컴퓨터와 앱이 켜져 있어야 한다. [OpenAI 공식 예약 문서](https://learn.chatgpt.com/docs/automations). 앱의 예약 생성은 정시 기동·공표 성공의 보장이 아니며, 놓친 날짜는 실제 누락으로 남긴다.
