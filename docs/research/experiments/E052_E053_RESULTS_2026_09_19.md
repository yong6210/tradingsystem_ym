# E052·E053 — 단일 종목 분할 운용 구조 재검토와 9개 방식 비교

**구현의 부족한 부분을 수정하고 검증 범위를 넓혔지만, 높은 월수익을 내는 후보는 확보하지 못했다.** 가격·상위 추세·장세·학습 예측·실제 공격적 체결량을 이용한9개 판단 구조를 같은 계좌 엔진에서 비교했다. 서로 독립된9개의 수익 원리를 발견했다는 뜻은 아니다.

## 이전 구현에서 실제로 부족했던 부분

1. E050/E051에서는 상위 시간봉이 주로 포지션 크기에 영향을 줬고, 하위 봉의 신호가 방향을 바꿀 수 있었다. 새 추세형·돌파 재확인형은 **상위 시간봉의 방향이 직접 진입·전환을 결정**한다. 실패 돌파형은 별도의 역방향 판단을 최대60분 유지하므로 한3분봉 뒤 자동으로 반대로 되돌리는 구조를 피했다.
2. 네 개의 동일 수량 단위를 먼저 만들면서 최소 주문 단위가 지나치게 커졌다. 새 방식은 전체 위험 한도를 먼저 계산하고 가능한 최소 단위에 맞춰 초기·축소·추가 수량을 정한다. 검증용 예에서 전체가능수량0.003 BTC일 때0.001 BTC 진입이 가능함을 검사했다. 이것은 과거 실계좌 성과가 아니라 기능 경계 테스트다.
3. 기본 보유분을 남기면서 목표 수량25/50/100%를 조절한다. 총평균 단가로 손익을 관리하며 독립적인 core/tactical lot별 회계는 아니다. 수량 조절을 하지 않는 고정수량 대조군도 같은 방향·손절 조건으로 비교했다.
4. 상위봉·3분봉 완료 후1분 지연, 미래 데이터 변경 시 과거 특징 불변, 학습 라벨의 성숙 시점을 검사했다. 월별 예측 모델은 이전90일만 학습하고, 예측 대상 수익이 학습 기준일 최소1일 전까지 실현된 라벨만 사용했다. 두 예측 방식에서 각24개 월별 모델을 계산했다.

## 비교한 방식

- 상위 추세 중심:1시간 EMA20/50과4시간 종가/EMA20의 방향 합의.
- 횡보 회귀:1시간20봉 효율비율0.3 미만,24시간 VWAP에서1.5표준편차 이상 이탈 후1분봉 반전.
- 실패 돌파:이전60분 고저점 이탈 후3분봉이 범위 안으로 복귀한 경우의 단기 반대 방향.
- 돌파 재확인:이전3시간 가격 범위를 돌파한 뒤 후속3분봉에서 해당 가격을 다시 확인.
- 장세별 전환:추세/횡보 효율비율에 따라 위 판단을 전환.
- 과거 학습 예측:7개 가격·변동·추세 특징의 고정 ridge 모델로60분 수익 예측,15bp 이상일 때만 진입.
- 체결량 추세:3분 공격적 매수·매도 차이15%와 상대 거래량1.5배,상위 방향 일치.
- 체결량·가격 버팀:공격적 매도가 많아도 저점에서 복귀하거나 공격적 매수가 많아도 고점에서 밀리는 조건. 실제 호가 재공급을 입증한 것은 아니다.
- 체결량 포함 예측:위 ridge에 실제3/15/60분 공격적 체결량 차이를 추가.

체결량은 기존 Binance 원본 CSV의 `taker_buy_volume`과`volume`을 해시 확인 후 읽었다. [공개 자료의 필드 설명](https://github.com/binance/binance-public-data)에 따른 실제 집계값이며, 호가 대기열·미체결 주문·수동 지정가의 체결확률은 아니다.

재고와 체결확률을 함께 다룬 [Avellaneda–Stoikov 논문](https://math.nyu.edu/inmemoriam/avellaneda/HighFrequencyTrading.pdf)을 검토했지만, 이 실험은 해당 시장조성 모형의 재현이 아니다. 필요한 호가·주문 도착 자료 없이 maker 수익을 가정하지 않았다. 여러 시도를 한 뒤 좋은 결과만 고르는 문제는 [백테스트 과적합 연구](https://www.davidhbailey.com/dhbpapers/backtest-prob.pdf)를 참고해, 후보와 규칙을 등록하고 모든 결과를 보존하는 방식으로 관리했다. 이것이 재사용 자료의 과적합 위험을 없애는 것은 아니다.

## 월별 결과 — 별도 자금 실험

2024-09~2026-08, 각 달 별도1,000 USDC로 시작한24회 실험이다. 월별 손실을 실제로 지우고 재시작하는 운용 정책이 아니며, 결과를 연속 복리 수익률로 합치면 안 된다. 명목 노출 한도3배는 아직 사용자 확정값이 아니며 실제 노출은 위험·수량 한도로 더 작다. 월 운영비2 USDC 역시 연구 시나리오다.

## 실제 체결 가정에서 발견한 한계

- 60,626개 가상 체결의 기준가격을 원본1분봉 시가(표본 종료는 종가)와 대조했고 모두 일치했다. 거래량0인 분봉에 체결한 행은0개다.
- 그중129행의 주문 수량은 해당1분 전체 거래량의10%를 초과했고, 최대 비율은2배였다. 여러 비교 계좌에서 반복된 행을 포함한 건수다. 그 시점의 호가 깊이를 확인하지 않은 채2~5bp 고정 슬리피지를 실행 가능한 가격으로 인정할 수 없다. 매매 방향의 성과와 체결 모델의 미검증을 구분한다.
- 가격 기반 특징15개 분, 체결량 포함 특징114개 분은 거래량0 분모 때문에 일부 특징이 정의되지 않았다. 원본 봉 누락이 아니며, 값을0으로 조작하지 않았다. 해당 시각 신규 판단은 쉬고 열린 위험은 계속 관리했다.
- 현재의 고저점·VWAP·RSI·체결량 조건은 실제 재량 거래자의 매물대 판단과 같다고 검증되지 않았다. 수익을 확보하지 못한 원인을 전부 거래비용 또는 전부 잘못된 구현 하나로 돌리지 않는다.

## 확인한 범위와 다음 교정 기준

구조와 원장 처리는 이전보다 명확해졌지만, 분할 익절·재확대의 순수익 우위와 높은 월수익은 미확보다. 실제 사례의 진입·추가·익절·전환 순서를 이 시스템과 나란히 비교하면 어느 판단이 누락됐는지 직접 확인할 수 있다. 이를 위한 [최초 주문 흐름 표](E052_ORDER_REVIEW_2026_09_19.md)를 함께 만들었다. 좋은 수익 구간을 골라 보여준 것이 아니다.

고정한9가지 방식만 시험했으며 세상의 모든 매매 방법을 다 시험했다는 뜻은 아니다. 실제 호가/대기열, 체결 지연·부분 체결 및 계정 검증은 남아 있다. 성과가 없는 버전을 실운용하거나 손실 한도를 높여 수익 모델로 포장하지 않는다.
