# Q003 — 예측값을 기대수익으로 사용할 근거가 있었는가

2026-09-19. E040의 저장된 예측을 읽는 사후 방법 진단이다. E040 재학습·구제 실험, 신규 매매 전략, E048 재개가 아니다. Q002 만기형 캐리는 자료 불충분 상태로 보존하고 이번에는 BTCUSDC 일별 예측 방법의 문제 하나를 확인한다.

## 질문

PRICE/FLOW 예측은 당시 가용한 단순 과거 평균보다 정확했는가? 기존 비용 문턱을 넘은 예측값의 크기는 실제 방향별 가격 이익과 얼마나 달랐는가? 두 복잡도 수준의 작은 MSE 차이를 비용 후 수익 근거로 잘못 읽을 위험이 있었는지 확인한다.

이미 알려진 결과: E040 FLOW는 PRICE보다 MSE가 0.284% 낮았지만 활성 거래의 예측 방향 기대 이익 약 34.42bp, 실현 가격 이익 약 5.63bp, 기본 비용 후 −3.98bp였다. 이 기존 결과를 새 발견으로 주장하지 않는다. 새 비교는 **동일한 과거 180일 목표 평균 및 0 예측**과의 오차 비교다. 비교 결과나 구간별 결과는 아직 계산하지 않았다.

학습 평균을 단순 예측 대조로 두는 근거는 [scikit-learn DummyRegressor](https://scikit-learn.org/stable/modules/generated/sklearn.dummy.DummyRegressor.html), 시간 밖의 예측 평가 원칙은 [Forecasting: Principles and Practice](https://otexts.com/fpp3/accuracy.html)를 참조한다. 무작위 교차검증을 금융 시계열에 옮기지 않는다. 오차가 작다고 거래 수익이 자동 개선되는 것은 아니다.

## 입력과 노출

- reports/validation/e040_daily_flow_forecast_20260919의 PRICE/FLOW_signals, daily_features_and_targets, base/stress 이벤트 4개, summary, verification. 기존 2024-09-01~2026-08-31 미만의 729개 일별 진입 경계다. 실제 마지막 진입·청산을 원문에서 검사한다.
- 이미 여러 번 사용한 가격 표본의 순차 예측이다. 행별 학습 밖 예측이지만 프로젝트 수준의 미사용 홀드아웃 또는 새 전진 검증이 아니다.
- 새 시장 자료 요청, 특징 추가, 모델 재학습, 방향·문턱·학습 기간·보유 기간 변경은 0회다. 기존 수익/실패 결과를 보존한다.

## 계산 전 고정하는 범위

1. 모든 729일, PRICE/FLOW/MEAN180/ZERO 네 예측을 같은 실제 목표와 대조한다. MEAN180은 각 행의 원래 학습 범위인 [i−181,i−1)의 목표 평균이다. 그 180개 날짜의 연속성·목표 확정 시각을 확인하고 저장된 intercept_bps와 일치하는지 검산한다. ZERO는 매일 가격 수익 0bp 예측이며 현금 매매 정책이 아니다. 두 대조로 새 매매 신호·수익을 만들지 않는다.
2. 평균제곱오차 MSE(bp²), 평균절대오차 MAE(bp), 평균 예측 오차(예측−실제,bp), 단순 대조 대비 MSE 개선율 `1−MSE_model/MSE_reference`를 전체와 달력 연도별로 표시한다. 2024/2026은 일부 기간이며 연환산하지 않는다. 음의 개선율은 해당 표본의 오차가 더 크다는 뜻이다. 우연 변동·연구 선택 편향에 대해 통계적 유의성을 선언하지 않는다.
3. 기존 PRICE/FLOW 활성 거래만 대상으로 평균 예측 방향 이익 `abs(prediction)`, 실제 `side×target`, 차이 및 기존 base/stress 비용 후 이벤트 평균을 대조한다. 운영비·손절·최소 수량·계좌 경로는 계산하지 않는다. 이 차이의 원인을 특정 특징이나 시장 참여자에 인과적으로 귀속하지 않는다.
4. 원래 비용 문턱 H 대비 예측 크기 비율을 사전 고정 3구간으로 나눈다: `abs(p)≤H`(무거래), `H<abs(p)≤2H`, `abs(p)>2H`. 각 구간 표본 수와 방향별 예측/실현 평균을 공개한다. 활성 두 구간만 기존 거래비용/순손익을 표시한다. 무거래 구간의 sign(p)×target은 방향 예측 진단일 뿐 매매 수익이 아니며 비용 후 수익은 null이다. 결과를 보고 좋은 구간만 채택하거나 문턱을 바꾸지 않는다. 표본 부족도 그대로 표시한다.
5. 비교표는 두 모델 모두 공개한다. 특정 연도·방향·거래를 빼서 새 성과를 만들지 않는다. 순위에 따라 새 모델을 승격하지 않는다. 보정 회귀·새 신호·계좌 시뮬레이션은 실행하지 않는다.

## 검산과 결정

입력과 명세·코드를 결과 집계 전에 해시로 등록한다. 과거 평균의 시간 범위·기존 intercept와 일치 여부를 확인하고, 저장 목표와 이벤트 gross/side의 일치를 대조한다. float 계산과 별도 Decimal 합/제곱합 계산으로 결과를 검산한다. 합성 경계 검사로 미래 목표 불사용, H/2H 경계, 비활성 순익 null, 0 분모 처리 등을 확인한다. 원본 분봉부터의 독립 재구축은 반복하지 않는다.

단순 대조보다 오차가 크면 ‘기존 특징이 단순 대조 이상의 예측 정확도를 입증하지 못함’으로 기록한다. 오차가 작아도 비용 후 손익/예측 크기 불일치가 남으면 예측값을 비용 후 기대수익으로 취급하지 않는다. 어떤 결과든 그 자체로 새 채택·5% 낙폭 충족·실운용 적격성을 부여하지 않는다.

진단은 이 한 번으로 종료한다. 결과를 반영해 **앞으로의 예측 모델 명세에 과거 평균/0 대조, 비용 문턱 초과 예측의 실현 검증, 학습·보정·평가 자료 분리**를 명시하되, 이것을 모든 비예측 전략의 MSE 합격 조건으로 강제하지 않는다. 이미 본 E040 표본으로 보정 계수나 문턱을 학습해 독립 검증이라고 부르지 않는다.

사용자의 수익 우선·손실 5% 선호는 유지하고 월 목표·손실 정의·실제 운영비는 미정으로 보존한다. 결과는 reports/validation/q003_forecast_expectation_audit_20260919에 신규 작성한다.
