# E020 — 수신 순서 기반 연속 모의 계좌

2026-09-19. E019의 flat1,000 진입 추정을 실제로 이어지는 **모의** 잔고·포지션·손절·위험 상태와 연결한다. 이번 검증은 고정 합성 사건이며 신규 공개 관측/전략 백테스트/실주문이 아니다. 기존 E019 소스·공개 결과는 보존한다.

## 고정 규칙

- T0 완료 봉 신호·예정+1분, 지연 허용60초, 호가 나이5초/미래1초, 기존 기본 비용/위험 사용. 동일 방향은 유지하고 물량 추가 없음. 반대/중립 신호는 먼저 청산한다. 반대 방향 재진입은 이후 새 요청의 새 호가에서만 허용하며 의도 만료를 적용한다.
- 매수ask/매도bid에 가정 슬리피지·수수료를 적용한다. 보유 평가와 청산에는 포지션 반대 호가를 사용한다. 손절/일손실/DD/7일 보유 상한은 관측된 새 호가에서 검사한다. 미관측 구간의 고저/손절 가격 체결을 만들어내지 않는다.
- 손절 등 청산 조건이 발생하면 청산 필요 상태를 유지한다. 표시 수량이 부족하면 전체 체결을 꾸미지 않고 포지션/미청산 위험을 남긴다. 반전 청산 후 같은 호가에서 신규 위험을 만들지 않는다. 실제 부분체결·호가 깊이·청산 주문 보장은 미포함이다.
- 확정 펀딩은 정산 시점 이전 모의 체결 이력에서 부호 있는 수량을 찾고 수신 시점의 잔고에1회 반영한다. 청산 후 받은 과거 펀딩도 적용한다. 정산 시각±1초에 체결이 있으면 수량 판정이 모호하므로 거부한다. 거래소와 로컬 시계 차이에 대한 보수적 모의 규칙이지 실제 계정 펀딩 복제는 아니다.
- 동일 정산 사건의 중복은 무효과, 수정/충돌 값은 거부한다. 이미 확정한 펀딩 원장을 뒤늦은 입력으로 고치지 않는다. 이전 신호·사이징·위험 판단은 소급 재계산하지 않는다. 현재 위험 상태는 다음 새 호가에서 평가한다.
- 새 수신 세션은 새로운 식별자로 선언하고 단조 시계 기준을 다시 시작한다. 이전 세션 메시지는 거부한다. 잔고·포지션·손절·고점·위험 상태는 유지, 대기 진입은 취소한다. 관측 공백은 품질 이력에 남기고 보유 포지션은 다음 적격 호가에서 정리한다. 지표 준비/ARM 전 신규 진입은 금지한다.
- 원문·세션/수신 시각·상태·출력을 SQLite 한 트랜잭션에 기록한다. 동일 요청 재시도는 같은 원문·시각·세션만 허용한다. DB 재개 시 소스/규칙 바인딩을 확인한다.

## 검증과 한계

롱/숏, 동일 방향 유지, 중립/반전, 손절 갭/수량 부족/회복 뒤 청산 지속, 일손실·DD·시간 종료, 중복/늦은/충돌/모호한 펀딩, 새 세션의 단조 시계 초기화·대기 취소·포지션 보존, 저장 예외 후 재개를 고정 사건으로 검증한다. 통합 원장을 별도 Decimal 회계로 재생하고 거래 수량의 시간 조회·늦은 정산 반영을 확인한다.

미정 펀딩의 존재/완전성을 증명하는 공개 어댑터, 실제 신호가 생기는 공개 전진 관측, OS 전원 장애 전체·거래소 필터/수수료/보호주문·실주문은 미완료다. 거래 이력/정산 dedup은 이번 유한 시험에서 상태에 보존한다. 장기 저장량 적격성이나 실제 계좌 안정성을 주장하지 않는다. 기존 수익성 확증 계약은 변경하지 않는다.
