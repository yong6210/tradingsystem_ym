## 조건부 주문/평가 시계

진입과 정상 종료는 BTC 먼저, 그 체결 확인 뒤 ETH 순서로 고정한다. 각 지정가는 미체결3초 후 즉시 취소 확인, 시장가는1ms 후 전량 체결됐다고 가정한다. 각 다리 사이1ms 처리 간격을 둔다. 위험 종료는 시장가로 BTC 먼저/ETH 다음이며 각1ms 처리 지연을 둔다. 주문은 모델 이벤트이며 외부 거래소 접수·복구 인증이 아니다.

같은 시간 시가를 몇 초 동안 유지하고 방향에 불리한2 또는5bp로 체결하는 대용값을 쓴다. bid/ask·부분 체결 확률·6초 동안의 실제 가격 변화는 자료에 없다. 가정된 전량 체결 결과를 실제 체결 성공으로 부르지 않는다. 부분체결/거절 합성 검사는 실제 수량·잔량/위험을 인식하는 회계 경계만 확인한다.

모든 수량·평가·펀딩·현금은 Decimal. 같은 시각에는 펀딩을 체결보다 먼저 처리한다. 펀딩은 정산 이전 체결된 해당 계약의 실제 모의 보유량에만 적용한다. 미래 펀딩은 신호/진입 판단에 사용하지 않는다. 정산시각에 이력을 확인할 수 있었다는 가정이다.
