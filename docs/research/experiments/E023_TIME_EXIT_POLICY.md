# E023 / H01 — T0의 7일 시간 종료 정책 비교

2026-09-19. 회고적 단일 정책 진단. 신규 독립 전략·수익성 확증·실운용 설정 변경이 아니다. E022 공개 관측과 독립적인 과거 계좌 실험이므로 예약 결과를 기다리지 않고 진행한다. E022의 검증 완료 여부나 예약 소스는 바꾸지 않는다.

## 질문과 사전 고정

같은 방향 신호를 유지할 때 7일마다 청산하는 정책이, 해당 시간 종료가 없는 정책보다 비용 후 계좌 손익과 위험에서 유리한가? E006 시간 종료/재진입 집계는 가설의 출발점이며 결론이 아니다. 시간 종료를 없애면 보유 기간뿐 아니라 이후 수량·손절 재설정·신호 진입 기회·펀딩도 달라지므로 전체 계좌를 다시 실행한다.

- 기간: UTC 2024-09-01 00:00 이상 ~ 2026-09-01 00:00 미만, 730일/1,051,200분. BTCUSDC 기존 검증 가격·마크·지수·펀딩 번들. 지표 준비 자료는 그대로 포함한다.
- 자금: 1,000 USDC. T0 신호·EMA20/80·ATR·초기 손절·반전/중립·수량·경고/일손실/DD 제한은 E015와 동일.
- 대조: `maximum_hold_minutes=10080`. 변형: `1051201`. 최초 flat 상태에서 평가 구간 내 최대 보유 나이는1,051,199분이므로 변형에서는 시간 종료에 도달할 수 없다. 0은 즉시 종료를 유발하므로 금지한다. 이 설정은 이 유한 기간의 비교에만 유효하며 무기한 실운용 정책이 아니다.
- 비용: 기본 편도 수수료5bp/슬리피지2bp/실제 펀딩. 스트레스7bp/5bp/실제 펀딩+정산마다 양쪽 방향에1bp 추가. tick0.1, 최소 수량/명목은 기존 Risk 그대로. 지정가 무료라는 가정이나 현재 계정 수수료의 확인으로 해석하지 않는다.
- 경로: OHLC, OLHC 둘 다. 실제 tick 경로 또는 가능한 전체 경로의 최선/최악 경계가 아니다.
- 총8회: 대조4회가 E015 계좌를 정확히 재현한 다음 변형4회. 기간/파라미터/결과 선택 없음. 모든 종료 포지션은 동일한 최종 분봉 종가와 비용으로 강제 청산하며 이 종료를 전략 신호로 해석하지 않는다.

## 실행·검산·중단

새 helper와 runner만 사용하며 동결 엔진을 수정하지 않는다. 실행 시작 전에 소스/자료 manifest, 기존 증거, 정확한 검사 목록, 설정과 중단 규칙을 `registration.json`에 기록한다. 원자료는 loader에서 manifest SHA256으로 검증하고 가격 세 종류의 완전한 평가 기간을 요구한다. 예약 E022 소스 및 기존 증거도 전후 대조한다.

시간 종료/지속 보유, 보호 손절, DD 중단, 중립/반전, 추가 보유 중 펀딩, 짧은 구간의 무변경, 입력 오류를 고정 합성 사례로 검사한다. 기존 관련 회귀도 포함한다. 각 계좌의 독립 Decimal 원장·730일 평가손익·지역적 장중 손절 계산·비용/월별/거래별 합계를 검산한다. 검산 범위가 실제 거래소 청산이나 완전한 tick 경로를 증명하지는 않는다.

검사·자료·대조 재현·회계·해시 불일치 시 중단하고 실패 결과를 보존한다. 자동 재시도0. 구현 오류를 고쳐야 한다면 별도 버전/등록에 이유를 남긴다. 성과가 나쁘다고 보유 일수 그리드로 확장하지 않는다.

## 보고와 해석

주 관찰값은 각 비용/경로에서 변형−대조의 비용 후 최종 계좌 차이(USDC). 2년 수익률과 연간 수익률을 구분한다. 함께 DD, 일별 고점 미회복/회복 기간, 최악 월, 방향별 손익, 거래 수, 시간 종료/인접 동일 방향 주기 수, 최대 보유 기간, 비용 상세, 실제 노출, 상위1/5/10거래 집중을 보고한다. 인접 동일 방향 거래를 독립 추세 표본으로 세지 않는다.

기준가 손익 차이와 수수료·슬리피지·펀딩 차이를 분해하되 비용 절감만의 인과 효과로 해석하지 않는다. 실제 운영비는 미정이며 포함하지 않았다고 표시한다. 종가 기준 미회복과 장중 DD의 측정 단위를 구분한다.

2023~2026-08은 이미 관찰한 자료다. 유리한 결과도 표본 외 우위·통계적 확증·최종 모델 채택을 뜻하지 않는다. 불리하거나 위험/집중과 상충하면 해당 변경을 보류한다. 기존 평가 계약의 목표를 소급 조정하지 않는다. 다음 연구는 이 축의 근거를 정리한 뒤 기존 후보와 다른 수익 원리·필요 자료·실행/자본 제약을 갖춘 단일 질문으로 제한한다.
