# E004: 고정 수량 기준 모델·1,000 USDC 위험·고정 비교

2026-09-17, 새 결과 확인 전 작성. 목적은 완결된 기준 계좌 시뮬레이터와 동일 조건 비교를 구축하는 것이다. 회고적 BTCUSDT 대체 자료 평가이며 BTCUSDC 실거래 채택이나 최적화 실험이 아니다. E001/E003은 보존한다.

## 1. 기준 모델 및 인과성

완료 4시간 봉, EMA20/80·ATR14·ER20의 기존 동결 산식. T0=EMA20−EMA80 부호, T1=T0에 간격/ATR>0.5·종가가 EMA20의 해당 방향·ER>0.2 조건, T2=20봉 전 대비 종가 수익 부호. 현금 C0는 무거래 기준이다. 각 모델 1설정만 실행한다.

완료 판단 1분 뒤 시가에 시장가 대용 체결한다. 진입에서 수량을 정하고 포지션이 닫힐 때까지 유지한다. 같은 방향 판단에서는 수량을 재조정하지 않고 비용도 내지 않는다. 중립이면 종료, 반대면 종료 후 위험 재검사 및 반대 진입. 최초 손절은 판단 종가−방향×3 ATR, 진입 후 움직이지 않음. 최대 보유 7일. 손절/위험청산 뒤에는 다음 새 4시간 판단까지 재진입하지 않는다. 추가/분할/순환/후행 손절 없음.

가격은 손익용 실제 체결 대용 가격과 평가용 분봉 가격을 구분한다. 메이커 체결은 시뮬레이션하지 않는다. 메이커0 가정은 보존하지만 이번 기준은 명시적 시장가 비용 시나리오다.

## 2. 사건 순서와 회계

매 분 시가에서 펀딩 시나리오 반영 → 기존 위험/가격 손절의 갭 확인 → 시간 만료/기존 신호 청산 → 신규 위험 승인과 진입 → 봉 내 가격/위험 손절 확인 → 종가 평가·일별 저장. 시가의 평가자산이 이전 최고점을 넘으면 알려진 시가로 최고점을 갱신한다. 미래 고가로 먼저 최고점을 올리고 같은 봉 저가로 낙폭 청산하지 않는다.

가격 손절과 일간/누적 위험 손절은 해당 분 시작에 알려진 잔고·최고점·일초 자산에서 가격 임계값으로 변환한다. 여러 손절을 넘으면 진행 방향에서 가장 가까운 보호선을 먼저 적용한다. 갭은 임계값이 아니라 시가에 슬리피지/틱 반올림을 적용한다. 봉 내 임계값 체결도 대용 가정이며 미체결·충격·지연을 보장하지 않는다. 종료 평가 시점 밖 자료는 사용하지 않고 마지막 봉 종가에 강제 종료한다.

원장 잔고=초기+실현손익−수수료−펀딩, 평가자산=잔고+미실현. 모든 체결은 별도 재생기로 이벤트 직후 잔고/수량/평균가 대조. 반전은 종료·신규 두 체결. 수량 유지 기간에는 입출금이나 가상 리밸런싱 없음.

## 3. 주문·위험

연도별 초기1,000 USDC와 별도 전기간 연속1,000 USDC 계좌를 모두 보고. 연도별 리셋을 연속 성과로 연결하지 않는다. 주기 위험0.5%, 전체 예약1%, 총 명목1배. 동시 포지션1개로 주기 한도가 우선한다. 진입 수수료·슬리피지와 손절 청산 비용을 포함해 q_cap을 계산하고 0.001 BTC 증분 내림, 50 USDC 최소 명목과 0.001 최소 수량, 0.1 가격 틱의 보존된 공개 스냅샷을 적용한다. 현재 필터의 과거 적용은 반사실적 시나리오이며 역사적 거래소 규격 재현이 아니다.

일초 평가자산 대비2% 손실이면 그 UTC일 신규 진입 중단. 원장·자료 검사를 통과한 다음 UTC일에만 일간 latch 해제. 이전 최고점 대비5% 경고는 실행 구간 내 해제 없이 이후 위험 예산 절반;8%는 해당 실행 구간 나머지 전체 신규 중단. 기존 포지션은 위험 보호선에서 시장가 대용 청산한다. 비용/갭으로 8%를 초과할 수 있다. 낙폭 기준에는 실현·미실현·비용 포함. 일초 기준은 해당 UTC일 첫 시가에서 보유 포지션 평가 후 정함.

유지증거금 구간과 실제 마크/계정 규격은 미검증이므로 실전 적격 판정은 하지 않는다. 평가자산≤0이면 신규 금지 및 파산 상태. 시장가 주문의 실제 유동성/증거금 승인은 별도 과제다.
