# Q001 — 체결 비용의 관측 근거와 가정 분리

2026-09-19. 방법 v2의 선행 자료 진단. 새 수익 가설·성과 실험·E048 재개가 아니다. 이 명세는 아래 집계 실행 전에 작성한다. 기존 S06B 실패 결과와 2/5bp 비용 시나리오는 그대로 보존한다.

## 질문과 결정

기존 BTCUSDC 호가 자료로 0.001 BTC 주문의 표시 스프레드, 표시 물량 소화 비용, 가정한 3초 동안의 가격 이동을 각각 식별할 수 있는가? 어떤 비용은 여전히 가정인가?

이 질문은 다음 전략의 비용 모델에 필요한 증거를 정한다. 비용을 낮추어 과거 실패 전략을 합격시키거나 수익 개선을 주장하지 않는다. 경제적 알파, 진입·보유·손절·청산·자금 배분·계좌 순익은 이번 질문의 대상이 아니므로 계산하지 않는다. 사용자 수익 목표·손실 정의·실제 운영비는 미정으로 유지한다.

## 입력·노출·범위

- E032 snapshot repair v2의 8개 grid.jsonl 모두: 2024-10-01부터 2026-07-01까지 분기 첫날 00:00–00:10 UTC. 총 80분, 1초 간격 4,800행. 날짜·신호·결과에 따른 추가 선택 없음.
- 기존에 사용한 자료다. 미사용 표본이나 전진 검증으로 부르지 않는다. 분기 첫날·UTC 자정에 집중된 짧은 자료로 장기 비용·급변 시 비용을 추정하지 않는다.
- E032의 기존 valid 판정을 승계한다. 원본 수신 시각 기준 재구성된 상위 5단계 호가다. 공급자 수신 시각은 우리 주문 왕복 지연이 아니다. 기존 독립 검산·수정 기록의 해시를 확인하되 이번에 원시 L2 재구성을 독립적으로 다시 증명하지 않는다.
- valid 행도 호가 정렬·양수 가격/수량·비교차 호가·mid 일치·수신 시각 선행·고정 1초 간격을 검사한다. invalid 행을 보간하지 않는다.
- 수량은 0.001 BTC 하나, 양 방향을 모든 적격 시각에서 계산한다. 같은 호가의 가상 매수/매도는 대응된 계산이며 별도 독립 거래가 아니다. 현재 최소 주문 단위와 같지만 체결·증거금·계정 승인 판정은 아니다. 표시 명목 50 USDC 미만 여부는 별도 집계한다.

## 산식과 대조

시각 t의 mid=m, 방향 s=+1 매수/-1 매도, best=b, 표시 물량 순차 소화 가중 가격=v:

- 반스프레드 비용: s×(b−m)/m×10,000 bp.
- 표시 깊이 비용: s×(v−b)/m×10,000 bp.
- 즉시 표시 비용: s×(v−m)/m×10,000 bp. 앞의 두 항과 일치해야 한다.
- 물량이 부족하면 미충족으로 기록하고 완전체결 가격을 만들지 않는다. 수수료·추가 슬리피지·틱 반올림을 이 가격에 더하지 않는다. 실제 표시 가격의 가중 평균이다.

t부터 t+3초까지 4개 행이 모두 valid이고 연속인 경우만 3초 진단에 포함한다. 3초는 기존 E032 시나리오 하나를 재사용하며 측정 지연이나 최적 지연이 아니다. 양 끝에서 해당 방향 0.001 BTC 표시 물량이 충분해야 한다.

- 방향별 가격 이동: s×(m[t+3]−m[t])/m[t]×10,000.
- 지연 후 반스프레드와 깊이 비용: 각각 s×(b[t+3]−m[t+3])/m[t]×10,000, s×(v[t+3]−b[t+3])/m[t]×10,000.
- 합계: s×(v[t+3]−m[t])/m[t]×10,000. 3개 항의 합과 일치해야 한다. 유리한 가격 이동은 음수로 유지한다.
- 즉시 표시 비용을 대응 대조로 제공한다. 절대 mid 이동도 방향과 무관하게 시각당 한 번 집계한다. 3초 구간은 중첩되므로 독립 관측으로 간주하지 않는다.

각 날짜·전체, 각 방향별 건수, 평균, 최소, 중앙값, 95백분위, 최대를 보고한다. 중앙값·95백분위는 오름차순 nearest rank(ceil(p×n)−1), 짝수 표본 중앙 두 값의 평균과 다를 수 있다. 유의확률·신뢰구간·연환산·최적 비용값·실제 손익은 계산하지 않는다.

## 관측과 가정의 구분

- taker 2.5bp/체결, maker 0bp는 사용자 입력이며 계정 요율 독립 확인은 없다.
- 2/5bp 추가 슬리피지 및 추가 1bp 펀딩 스트레스는 연구 시나리오다. 실제 역사적 펀딩 현금흐름과 구분한다.
- 봉 기반 Costs.fill의 reference와 호가 기반 market_leg의 reference가 다르다. mid 대비 호가 비용으로 봉 진입 가격 대비 슬리피지를 곧바로 대체할 수 없다. 이미 진입 시각 가격에 반영된 가격 이동을 중복 부과하지 않도록 이후 정책의 기준 시각/가격을 명시해야 한다.
- 표시 호가는 체결 보장이 아니다. 숨은/RPI 유동성, 주문 도착 시 취소·경합, 부분 체결, 실제 거래 역할, 계정 조건은 이 자료로 확인하지 못한다. 지정가 maker 수익도 추정하지 않는다.
- 공식 거래소 API 근거: [Binance USD-M market data](https://developers.binance.com/en/docs/catalog/core-trading-derivatives-trading-usd-s-m-futures/api/rest-api/market-data). 현재 API 설명은 과거 공급자 자료의 완전성을 보증하지 않는다.

## 판정·검산·종료

표시 비용 분해가 검산되면 해당 80분의 표시 호가 진단만 통과한다. 실제 체결 비용 보정 가능 여부는 별도이며, 실제 주문/체결과 대표적인 시간대 자료가 없으면 미확인으로 끝낸다. 스프레드가 작아도 추가 비용을 0 또는 관측 분위수로 바꾸지 않는다.

총 범위: 수량 1개 × 방향 2개 × 즉시/3초 진단, 8개 구간 전수. 전략 백테스트 0, 신규 시장 요청 0, 실주문 0. 더 긴 지연·더 큰 수량·다른 날짜·성과 재계산으로 확장하지 않는다.

실행 전 registration.json에 명세·코드·테스트·입력·기존 검산 해시를 고정한다. Decimal 계산과 별도 Fraction 계산을 대조하고, 경계 테스트로 다단계 소화·물량 부족·부호·무효 구간을 확인한다. 결과·검산은 reports/validation/q001_execution_cost_evidence_20260919에 신규 작성하며 실패·변경을 덮어쓰지 않는다. 원본과 동결 소스는 수정하지 않는다. 이후 전략은 수익 원리와 완결된 정책을 별도로 명세해야 한다.
