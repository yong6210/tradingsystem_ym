# Q004 누적 평가 보완 — 예측/비용 규칙 변경 없음

2026-09-19. 첫 목표 종료 전 읽기 전용 평가기를 추가했다. 기존 Q004 명세의 PRICE/MEAN180/ZERO 비교와 원래 H/사후 2H의 비용 후 사건 결과를 구현한다. 새 모델·신호·문턱·성과 합격 기준이 아니다. 과거 모델을 다시 튜닝하거나 관찰 종료를 연장하지 않는다.

현재 날짜의 상태 표시는 원래 `status` 명령보다 엄격하다. 90개 등록 날짜마다 미래, 공표 창, 미공표, 결과 대기, 만기 경과 후 결과 미확인, 증거 오류, 검산된 결과를 구분한다. 예측 공표 영수증·기존 독립 예측 감사의 해시 연결·고정 입력을 확인한다. 늦은 공표, 감사 누락, 원문 변조, 목표 종료 전 점수는 집계에서 제외하고 오류 사유를 남긴다.

결과가 있으면 공개 요청 4개의 원문/영수증을 대조한다. 진입·종료 가격은 등록된 두 분봉 시가이고, 펀딩은 양끝을 감싸고 간격 조건을 만족해야 한다. 기존 단위 사건 계산기를 호출하지 않고 Fraction 산술과 방향별 틱 올림/내림으로 비용 성분을 재구성한다. 원문과 저장 결과가 맞지 않으면 결과 오류로 표시한다. 미래 자료를 요청하거나 기존 결과 파일을 수정하지 않는다.

예측의 MSE(bp²)·MAE(bp)·예측−목표 평균은 세 모델의 **같은 검산 날짜**에서 계산한다. 원래/강한 규칙 모두 기본/스트레스의 사건 bp 합계, 검산 날짜당 평균, 활성 사건당 평균을 표시한다. 활성 사건당 평균의 분모에서 관망은 제외하지만, 검산 날짜당 평균에는 실제 관망의 0을 포함한다. 미공표·미확인·오류·미래 날짜는 어느 쪽에도 0으로 넣지 않는다. 전체 등록 날짜별 상태와 분모를 함께 공개한다. 관측이 0개이면 손익 합계와 평균·MSE 모두 null이다. 검산된 날짜가 있지만 활성 사건이 없으면 달력 기준 손익은 0, 사건당 평균은 null이다.

bp 합계는 복리 계좌 수익이나 USDC 손익이 아니다. 일부 관측이 누락된 집계는 유효 부분집합에 대한 기술 통계이며 전체 기간 수익을 추정하지 않는다. 자동 채택·손실 5% 적합 판정·계좌 위험 지표는 만들지 않는다. 90일 종료와 기존 모든 예측은 유지한다.

실행: 저장소 루트에서 Python으로 `scripts/evaluate_prospective_price.py`를 호출한다. `--output`에 **새 JSON 경로**를 지정하면 현재 시각 스냅샷을 기록하며 기존 파일은 덮어쓰지 않는다. 조회·prepare·publish·score·예약 실행은 수행하지 않는다. 원래 [수동 순서](Q004_MANUAL_RUNBOOK.md)를 따른 뒤 집계기를 실행한다. 기존 수동 문서와 동결 스크립트는 편집하지 않았다.

검사는 별도 임시 폴더의 합성 관측으로 수행하며 실제 성과에 넣지 않는다. 8개 검사는 무관측 null, 미공표/미확인, 실제 관망 분모, 원문 독립 계산, 결과 변조, 해시가 다시 연결된 펀딩 누락, 늦은 공표/이른 결과, 공표 없는 결과와 집계 산술을 다룬다. 실제 미래 결과 검산은 아직 불가능하다.
