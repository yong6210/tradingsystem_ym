# E028 S10 고정 규칙의 조건부 과거 재생

2026-09-19. E027 단일 주기 엔진을 변경하지 않고 E026의2024-09-01~2026-09-01 UTC 미만 자료에 연결한다. 질문은5 USDC 주기 손실중단·분리 지갑·순서 체결이 E026의 조건부 현금흐름을 얼마나 바꾸는가다. 실제 체결가능성/미래 수익성 인증이 아니다.

## 고정 범위

- 초기 현물/선물500/500 USDC, 현물 지출 상한400, 목표양쪽0.006 BTC, 재진입·자동 이체 없음. E027의 손실/담보/시장가 전환 규칙과 코드 그대로다.
-4조건: 기본2bp 체결가격 불리함/역사적 펀딩, 스트레스5bp/각 정산1bp 추가 지급 × 월 운영비0 또는2 USDC. 현물10bp/선물2.5bp를 USDC로 지급한다고 가정한다.0은 운영비 미반영 대조,2는 미확인 비용 예시이며 실제 견적 또는 최적값이 아니다.
- 운영비는 각 달 마지막 날23:00에2 USDC를 현물 지갑에서 차감한다. 중단 이후에도 전체24개월 서비스가 유지되는 조건으로 총48 USDC를 차감한다. 중단하면 자동 비용 면제라고 가정하지 않는다.
- 최초 시간봉 시가에서 진입 시도. 모든 지정가는 미체결,3초 후 즉시 취소 확인, 시장가 잔량은 다음1ms에 전부 체결된다고 가정한다. 두 다리는 순서대로 처리한다. 이 몇 초 동안 같은 시간봉 시가를 가격 대용값으로 유지한다. 호가/취소 지연/체결확률 관측이 아니다.
- bid/ask 대용값은 해당 시가에각각−/+2 또는5bp, 시장가 체결도그 값이다. 비용을 두 번 차감하지 않는다. 지정가 주문이 실제로 미체결될지는 자료로 확인할 수 없다.
- 위험 판단은 매시간 시작에만 한다. 마크는 기존 분봉의 해당 시각 시가를 쓴다. 같은 시간의 고가·저가·종가는 그 시간 진입/청산 판단에 쓰지 않는다. 펀딩 시각에는 당시 마지막 시간 시가 대용값으로 위험을 재확인한다. 이 경우에도 초 단위 실제 신선한 호가라고 표시하지 않는다.
- 펀딩은 역사적 정산시각에 확인 가능했다고 가정한다. 같은 시각 체결보다 정산이 먼저다. 미래 정산률을 진입 판단에 쓰지 않는다. 미확인 선물 주문이 걸린 정산은 완료 증거 이후 과거 보유량으로 반영한다.
- 종료는 마지막 시간2026-08-31 23:00 UTC부터 순차 청산을 요청한다. E026의 마지막 종가 동시 청산과1시간 및 실행 순서가 다르며 차이를 분리한다. 먼저 위험 중단된 계좌는 재진입하지 않는다.
- 시간별/일별 평가만 해당 완료 봉의 종가·마크 종가를 사용한다. 위험 판단은 시간 시작 기준이므로 장중 손실중단·실청산 위험을 재현하지 못한다. 평가에는 가정상 잔여 청산 수수료를 별도 차감하며 E027 중단 기준 자체는 바꾸지 않는다.

## 검산과 종료 기준

등록 후4계좌만 실행한다. 별도 모의 거래소의 체결·정산 입력·운영비에서 모든 시간말 두 지갑과 평가자산을 독립 Decimal 재구성한다. 진입/종료시각, 비용·가격·펀딩 귀속, 중단 후 현금 유지,730일 회복/낙폭을 보고한다. E026 기본/스트레스는 동일 월비용0 조건의 설명용 대조이며 변경된 시점·위험중단 차이를 숨기지 않는다.

재생 도구는 합성 짧은 경로에서 미래 봉 고가/종가가 이전 판단을 바꾸지 않는지, 펀딩의 실제 보유시각, 중단 뒤 재진입 없음, 운영비 지속, 최종 강제 종료를 검사한다. E02724검사도 동결 소스로 실행한다. 기존 E022/E026/E027 소스와 증거를 보호한다. 새 공개 요청·실주문 없음.

조건부 결과가 양수여도 단독 전략 적격성과 조합 채택으로 승격하지 않는다. 음수/중단이 확인되면 해당 고정 조건을 기록하고 중단 기준·수량·초기 시점·비용 가정을 사후 변경하지 않는다. 이 단일 질문을 종료하고 결과에 따라 남은 자료/계정 확인 또는 다른 독립 후보의 적격성을 판단한다.
