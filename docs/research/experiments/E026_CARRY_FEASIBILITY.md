# E026 / H02: 현물 매수·선물 매도 캐리의 자료와 자본 적격성

2026-09-19. E025 뒤 독립 수익 원리 하나를 선택한다. S10의 현물 BTC 매수와 동일 BTC 수량의 BTCUSDC 무기한 선물 매도를 검토한다. 가격 방향 예측이나 과거 펀딩 필터 S09의 변형이 아니다. 음수 펀딩도 그대로 지급하며 미래 펀딩을 미리 보고 진입/청산하지 않는다.

이번 질문은 **무료 동시 현물 자료를 확보할 수 있고, 1,000 USDC에서 고정 수량을 두 계정에 나눠 보유하는 단순 구조가 비용·증거금 관점의 다음 연구 대상으로 적격한가**다. 이것은 실제 운용 전략·전체 위험 엔진·수익성 백테스트가 아니라 선행 적격성 진단이다. 초기 400 USDC를 현물 매수 상한, 500을 선물 격리 담보, 나머지를 미이전 현금으로 고정한다. 자동 이체·현물 담보 사용·재투자·재조정·레버리지 확대는 없다. 자본 배분을 결과에 맞춰 탐색하지 않는다.

관찰 기간은 기존 연구와 같은 2024-09-01 00:00~2026-09-01 00:00 UTC 미만. 진입은 최초 시간봉 시가의 시장가 대용값, 최초 경계와 같은 시각의 펀딩은 진입 전 정산으로 제외한다. 평가 종료는 마지막 시간봉 종가의 두 다리 청산 대용값이다. 새로 확보하는 현물도 이미 본 과거와 겹치므로 독립 전진 자료로 부르지 않는다.

공식 BTCUSDC 현물 월별 1시간봉 24파일과 CHECKSUM 24파일, 현재 공개 현물 필터 1요청만 수집한다. 최대49요청·개별응답1MiB·총16MiB·파일당 펼친 자료4MiB·요청당20초, 자동 재시도0. 2025년부터 공식 현물 timestamp가 ms→us로 바뀐 것을 처리하고 월별 시각 단위를 명시한다. OHLC/거래량/체결수/중복/순서/시간 경계/월 전체/17520시간 일대일 조인을 검사한다. 결측 보간·다른 종목 대체 없음. HTTP/체크섬/품질 실패는 보존하고 중단한다.

초기 BTC 수량은 가장 불리하게 등록한 현물 편도 수수료10bp·슬리피지5bp에서400 USDC 안에 들어가는 수량을 공통0.001 BTC 단위로 내린다. 현물 사용자 수수료는 미확인이다. 0/2.5/10bp의 세 **가정 민감도**를 보고하며 실제 요율로 취급하지 않는다. 사용자 답변은 별도 증거로 보존하며 등록된 민감도를 소급 변경하지 않는다. 선물 편도 수수료는 사용자2.5bp를 유지한다. 양 다리 슬리피지2/5bp, 추가 선물 펀딩0/1bp를 기본/스트레스로 고정하여 총6개 동일 수량 귀속 경로를 계산한다. 현물 수수료의 USDC 현금 지급 가정·실제 자산 차감 방식 미확인도 남긴다.

주 진단은 선물 계정의 자본 부족 여부다. 시간 내 마크 고가에서, 해당 시간의 모든 양수 펀딩은 이미 받았고 음수 펀딩은 아직 내지 않았다는 **가장 유리한 펀딩 시각 상한**으로도 선물 평가자산이0 이하라면 무이전 고정수량 경로의 생존 불가를 확인한다. 현물 평가이익과 미이전 현금을 선물 담보로 자동 합산하지 않는다. 유지증거금0에서도 부족한지와 별도1%+청산비용 준비 가정을 분리한다. 1%는 실제 계정 유지증거금이나 역사적 구간값이 아니다. 시간봉/마크 공백은 결론 차단이다.

비용 후 이론적 쌍 합산 현금흐름·월별 귀속·펀딩 부호/집중·호가 없는 가격 괴리 대용값을 보조로 공개한다. 담보 부족 뒤의 합산 경로는 **실행 불가능한 조건부 산술**이며 전략 수익률로 보고하지 않는다. 두 다리 지연/부분체결·청산/ADL·운영비·현재/역사 계정 조건·공통 위험 중단은 미검증이다. 이 진단만으로 T0와 조합하거나 전진 수익성 후보로 채택하지 않는다.

검산: 단위 전환/중복·공백/자본 분리/펀딩 부호의 손계산 fixture, 전체시간 벡터 결과의 별도 Decimal 합산·최종 네 체결 비용 대조, 등록 소스/원문 SHA256. 이전 E025/E022 소스·예약은 보존한다. 다음 단계는 실제 관찰된 실패 하나를 기준으로 결정하며 사후 자본 배분 그리드를 실행하지 않는다.
