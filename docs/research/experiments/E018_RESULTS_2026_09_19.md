# E018 — T0 증분 계산과 과거 재현 결과

**관측 경계에서 포지션을 청산하지 않고, 이전 계좌·지표 상태에서 계산을 이어가는 오프라인 핵심을 구현했다.** 기본/스트레스2년 결과가 E015 OHLC와 정확히 일치했다. 새 시장 관측이나 전진 체결 모의가 시작된 것은 아니다.

## 해결한 구현 문제

기존 배치 엔진은 실행 끝마다 `end_exit`한다. 이를 매 분/주기 관측에 그대로 호출하면 관측 경계가 불필요한 청산·재진입으로 바뀐다. 새 엔진은 포지션·최초 손절·진입 시각·고점·일 시작 자산·위험 경고/중단 상태를 인계한다. 최종 비교 종료에만 명시적으로 `finish()`한다.

지표도 전체 과거를 반복 계산하지 않고 완료4시간 봉마다 EMA20/80·ATR14를 갱신한다. 기존 T0의 ER 유효성 마스크를 보존하기 위해 최대21종가를 유지한다. 원장 이벤트는 매 분 출력으로 반환하고 체크포인트에 전체 이력을 누적하지 않는다.

| 코드 | 역할 |
|---|---|
| `app/research/observation/t0_signal.py` | 완료 봉 집계·고정 T0 신호·관측 시각 |
| `app/research/observation/bar_account.py` | 분봉 계좌·위험 상태 증분 실행과 명시적 종료 |
| `app/research/observation/checkpoint.py` | 소스·설정 바인딩과 체크섬 상태 봉투 |
| `scripts/verify_incremental_bars.py` | 과거 재생·JSON 인계·기준 원장 대조 |
| `tests/test_bar_observation.py` | 새 경계 검사12개 |

38검사는 신규12개·장중 경로10개·회계5개·방향11개다. 전 프로젝트 전체 회귀는 아니다. 인계972회에는 준비 기간도 포함된다. 같은 프로세스 안에서 JSON을 거쳐 새 객체로 복원한 검사이며,972번 OS 장애 복구가 아니다. 크기는 이번 측정값이지 장기 저장량 전체의 보장이 아니다.

**전체 이벤트·거래·일별 자산·거절·장중 청산 기준가 기록과 최종 지표가 E015 OHLC와 정확히 일치**했다. 순차 ATR과 배치 ATR은 절대오차1e-8로 검사했으며 방향·결정 시각은 동일했다. 전체 데이터의 신호 준비 구간과730일 계좌 평가를 구분한다.

| 기존 T0 재현 | 2년 누적 수익 | 장중 가정 경로 최대DD | 주기 |
|---|---:|---:|---:|
| 기본 | 7.9217% | 3.9634% | 153 |
| 스트레스 | 4.8710% | 4.7212% | 153 |

이는 새 수익성 증거나 개선 전략이 아니라 기존 모델의 실행 방식 재현이다. 실험은 OHLC 경로로 고정했다. OLHC는 단위 검사에서 비교했고 전체2년 증분 실행을 추가 수행한 것은 아니다. 기존 E005/E015 소스·위험 한도·전략 규칙은 보존했다.

## 과거 재생과 전진 관측의 경계

완료 분봉의 고가·저가·종가를 받은 시점에 그 봉의 과거 시가로 진입할 수 있었다고 주장하면 안 된다. 신호는 봉 종료, 예정 시각(종료+1분), 수신 시각, 관측 가능 시각을 구분한다. 관측 가능 시각은 예정과 수신 중 늦은 값이며 지연 수신을 과거로 돌리지 않는다.

이번 수신 시각은 **봉 종료로 가정한 모의 시계**다. 과거에 측정한 실제 수신 시간이 아니다. 등록에 `SIMULATED_BAR_CLOSE_NOT_MEASURED_RECEIPT`를 명시했다. 계좌 코어는 `HISTORICAL_REPLAY`만 허용하고 실시간/전진 체결 분류를 거부한다.

중복/누락 분, 미완료 봉, 잘못된 OHLC, 펀딩의 처리 분 불일치, 체크포인트 내용·구현 바인딩 변경, 종료 후 재실행을 거부하는 검사를 통과했다. 체크섬은 우발적 변경 검출이며 외부 공격에 대한 서명이나 원장과 상태의 원자적 저장을 증명하지 않는다.

## 다음 작업

완료한 범위는 **고정 지표·위험·계좌의 증분 계산과 과거 재현**이다. 다음은 제한된 공개 수신에서 원본/수신 시각→완료 봉 신호→수신 이후 가격의 모의 주문 의도를 연결한다. 지연 신호를 과거 예정 가격으로 채우지 않고 지연/미체결로 남긴다. 늦게 확정된 실제 펀딩도 과거 의사결정을 수정하지 않는 별도 정산 규칙이 필요하다. 원장과 상태의 저장 경계 연결도 남아 있다.

긴 L2 호가 수집이나24시간 적격성 개발을 봉 기반 경로의 선행 조건으로 되돌리지 않는다. maker 체결/역선택은 별도 증거가 필요한 범위다. 기존 수익성 전진 계약의 운영비·정밀도·기간 미정은 그대로 유지한다. 기술 검사 통과를 수익성 합격으로 바꾸지 않는다.
