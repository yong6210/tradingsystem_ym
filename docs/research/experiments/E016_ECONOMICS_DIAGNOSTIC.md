# E016 — 기존 T0 원장의 경제성·수량·회복 진단

2026-09-18. 실행 전 분석 범위를 고정한다. E014 T0 기본/스트레스 두 원장과 동일한 E015 OHLC 원장만 사용한다. 2024-09-01~2026-09-01 UTC 미만, 730일, 최초 1,000 USDC. 새 전략 실행·튜닝·채택은 없다.

1. 실제 분봉 시가/최종 종가와 E015 장중 청산 기준가를 연결한다. 동일 거래·수량의 기준가 손익에서 슬리피지, tick 반올림, 수수료, 실제 역사적 순펀딩, 인위적 스트레스 펀딩을 분리해 순이익과 Decimal 대조한다. 기준가 손익은 무비용 전략 재실행이나 지정가 수익이 아니다.
2. 최초 손절과 비용을 포함한 BTC당 위험, 연속 수량, 명목 한도, 거래소 단위로 내림한 수량을 재구성한다. 위험 예산 사용률과 주문 단위를 집계한다. 거절은 반복 결정 수이며 놓친 독립 거래 수가 아니다. 위험 예산을 기간 전체에 합산해 유휴 자본으로 해석하지 않는다.
3. 진입/장중 청산 분은 포함하고 시가 청산 분은 제외하여 실제 보유 시간과 평균 명목을 원시 가격으로 재계산한다. 명목/초기 자본은 증거금 사용률이 아니다.
4. 일별 종가의 고점·최저점·회복 날짜와 마지막 미회복 구간을 표시한다. 고점부터 회복일까지의 달력 일수와 실제 고점 미만인 종가 수를 구분한다. 장중 최대 DD와 일별 DD를 혼동하지 않는다.
5. 순이익/24개월을 같은 거래 경로의 추가 운영비 손익분기액으로 표시하고 월 0/1/2/5 USDC 차감 예시를 계산한다. 실제 서비스 가격이나 인출·재사이징 백테스트가 아니다.

새 진단의 경계 검사, 기존 회계/캘린더 검사, 두 계좌의 독립 회계·일별 종가 검산을 실행한다. 기존 E014/E015 증거 해시와 새 소스 스냅샷을 보존하고 실행 전후 대조한다. 오류가 있으면 실패 기록을 남기며 기존 출력 디렉터리를 덮어쓰지 않는다. 결과에 맞춘 레버리지·위험·신호 변경은 하지 않는다.
