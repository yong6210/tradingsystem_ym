# E018 — T0 분봉 증분 실행과 오프라인 상태 인계

2026-09-19. 실행 전 범위: 새 가격 봉 관측 경로의 **오프라인 증분 계산 핵심**을 확인한다. E015 OHLC T0 기본/스트레스 두 계좌를 그대로 재현한다. 새로운 수익 모델 비교가 아니다. 기존 등록·평가·데이터 정책을 수정하지 않는다.

## 해결할 구현 문제

기존 배치 엔진은 호출 종료마다 end_exit한다. 이를 주기 관측에 그대로 재사용하면 관측 경계에서 강제 청산·다음 진입을 반복하게 된다. 새 엔진은 계좌/위험 상태와 EMA·ATR·최대21개 종가만 인계하며, 경계에서 청산하지 않는다. 최종 비교 종료 시에만 명시적으로 finish한다. 출력 이벤트는 매 분 반환하여 상태에 전체 이력을 쌓지 않는다.

## 고정 조건과 검사

- BTCUSDC, 최초1,000 USDC, T0 완료4시간 EMA20/80, ATR14/손절3ATR, 기존 위험·비용 유지. OHLC 가정 경로 한 개를 명시한다. 실제 틱 경로가 아니다.
- 기존 전체 가용 분봉에서 신호를 순차 계산하고 기존 배치 정책의 모든 결정과 시각/방향/ATR을 비교한다. ATR 부동소수 계산은1e-8 절대 오차로 검사한다. 종료 뒤 예정 신호는 별도로 제외한다.
- 2024-09-01~2026-09-01 UTC 미만2년에서 기본/스트레스를 각각 실행한다. 매일 경계 및 처음 진입 직후 JSON 직렬화/복원한다. 신호는 과거 가격으로 준비하되 계좌는 평가 시작에1,000으로 시작한다.
- 전체 사건·거래·일별·거절·지역 손절·최종 지표를 E015 OHLC 증거와 정확 대조한다. 차이가 생기면 원인을 남기며 기준값을 수정하지 않는다. 회계/신호 검사와 경계 단위 검사를 함께 실행한다.
- 중복/누락 분, 미완료 봉, 펀딩 사건의 처리 분 불일치, 변경된 체크포인트/구현 바인딩, 종료 후 재실행을 거부한다. 상태 인계는 명시적 체크섬 봉투이며 전체 OS 장애·원자적 원장 저장 검증으로 부르지 않는다.

## 관측 시각과 체결의 경계

분봉의 시가/고가/저가/종가를 전부 받은 때는 그 봉이 끝난 뒤다. 그때 과거 시가에 실제로 체결할 수 있었다고 해석하면 선행 정보 오류다. 따라서 이 버전의 계좌 코어는 `HISTORICAL_REPLAY`만 허용한다. 신호는 봉 종료 시각, 예정 시각(종료+1분), 수신 시각, 실제로 관찰할 수 있는 가장 이른 시각을 별도 출력한다. 지연 수신을 예정 시각으로 되돌리지 않는다.

실시간 가격/펀딩 수신, 수신 이후 모의 체결, 지연/공백 처리, 원장과 상태의 원자적 저장 연결은 다음 단계다. 이번 실행은 새 전진 표본·수익성 확증·장기 관측 시작·실주문이 아니다. 기존 전진 수익성 계약의 운영비/정밀도/기간 미정 상태는 유지한다. 기존 L2 전진 자료 계약은 지정가 체결용으로 보존하고 봉 기반 경로에 임의 적용하거나 완화하지 않는다.
