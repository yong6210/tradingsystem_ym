# E036 — 전날 같은 세션 반전의 비용 후 경제성

상태: 실행 전 명세. 2026-09-19. T0 변형이 아닌 고정 세션 가설 한 개의 회고 검증이다.

가설: 특정 시간대에 일시적인 주문 불균형으로 발생한 가격 움직임이 다음 날 같은 시간대에 되돌려질 수 있다. 주문 불균형 자체는 이번 가격 자료로 관찰하지 못하므로 인과 원인을 입증하지 않는다. [외부 연구](https://www.mdpi.com/1911-8074/19/9/692)의 BTC 08:00/20:00 UTC, 전날 같은 세션 수익률 반대 방향을 사용한다. 그 논문은 여러 규칙/시간대를 검색했고 선택 후 우위의 통계적 불확실성을 보고했다. 따라서 규칙 선정 배경일 뿐 검증된 수익 전략으로 취급하지 않는다. 이번에는 시간대·방향·기간을 추가 검색하지 않는다.

## 고정 규칙

- BTCUSDC, 평가 2024-09-01 00:00~2026-09-01 00:00 UTC 미만. 이미 본 자료이며 새 검증 표본이 아니다.
- 세션 시작 b=매일 08:00 또는 20:00 UTC. 이전 동일 세션은 b−24시간~b−12시간이다. 그 구간 경계 직전 1분봉 종가 두 개의 수익률 부호를 반대로 취한다. 직전 12시간의 수익률과 혼동하지 않는다. 정확히 0이면 거래하지 않는다.
- 신호 가용 시각 b, 진입은 b+1분 시가에 시장가 비용 적용, 종료는 b+12시간 시가. 평가 종료를 넘는 세션은 시작하지 않는다. 하루 시간대·요일·추가 임계값을 탐색하지 않는다.
- 우선 손절 없는 각 세션의 방향별 가격 손익·실제 펀딩·비용을 분리해 bps 단위로 계산한다. 이 계산은 계좌 수익이 아니다. 동일 시각 상시 매수 대조를 함께 보고한다.
- 계좌화는 후보 R/R과 동일 시각 LONG 대조 각각 기본/스트레스, OHLC/OLHC 경로 = 8계좌로 제한한다. 현금 대조는 운영비 전 0이다. 경로 두 개는 가정이며 독립 표본이 아니다.
- 위험: 최초 1,000 USDC, 거래당 계획손실 0.25%, 총 계획위험 0.5%, 명목노출 상한 1배, 일손실 중단 1%, 고점 대비 경고 2.5%(이후 신규 거래 위험 절반), 중단 4%(실험 종료까지 자동 재개 없음). 중단 4%와 사용자 선호 5% 사이의 1%p는 임시 실행 여유이며 갭 상한의 보장이 아니다. 실제 측정 낙폭이 5%를 초과하면 위험 부적합이다.
- 초기 가격 손절은 b에 완료된 4시간 ATR(14)의 3배. 이 손절과 계좌 위험은 문헌 전략에 추가한 실행 제약이다. 원 논문의 직접 복제라고 부르지 않는다. 최소/단위 0.001 BTC, 최소 명목 50 USDC, 가격 단위 0.1 USDC는 기존 연구 가정이다.
- 매 세션 종료 b+12시간에 중립 신호로 청산, 다음 세션의 b+1분까지 1분 현금. 가격 손절 뒤 같은 세션 재진입 없음. 펀딩은 기존 엔진과 같이 정산시각 이상 최초 분봉 시가에서 주문 판단 전에 처리한다.
- 편도 사용자 수수료 2.5bp, 가격 불리함 기본 2bp/스트레스 5bp, 실제 부호 있는 펀딩 + 스트레스 정산당 1bp. 메이커 무료 가정 없음.
- 운영비는 미정. 운영비 전 계좌 결과와 동일 경로 기준 월 손익분기 허용액을 보고하며, 사후 비용 차감 결과를 운영비 통합 계좌 검증이라고 부르지 않는다.

## 판정과 중단

세션당 순기대손익, 계좌 순익, 수수료/펀딩, 최대 낙폭, 월/연도별 손익, 미회복, 집중도를 공개한다. 양 비용의 순익이 양수이고 최대 낙폭 5% 이내인 경우에만 추가 검증 후보로 남긴다. 이는 필요조건이며 최종 채택 기준이 아니다. 운영비·미관측 자료·수익 규모가 미확정이므로 바로 채택하거나 조합하지 않는다. 전체 기간에 묻히는 악화를 확인하기 위해 2026년 1~8월도 별도 표시하지만 독립 검증이라고 부르지 않는다.

거래 기대손익은 28일 순환 블록, 2,000회, seed=19092026의 탐색 구간을 표시한다. 자료 재사용과 문헌 내 선택편향을 제거한 통계가 아니다. 인과성·독립 원장 검산·입력 해시 실패 시 남은 계좌를 중단하고 실패를 보존한다. 불리한 결과 뒤 다른 시간대나 레버리지로 재검색하지 않는다. 실주문·예약 변경 없음.
