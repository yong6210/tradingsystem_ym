# E025 기존 구현의 동일 수수료 재평가

2026-09-19. 최신 사용자 요청에 따라 공통 6개를 먼저, 기존 보완 구현과 대조를 다음으로 실행한다. 기존 비용 재실행 보류 결정보다 이번 요청이 우선한다. 이미 본 2024-09-01~2026-09-01 미만 730일 자료의 회고 비교다.

공통 T0/T1/T2/B0/R0/F0, 후속 S04/S05/S02/S08/S06A/S09F/S09B/S09FB/C4/P4/C15/P15/S07_FADE/S07_CONTINUE로 고정한다. 총 20개 구현에는 대조·변형이 포함되며 독립 수익 원리 20개나 전체 연구 범위를 뜻하지 않는다. 조건별 2회, 총 40계좌. 최초 1,000 USDC, 원래 구현의 위험·출구·시계·최소 주문 규칙을 유지한다. 수수료만 체결당 2.5bp로 변경하고 기본 슬리피지 2bp/추가 펀딩 0bp, 스트레스 슬리피지 5bp/추가 펀딩 1bp는 유지한다. 원본 실제 부호 있는 펀딩을 반영한다. 운영비는 미정이다.

원래 E005~E013 공통 실행기를 사용해 비용 변경과 엔진 변경을 섞지 않는다. 해당 DD는 그 엔진의 관측 방식이며 실제 틱 최대 DD가 아니다. T0 새 원장/거래/일별/거절은 E024와 대조한다. 기존 소스·증거 해시를 검증하고 원장 Decimal 재계산과 730일 종가 검산을 모든 새 계좌와 참조 계좌에 적용한다. 실패 시 중단하며 결과에 따른 파라미터·후보 추가가 없다.

수익·연도별 성과·거래수·수수료·펀딩·명목 노출 외에 종가 고점 미회복, 종료 때 미회복 여부, 최악 월, 수익 거래 이익 대비 상위 1/5/10 거래 비중을 보고한다. 상위 거래 산술 차감은 제거 재백테스트가 아니다. T0 대비 같은 날짜 손실 중첩·일수익 상관·양쪽이 실제 보유한 날짜의 손실 중첩과 28일 블록 2,000회 탐색 구간을 계산한다. 중단 후 현금 날짜를 버리지 않으며 전체 달력과 공동 보유 날짜를 함께 보고한다.

후속 검토의 최소 필요조건은 기존 선별과 같은 양 비용 양수·양 비용 중단 없음·양 비용 최소 100주기·스트레스 2025/2026 양수다. 이것은 충분조건이나 신규 확증 문턱이 아니다. 보완 후보는 추가로 스트레스 회복 기간과 상위5 수익 집중도 개선 여부를 공개한다. 수치상 개선과 통계적 추가 가치를 구분한다. 원래 비교군에 대한 증분 구간도 함께 남긴다. 다중 연구 선택을 보정하지 않은 구간으로 채택하지 않는다.

근거 부족 시 결합은 실행하지 않는다. 자금 분할로 생기는 최소 수량·신호 충돌·공유 중단을 반영하지 않은 가중 평균을 실행 가능한 조합 성과로 부르지 않는다. 전진 수익성 검증과 실운용은 별도 적격성 단계이며 짧은 E022 관측 결과의 유무로 대체하지 않는다.
