## 2. 당장 중단하거나 보존할 것

- E047까지의 원본·실패·검산·소스 해시는 보존한다. 기존 양수 결과도 지우지 않는다.
- E048은 비교 명세 초안만 있고 실행 스크립트·결과가 없다. **방법 재설계에 따라 실행 보류**한다. 이미 검증한 결과로 세지 않는다.
- 실패 후 같은 자료에서 방향·문턱·보유·위험 배수를 바꾸거나 무관한 지표를 차례로 추가하는 연구를 멈춘다.
- 새 가설은 동시에 최대 2개까지 준비한다. 이는 연구 범위 관리값이고 통계적 검증 기준이나 사용자 수익 목표가 아니다.
- 연구 재설계가 실주문·새 예약·유료 자료·운용 범위 확대를 뜻하지 않는다. 기존 운영/예약 설정은 이번에 변경하지 않는다.

## 3. 먼저 하나의 질문을 명세한다

[질문 명세 양식](RESEARCH_QUESTION_TEMPLATE_V2.md)을 사용한다. 핵심은 **어떤 정보가 어떤 거래 기회에서 비용 이상의 이익을 만드는가, 적절한 대조와 무엇이 다른가**다.

다음 항목이 비어 있으면 수익 결과를 산출하는 새 실험을 시작하지 않는다.

1. 경제적 설명: 누가 왜 거래 압력이나 현금흐름을 만드는지, 그 효과가 왜 즉시 사라지지 않을 수 있는지. 확인된 사실·외부 연구·우리의 추측을 구별한다. 논문 제목이나 지표 이름만으로 수익 근거를 대신하지 않는다.
2. 관측 가능성: 당시 공개 시각, 완료/확정 기준, 수정 이력과 지연, 필요한 원본. 확보 불가능한 입력은 먼저 적격성을 판정한다.
3. 완결된 정책: 진입·보유·손절·청산·휴지·비용·주문 단위. 수익 원리가 긴 보유나 비대칭 청산에 있다면 그 정책을 평가한다. 임의의 짧은 고정 보유 사건 평균만으로 전략 전체를 기각하지 않는다.
4. 대조: 같은 달력과 비교 가능한 비용/위험을 갖춘 단순 기준. 현금과 관련 단순 정책의 역할을 구별하고, 실제 노출이 다르면 추가 예측력을 분리했다고 주장하지 않는다.
5. 판정: 주 지표, 필요한 표본의 단위와 관찰 기간, 실패·자료 부족·추가 확인의 구분. 모든 전략에 일률적인 20/100거래 조건을 소급하지 않는다.
6. 시도 수: 가설·모델·예정 변형·비용/지연 민감도와 총 실행 범위를 결과 전에 고정한다. 수정 이유와 중단한 시도도 누적 기록한다. 사전 기록만으로 반복 탐색의 선택 편향이 없어지는 것은 아니다.

## 4. 정보 가치와 계좌 실행을 분리하고 다시 연결한다

**정보/정책 진단:** 신호와 완결된 보유·청산 정책의 비용 후 성과를 적절한 대조와 비교한다. 가상 단위 명목 결과라면 그렇게 표시하고 계좌 수익으로 바꾸어 부르지 않는다. 단순 사건 수익은 보조 진단으로 사용하며 질문과 다른 보유 길이를 기계적 탈락 관문으로 쓰지 않는다. 순익 감소를 동반한 낮은 상관·적은 손실 횟수·높은 승률만으로 통과시키지 않는다.

**실행 가능성 진단:** 같은 정책을 1,000 USDC와 최소 주문·현금·수수료·펀딩·체결 지연·운영비에 연결한다. 기회 중 실제 승인/거절과 위험 사용량을 기록한다. 실패를 정보/정책 손실, 최소 주문 불가, 비용 부담, 실행 모델/자료 미비로 구분한다. 전체 순익을 비용 후에 단순 조정하지 않고 계좌 경로에 필요한 비용은 경로 안에서 반영한다.

**위험 설계:** 손실 정의와 손절 정책을 기준으로 예산·중단 여유를 결과 전에 정한다. 관측 결과를 5%에 맞추려고 사후 배수를 조정하지 않는다. 5%는 손실 선호이지 시장 갭과 비용까지 보장되는 절대 한도가 아니다. 이미 취소한 T0 동일 노출 진단이나 종료한 위험 배수 실험은 이 원칙을 이유로 자동 재개하지 않는다.

## 5. 이미 본 자료와 앞으로 볼 자료를 구별한다

- 반복 사용한 2024-09-01~2026-09-01 미만 730일 가격 표본은 **탐색/진단용**이다. 새 지표를 붙이거나 다시 나눠도 독립 검증 표본이 되지 않는다.
- 다른 날짜도 파일을 새로 받았다는 이유로 미사용 표본으로 간주하지 않는다. 과거 프로젝트/실험에서의 사용 여부를 확인할 수 없으면 ‘노출 여부 미확인’이다.
- 독립 평가를 계획할 때는 후보 코드·규칙·비용·위험·대조·평가 종료 조건을 먼저 고정하고 해시를 남긴다. 명확한 미사용 과거 자료가 없다면 **그 고정 시각 이후 실제 발생한 시장 자료**를 전진 관측한다.
- 이번 연구 절차 문서의 작성 시각은 후보 규칙 고정 시각이 아니다. 아직 고정 후보·전진 관측 기간·신규 수집 일정은 정하지 않았다.
- 관측 중에는 성과를 보고 규칙이나 종료 시점을 바꾸지 않는다. 구현 결함으로 바꾸면 버전을 분리하고 이전 결과와 새 버전의 검증 지위를 명시한다. 짧은 관측은 연결/체결 동작 확인과 수익성 판단을 구별한다.

## 6. 다음 작업과 종료 조건

현재 다음 작업은 **사용자 기준 반영 → 기존 자료의 노출 범위·가설 이력 요약 → 근거 있는 질문 최대 2개 명세**다. E048 전체 비교나 새 지표 다운로드를 자동으로 실행하지 않는다. 기존 기록에서 질문 선정에 꼭 필요한 사실만 재사용하며, 필요성을 설명할 수 없는 진단은 늘리지 않는다.

명세가 완성된 질문만 별도 실행 등록으로 진행한다. 정보 부족은 자료 문제로, 비용 후 음수는 해당 정책의 경제성 실패로, 최소 주문 거절은 실행 제약으로 기록한다. 충분한 순익과 손실 조건의 근거가 없으면 결합·운영 기능 확대·실운용 준비를 성과로 대신하지 않는다. 목표/비용 미정은 질문으로 남기고 임의의 달성 기준으로 메우지 않는다.

결과가 좋으면 제한과 함께 다음 단계로, 나쁘면 고정 가설을 종료한다. 수익이 나올 때까지 같은 표본에서 변형을 반복하는 종료 조건은 두지 않는다.
