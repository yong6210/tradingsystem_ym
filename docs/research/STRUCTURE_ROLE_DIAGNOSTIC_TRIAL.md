# 현재 이동과 외곽 구조의 역할 진단 — 사전 명세

2026-09-20. 기존 판단식을 수정하지 않는 오프라인 진단이다. 사용자 원칙이나 채택 전략이 아니다. 8월 4일 검토에서 관측한 국소 상승과 외곽 하락의 충돌을 다른 기존 사례에도 같은 조건으로 기록한다.

## 고정 입력과 범위

기존 여섯 날짜 진입 심사 결과의 모든 시점과 기준 갱신 결과의 원래 아홉 시점을 사용한다. 날짜·초기 보유·채택 상태·8/16일 이력·15/60/240분 구조 추출은 유지한다. 사후 사례 라벨은 설명용이다. 새 후보를 찾기 위해 기간을 늘리지 않는다.

## 진단 조건

1. 각 이력에서 활성 구조 중 동일 방향·동일 세 가격은 중복으로 취급한다. 중복을 두 개의 독립 지지로 세지 않는다.
2. 서로 다른 관찰 창의 구조 A와 B가 동일 방향이고, A의 이전 반응이 B보다 먼저 형성됐고, B의 보호 가격이 A보다 나중에 형성됐고, B의 세 가격이 A의 당시 알려진 범위 안에 있으면 ‘동일 방향 연결’로 기록한다. **A가 다른 모든 구조를 포함해야 한다는 기존 주된 기준 조건은 이 진단 항목에만 요구하지 않는다.**
3. A와 B의 창·방향·형성 시각·각 가격의 형성/가용 시각이 두 이력에서 동일해야 공통 연결로 기록한다. 한쪽에서만 존재하면 이력별 관측에만 남긴다. 방향 부호만 같으면 합의로 취급하지 않는다.
4. 각 이력의 모든 활성 반대 구조를 별도 기록한다. 그중 A보다 이전 반응이 먼저이고 A의 세 가격을 포함하면 ‘외곽 반대 구조’로 표시한다. 서로 다른 창이라는 이유로 자동 외곽 판정을 하지 않는다. 반대 구조를 삭제하거나 오래됐다는 이유만으로 무효화하지 않는다.
5. 같은 시점에 양방향 연결이 있으면 양쪽을 기록한다. 하나를 우승 방향으로 고르지 않는다. 연결 없음·자료 부족은 진단 없음이지 반대 승인이나 보유 지시가 아니다.

## 후속 검토와 금지

각 공통 연결의 최초 관측부터 해당 사례의 원래 종료까지, 두 구조의 원래 관찰 창에서 보호 가격을 처음 종가 이탈하는 시각을 별도로 확인한다. 미래 사건은 후속 관찰 필드에만 저장하며 당시 연결 판정에 넣지 않는다. 종료까지 이탈이 없으면 ‘관찰 종료까지 없음’으로만 표시하고 성공·전환 확정으로 부르지 않는다. 가격 목표·수량·수익을 계산하지 않는다.

원본 봉의 시각·가용성, 두 이력 합의, 기존 방향 출력 불변, 처음/끝 및 첫 공통·외곽 충돌 시점의 미래 제거 재계산을 확인한다. 같은 자료에 대한 여러 연결은 독립 거래 표본이 아니다.

완료 기준은 최근 동일 방향 연결의 존재, 외곽 반대 근거, 기존 판단과의 차이, 이후 빠른 국소 실패를 함께 설명하는 것이다. 연결이 많아지거나 롱을 만들었다는 이유로 방향 규칙을 채택하지 않는다. 반등에서도 동일 진단이 나타나거나 빠르게 실패하면 이 조건만으로 주된 전환을 정할 수 없다는 제한을 남긴다.
