# 8월 11일 반등 — 기준 생존·현재 지지·진입 조건 분리

**기준이 살아 있는 것, 현재 방향이 지지되는 것, 신규 진입이 가능한 것은 서로 다른 상태였다.** 기존 시험 규칙에서는 03:15~16:00에 이 구분이 일관되게 적용됐다. 현재 롱 지지가 있을 때 새 롱 반응이 없었고, 롱 반응이 나타났을 때는 현재 지지가 없어 모두 진입 대기였다.

[시간순 전체 판단표](../../reports/validation/rebound_state_sequence_20260920/review.md), [당시 구조·반응·원본 검산 기록](../../reports/validation/rebound_state_sequence_20260920/review.json), [이전 역할 대조](STRUCTURE_ROLE_DIAGNOSTIC_RESULTS.md)를 연결했다. 규칙을 변경하거나 가정 체결을 추가하지 않았다. 이후 하락을 알고 당시 롱 지지를 오답으로 바꾸지도 않았다.

## 고정한 범위와 보유

2026-08-11 03:15~16:00 UTC를 검토했다. 그날 00:00의 기존 상태에서 연속 재생했으며 8일·16일 이력과 기존 심사 시점을 유지했다. 새 기준을 03:15에 임의로 채택하지 않았다.

초기 채택 기준은 4시간 롱 보호 저점 63,788.1이다. 당시 이 기준은 살아 있었지만 00:00에는 공통 후속 지지가 없었다. 계좌 입력은 전 구간 수량 0, 평단 없음, 실현손익 0, 자금·여력 1,000 USDC다. ‘기준 유지’는 롱 물량을 계속 보유하라는 뜻이 아니다.

## 13:45에 드러난 정책 경계

09:00의 지지 63,958은 11:15에 최신 지지 64,120.3으로 교체됐다. 13:45에는 새 가격만 이탈했으며 이전 가격은 14:30에야 이탈했다. 하지만 현재 구조 추출은 각 관찰 창의 최신 후보 하나를 전달하므로 이전 지지를 자동 복원하지 않는다.

이는 데이터 누락이나 최신 가격 비교 오류가 아니다. **‘현재 지지’에 교체된 옛 구조를 포함할 것인가라는 시험 정책**이다. 옛 지지를 되살리면 13:45~14:30의 방향 표시가 달라질 가능성은 있지만, 그것만으로 더 타당한 시장 판단이라는 근거는 없다. 이번에는 자동 복원을 추가하지 않는다. 옛 지지 보존을 비교하려면 별도 명세·반례·기존 사례 재검토가 필요하다.

또한 롱 방향 지지 구간의 반대 반응을 단순히 버린 것이 아니라 방향과 충돌하는 정보로 보존했다. 반대 반응 한 번으로 기존 주된 기준을 무효화하거나 반대 진입을 승인하지 않았다.

## 결정과 다음 순서

이번 구간에서는 기존 상태 전이와 진입 대기 사이의 모순을 찾지 못했다. 따라서 **판단 코드를 수정하지 않고 현재 시험 규칙을 유지**한다. 이는 U1의 일반적인 주된 이동 선정이 검증됐다는 뜻은 아니다. 초기 계보·외곽 구조의 역할·교체 지지 복원 여부는 계속 미정으로 남긴다.

U1의 현재 동작과 한계를 기록했으므로, 같은 방향 시험식을 더 늘리는 대신 다음은 예정된 **U2 중요 구간·목표 선정**을 검토한다. 고정 대상은 이미 사용한 8월 16일 16:09 후보의 구조 목표 62,966.6과 이전 계좌의 거래량 구간 Z01 상단 62,900이다. 당시 가용 자료에서 각각 무엇이 확인됐고 왜 목표 후보인지 비교하며, 이후 수익이 좋은 가격으로 교체하지 않는다. 목표가 가까워 비용을 감당할 수 있다는 계산과 목표의 시장 중요성을 구별한다. U1 미정을 해결한 것으로 취급하거나 운영 연결을 시작하지 않는다.

## 검증 범위

새 감사 스크립트는 기존 결과를 동일 초기 상태에서 재생해 모든 심사 결과와 대조했다. 상태·지지 교체·반응 사건마다 미래 분봉을 제거한 전체 앞부분 재계산도 일치했다. 별도로 원본 압축 분봉을 읽어 연속성과 실제 종가, 최신/이전 지지의 첫 이탈 시각을 검산했다. 방향과 같은 방향 반응의 동시 충족이 없다는 사실도 전체 검토 시점에서 확인했다.

```sh
.venv/bin/python scripts/review_rebound_state_sequence.py
```

이 검증은 기존 규칙의 재현성과 사건 설명 확인이다. 가정 수익·보유 종료 정책·실거래 가능성을 평가한 것이 아니다. 3·4단계는 미완료이며 5·6단계는 보류한다.
