# 새 수익 가설의 표본 계획 — 방법 v2 추가 기준

2026-09-19. [Q006](experiments/Q006_RESULTS_2026_09_19.md)의 표본 계획 진단을 반영한다. 동결된 정책이나 운용 설정을 수정하지 않는 연구 기준이다.

새 후보는 구현 전에 다음을 질문 명세에 포함한다.

1. 비용·최소 주문·계좌 제약을 고려했을 때 어느 정도의 이익을 검증하려는가. 사용자 수익 목표가 미정이면 임의의 목표를 확정하지 않고 규모를 변수 또는 명시된 연구 참조로 둔다.
2. 정해진 관찰 기간에 거래 기회가 어느 정도 생길 근거가 있는가. 과거 빈도, 군집, 누락 가능성을 구분하며 과거 비율을 미래 보장으로 쓰지 않는다.
3. 거래 손익의 변동과 자기상관, 선택 과정에 비추어 그 기간에 무엇을 판단할 수 있는가. 기술 연결 확인, 큰 예측 오차의 발견, 소규모 양의 순익 입증은 서로 필요한 정보량이 다르다.
4. 자료가 부족하면 어떻게 종료하는가. 미판정도 정상 종료이며 좋은 결과가 나올 때까지 관측을 연장하지 않는다. 모든 전략에 동일한 최소 거래 수를 일률 적용하지 않는다.

이익 여유는 작고 기회가 드물어 현실적인 기간에 필요한 근거를 얻기 어려운 질문이라면, 먼저 질문·자료·경제적 근거를 재검토한다. 표본 수를 늘리려는 문턱 완화, 위험 증대, 서로 의존하는 거래를 독립 표본으로 세는 방법으로 해결하지 않는다. 이런 구현을 또 시작하기 전에 실패 가능성을 판단한다.

Q004의 90일은 등록 당시부터 예측/사건 진단이며 확증 기간이 아니었다. 이번 기준으로 모델·H/2H·비용·종료일을 바꾸지 않는다. 기존 첫 예측도 보존한다. Q006은 IID 표준오차의 계획 규모를 비교했을 뿐, 앞으로의 신뢰구간·검정력·필요 기간을 계산한 것이 아니다.

현재 Q004의 다음 새 증거는 목표 종료 뒤 실제 가격·펀딩이다. 현 시점 수익성·5% 손실 선호는 미검증이며, 캐리 실행 자료 불충분과 E048 보류도 유지한다. 이 추가 기준을 이유로 새로운 모델군·변형 탐색·예약·실운용을 자동 실행하지 않는다.
