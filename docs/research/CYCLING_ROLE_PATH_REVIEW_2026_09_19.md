# 같은 방향의 축소·재추가·재축소를 연속 장부로 연결

이전 비교는 각 시점에 독립적인 보유 가정을 놓았다. 이번에는 실제 관찰 세 시각에 명시적인 가정 행동을 붙이고 잔량·평단·실현손익·비용을 다음 단계로 계속 넘겼다. 결과는 `reports/validation/cycling_role_examples_20260919/paths.md`와 `paths.json`이다.

## 시간순 흐름

초기 롱 0.2 BTC·평단 63,050을 이미 보유했다고 가정한다. 실제 초기 진입 이력을 재현한 것은 아니다. 주된 롱 방향도 가정이며 시장 자료로 확정하지 않았다.

1. 8월 15일 09:28 UTC: Z01 상단 위로 마감. 추가 물량을 덜어낼 되돌림으로 판단했다고 가정해 총수량 절반인 0.1을 축소한다. 본절 전이므로 실현손실이 발생해도 원장에 그대로 남긴다.
2. 17:55: 새 저점 후보 62,971 접촉 후 위 마감. 여기서 재추가를 승인한다고 가정한 경로와 보류한다고 가정한 경로를 나눈다. 위쪽 1.8 USDC 마감이 충분한 추가 근거라는 규칙을 채택하지 않았다.
3. 8월 16일 22:56: 같은 Z01에 아래에서 접근해 아래 마감. 반등에서 다시 축소하기로 판단했다고 가정한다. 국소 역할 변화만으로 숏 전환하지 않는다.

| 경로 | 수량 변화 BTC | 마지막 평단 | 최종 누적 비용 | 마지막 전체 순손익 |
| --- | --- | ---: | ---: | ---: |
| 재추가 가정 | 0.2 → 0.1 → 0.2 → 0.1 | 63,019.30 | 12.59 | −84.53 |
| 재추가 보류 가정 | 0.2 → 0.1 → 0.1 → 0.05 | 63,050.00 | 8.81 | −56.00 |

계좌 초기값 10,000 USDC, 초기 진입 비용 5.044, 편도 수수료 4bp·반스프레드 0.5bp·슬리피지 2bp·펀딩 0 가정이다. 관찰 종가 주변의 즉시 계산상 체결이며 실제 호가·부분 체결·유동성을 반영하지 않는다. 보유 기간 실제 펀딩도 반영하지 않았으므로 역사적 백테스트 성과가 아니다.

두 경로의 잔량·위험이 다르다. 손익 숫자로 재추가 보류 전략이 우월하다고 판정하지 않는다. 이 사례에서 평단이 낮아졌더라도 늘린 수량이 이후 하락에 더 노출됐다는 산식상의 차이를 보여준다.

## 중요한 구분

초기 절반 축소에서 발생한 손실을 재추가할 때 지우지 않았다. 같은 종목·같은 방향을 유지하면서 수량만 순환한다. 마지막에도 당시 총수량의 절반을 줄이므로 보류 경로의 축소량은 0.05다. 새 봉마다 자동으로 절반씩 줄인 것이 아니라 별도 되돌림 판단을 가정한 것이다.

실제 자료는 가격·접촉·확인 시각을 제공한다. 행동을 실행할 만큼 충분한 근거인지는 아직 미확정이다. 이번 경로를 새 매매 규칙이나 실제 체결 이력으로 사용하지 않는다. 약손절 수량·발동 기준도 여전히 별도다.

## 검증

신규 테스트 4개 통과: 이전 실현손실 이월과 당시 총수량 절반, 대기 경로의 실제 잔량 기준 축소, 미래 근거·시간 역전 거부, 후속 단계가 이전 기록을 바꾸지 않음. 최초 테스트의 작은 가격 예시는 $3,000 스트레스 가격을 음수로 만들므로 검사 자료를 양의 가격 범위로 수정한 뒤 통과했다.

실제 두 경로의 모든 단계는 매수·매도 현금 흐름과 최종 재고 평가를 별도로 계산해 원장 총손익과 대조했다. 입력·코드 해시를 기록했다. 실주문 0건이며 기존 실험 결과는 변경하지 않았다.

남은 의사결정의 중심은 17:55의 재추가가 충분한 근거를 가졌는지와 두 축소 시점의 발동 판단이다. 다음에는 해당 후보가 기존 노출을 늘릴 만큼 새로운 정보를 제공했는지, 그 시점에 알려진 다음 저항까지의 공간과 비용·여력을 함께 검토한다.
