# 같은 방향 순환매 — 통합 판단 명세 초안

후속 [통합 판단 시험 v1](CYCLING_DECISION_TRIAL_V1_2026_09_19.md)이 현재 실행 초안이다. 이 문서는 원칙과 이전 검토의 배경을 보존한다. 산발적으로 늘어난 관찰을 방향·보유 상태·자리·여력에 연결한다. **사용자 확정 원칙**, **검토용 설계 제안**, **미확정 판단 기준**을 구분한다. 명세 작성이 실거래 구현 완료나 수익성 검증을 뜻하지 않는다.

실제 충돌 사례: `reports/validation/cycling_decision_spec_cases_20260919/cases.md`. 기존 자료의 네 시각을 설명 목적으로 골랐으며 새 검증 표본이 아니다.

## 1. 사용자 확정 원칙

- 주된 방향이 롱이면 롱, 숏이면 숏으로 진입·추가·축소·재진입을 운용한다. 반대 방향 진입은 추세 전환이 확인된 경우에만 검토한다.
- 4시간봉은 예시이며 유일하거나 필수인 방향 기준이 아니다. 짧은 반대 반응을 주된 추세 전환으로 대체하지 않는다.
- 추가 물량은 평단 조정과 순환을 위한 물량이다. 되돌림 축소를 결정하면 **축소 직전 총 보유 수량의 최소 절반**을 덜어낸다. 추가분만의 절반이 아니다.
- 전체 본절을 기다려야만 덜 수 있는 것은 아니다. 잔여 포지션 본절과 전체 운용 회복 가격은 구분한다.
- BTC 가격 $2,000~3,000 역행은 고려할 가격 움직임이며 고정 손절·무조건 버티기 규칙이 아니다.
- 수량을 임의의 고정 비율로 정하지 않는다. 자리, 추가 후 노출·손실, 남은 여력과 체결 가능량을 함께 검토한다.
- 평단이 좋아졌다는 이유만으로 추가를 정당화하지 않는다. 이후에 생긴 매물대나 무너진 근거로 과거 주문을 설명하지 않는다.

## 2. 판단 입력 — 설계 제안

한 판단 시각에 아래 입력을 모은다. 숫자가 없거나 판단되지 않은 상태는 명시적으로 `unknown`으로 남긴다. 이를 0, 횡보, 방향 전환으로 바꾸지 않는다.

| 입력 | 기록 내용 | 현재 상태 |
| --- | --- | --- |
| 주된 방향 | 방향, 근거, 판단 시점, 유지/약화/전환 구분, 무효화 조건 | 생성·승인 기준 미확정 |
| 실제 보유 | 방향·총수량·평단·실현손익·비용·추가/축소 이력 | 독립 연구 장부 있음. 이번 사례는 가정 |
| 시장 자리 | 매물대 구간, 구조 가격, 버전·출처·확인 시각 | 관찰 구현. 중요도 선정 미확정 |
| 반응 | 접촉·회복·재접근·재이탈, 같은 봉/가격의 중복 출처 | 관찰 구현. 충분한 확인 기준 미확정 |
| 대응 여력 | 사용 가능 증거금, 추가 후 노출·역행 시 손익, 예상 체결 비용 | 예시 산식 있음. 실제 계좌 대사 미연결 |
| 주문 상태 | 미체결·취소 중·누적 체결·오류·재시작 대사 | 과거 연구용 모듈 있음. 최신 판단과 미연결 |

구조 가격은 매물대와 다르다. 다른 시간봉이 같은 가격·같은 봉을 관찰해도 독립 근거 수를 늘리지 않는다. 같은 봉에 가까운 가격 여러 개가 있어도 중요도가 자동으로 높아지지 않는다.

## 3. 행동 후보 — 설계 제안

| 상황 | 검토할 행동 | 반드시 구별할 것 | 아직 없는 결정 기준 |
| --- | --- | --- | --- |
| 무포지션, 주된 방향 유효 | 같은 방향 최초 진입 또는 대기 | 방향과 타점을 한 접촉 신호로 동시에 정하지 않음 | 유리한 자리·반응의 충분성 |
| 보유 중 역행 | 같은 방향 추가·대기·노출 축소 각각 비교 | 현재 손실과 새 추가 근거는 별개 | 새로운 반응·적정 수량·여력 한도 |
| 추가 후 유리한 되돌림 | 총수량 최소 절반 축소 후보 | 전체 본절 도달은 필수 조건 아님 | 어느 반응에서 되돌림 축소를 발동할지 |
| 축소 후 재접근 | 같은 방향 재진입 후보 | 축소했다는 사실이 새 시장 근거를 만들지는 않음 | 기존 반응 반복과 재사용 가능한 새 반응의 차이 |
| 해당 자리 이탈 | 그 자리에 의존한 추가 근거 재평가, 대기·축소·약손절 검토 | 국소 근거 무효화와 전체 방향 전환은 별개 | 약손절 발동·수량 |
| 실제 추세 전환 확인 | 기존 포지션 정리 후 반대 방향의 별도 자리 검토 | 부분 체결 상태에서 반대 신규를 먼저 하지 않음 | 추세 전환 확정 기준 |
| 자료·보유·주문 불일치 | 대사·복구 절차 | 시장 방향 불명과 실행 상태 불명은 별개 | 실제 거래소 복구 연결 |

위 표는 자동 실행 규칙이 아니다. 특히 약손절 수량이나 정상 운용 중 전량 종료 조건을 빈칸에 임의로 채우지 않는다. 판단 불가는 자동 보유나 자동 청산 명령이 아니다. 기존 노출 처리 검토와 새 노출 증가 승인은 각각 남는다.

## 4. 충돌 처리 — 제안이며 미확정

검토 순서는 **체결·계좌 상태 확인 → 노출·여력 검토 → 사용 근거의 유효성 → 축소 후보 → 증가 후보**다. 최초 대화의 우선순위 초안을 유지하되 자동 정책으로 승인한 것은 아니다.

- 동일 근거의 유효성이 흔들리는 상황에서 같은 근거로 추가부터 정당화하지 않는다.
- 추가와 축소 후보가 함께 나오면 수량을 상계해 한 주문으로 만들지 않는다. 각 행동의 목적·근거·계좌 효과를 따로 설명한다.
- 되돌림 축소가 결정되면 결정 당시 총수량과 목표 축소량을 고정한다. 부분 체결 이후에는 목표에서 실제 체결량을 빼 잔여량을 계산하는 방식을 제안한다. 봉마다 남은 수량을 다시 절반으로 줄이는 규칙이 아니다.
- 이미 진행 중인 주문은 실제 체결·취소 상태를 확인해야 후속 수량을 계산할 수 있다. 사건 중복 제거만으로 중복 주문 방지가 구현된 것은 아니다.
- 국소 구조 이탈은 그 구조에 의존한 근거를 재검토하게 한다. 추세 전환을 자동 생성하지 않는다.

## 5. 실제 사례가 요구하는 판단 차이

| UTC | 그 시점에 확인한 사실 | 판단에 주는 의미 | 이 사실만으로 정할 수 없는 것 |
| --- | --- | --- | --- |
| 08-15 10:33 | 고점 62,960.4 접촉, 62,944.2 아래 마감 | 추가 롱의 반등 축소 또는 숏 방향 내 저항 반응 검토 | 주된 방향·축소 발동·숏 추가 승인 |
| 08-15 17:55 | 저점 62,971.0 접촉, 62,972.8 위 마감 | 저점 역할 반응 후보. 위쪽 차이는 1.8 | 이 차이가 충분한 확인인지, 롱 추가 여부 |
| 08-15 21:26 | 세 고점 가격을 같은 봉이 넘고 63,051.4 마감. 원본 후보 총 4개 | 해당 저항 유지 근거 재평가. 네 개의 독립 근거가 아님 | 전체 롱 전환·추격 추가·전량 종료 |
| 08-16 01:40 | 두 저점 가격 아래 62,923.9 마감. 원본 후보 총 3개 | 해당 지지의 유지 근거 재평가 | 약손절 수량·전체 숏 전환 |

같은 시각의 여러 가격에 대해 계좌 계산을 반복 합산하지 않았다. 네 시각 × 롱·숏 보유 가정 × 유지·추가·절반 축소 = 24개 독립 비교다. 가정 계좌와 비용은 사례 파일에 명시했다. 이후 차트는 당시 판단의 근거에 넣지 않았다.

## 6. 실행 가능한 기준으로 남겨 둔 다섯 가지 빈칸

재추가 후속 검토: [17:55의 비용 후 공간](READD_ROOM_REVIEW_2026_09_19.md). 가까운 구조 가격에서 종료할 목적이면 가정 왕복 비용을 넘지 못하는 사례를 확인했다. 전체 평단 조정 목적과 구분하며, 먼 목표를 임의로 골라 추가를 정당화하지 않는다.

구간 선정 후속 감사: [상위 다섯 제한의 누락](VOLUME_ZONE_COVERAGE_REVIEW_2026_09_19.md). 역사적 거래량 구간이 순위 제한으로 빠진 사례를 확인했다. 역사적 후보·현재 접근·반응 관찰·주된 방향 핵심 근거를 구분하며, 후보 추가가 방향 승인으로 이어지지는 않는다.

후속 실제 시험: [단일 최근 구조 기준 검토](THESIS_ANCHOR_TRIAL_2026_09_19.md). 좁은 구조의 반복 이탈·회복과 넓은 구조의 양방향 미이탈이 동시에 나타나, 이를 주된 방향 자동 판정식으로 채택하지 않았다.

1. **주된 방향 유지와 실제 전환:** 어느 구조·구간 이력이 유지 판단을 뒷받침하고 무엇이 이를 무효화하는가. 시간봉 투표로 대신하지 않는다.
2. **중요한 구간 선정:** 단순 거래량 비중·최근 고점·저점을 넘어 어떤 구간을 현재 의사결정에 사용할지. 구조 가격과 체결량 구간의 역할도 분리한다.
3. **되돌림 축소 발동:** 최소 절반이라는 수량 원칙은 확정됐지만, 어느 반응에서 실행할지는 미확정이다.
4. **추가·재진입의 새로운 근거:** 같은 구간 재방문을 금지하지 않으면서 과거 반응을 재사용한 반복 진입을 구별해야 한다.
5. **약손절과 실제 대응 여력:** 약손절 조건·수량, 증거금·노출 한도, 미체결 예약과 실제 체결·복구 처리가 필요하다.

이 다섯 항목을 검토하지 않은 상태에서 수익률 최적화나 실거래 연결로 넘어가지 않는다. 이는 현재 작업 순서에 대한 제안이며, 사용자에게 추가 승인을 요구하는 절차는 아니다.

## 7. 완료 범위와 제한

후속 구현: [주된 방향 입력 수정](CYCLING_THESIS_INPUT_2026_09_19.md). 특정 시간봉을 요구하지 않는 명시적 판단 입력을 기존 장부·전환·복원 흐름에 연결했다. 입력 형식 검증이며 자동 시장 판단은 아니다.

완료: 시점별 매물대·구조 관찰, 확인 지연 기록, 이후 최초 접촉, 출처·중복 관계, 보유 상태별 손익·여력 산식, 실제 충돌 사례 네 개의 동결과 출처 해시.

미완료: 실제 시장 방향·자리·발동 조건의 유효성 검증과 자동 행동 선택, 실제 계좌 연동·실주문. 기존 4시간봉 고정 시험 엔진은 최신 사용자 원칙의 완성본이 아니다.

이번 변경은 판단 명세 통합과 기존 결과 추출이다. 새 주문 알고리즘을 추가하지 않았다. 네 사례의 원본 관찰 존재, 같은 봉의 가격·보유 비교 일치, 24개 비교 수, 입력·스크립트 해시를 확인했다. 새로운 전략 수익성 테스트가 통과했다고 주장하지 않는다.
