# 전략 후보 명세와 동등 비교

상태: 후보 설계. 아래 신규 규칙은 미구현이며 수익 우위가 검증되지 않았다. 구체적 수치가 미정인 후보는 실행 등록 불가다. 기존 결과를 보고 숫자를 정하면 사후 선택으로 기록한다.

## 1. 공통 모델 카드

각 버전은 ID, 경제적 가설, 필요한 시장 자료, 특징 산식/준비 구간/가용 시각, 판단 주기, 롱·숏 조건, 신규 진입 금지, 진입 주문/만료, 최초 무효화 가격, 청산 우선순위, 최대 보유, 추가/재진입 조건, 위험 예산, 주 지표, 비용, 반증 조건, 시험 개수를 필수로 가진다. “추세가 강하면”, “적절히 매수” 같은 조건은 등록하지 않는다.

규칙 조건 충족 시 신호 ID를 발급한다. 같은 신호가 반복 판단되어 중복 주문되지 않도록 signal_id/order_intent_id를 연결한다. 판단 주기와 보유기간을 분리한다. 단타·스윙·스캘핑은 시간 스타일이지 서로 독립적인 수익 원리가 아니다.

## 2. 최소 여섯 후보

| ID | 가설과 구체적 규칙 구조 | 청산·관리 | 예상 실패와 검증 대조 |
|---|---|---|---|
| S01 추세 지속 | 완료 4시간 봉 fast EMA > slow EMA, ATR로 나눈 간격 > k, 종가 > fast이면 롱; 숏 대칭 | 최초 ATR 손절, 완료 봉에서만 갱신하는 후행 손절, 시간 만료; 추가 진입 없음 | 횡보 손절 반복; 동일 방향 노출의 단순 보유 및 무작위 시점 대조 |
| S02 채널 돌파 | 완료 1시간 종가 > 직전 N봉 최고가 + k×ATR; 숏은 최저가 아래. 현재 봉을 채널에서 제외 | 최초 손절, 후행 손절 또는 사전 고정 반대 채널 청산; 두 방식 별도 버전 | 가짜 돌파/갭; 거래량 필터 유무를 독립 실험 |
| S03 추세 눌림 | 완료 4시간 추세 방향과 같은 쪽만; 15분 종가 EMA 이격이 기준을 넘고 별도 반전 확인 조건 충족 | 최초 손절, 고정 목표/시간 만료; 분할 추가 없음 | 추세 전환을 눌림으로 오인; 추세 조건만 있는 대조와 비교 |
| S04 범위 회귀 | 완료 4시간 ER < 한도, 완료 15분 z-score가 경계 초과; 롱/숏 대칭 | 평균 회복 또는 최초 손절 또는 만료; 목표를 손실 확대 방향으로 이동 금지 | 범위 붕괴; E001의 기존 inventory v2와 동일 진입이면 독립 새 신호로 세지 않음 |
| S05 반등 확인 후 회귀 | S04 조건에서 즉시 주문하지 않고 이후 완료 봉이 사전 등록 회복 경계를 재통과해야 신호. 대기 중 무효화/기한 초과 시 취소 | 최초 무효화 가격 고정, 평균 회복 청산; 재진입은 새 확인 필요 | 반등 지연·좋은 가격 상실; 같은 사건의 즉시 진입과 확인 후 진입 비교 |
| S06 단기 유동성 회복 | 스프레드·호가 불균형·공격 체결 흐름으로 단기 가격 압력/회복 가설 정의 | 짧은 주문 만료·재고 상한·시간 청산 | 역선택/대기열/지연; 현재 분봉으로 검증 불가, 호가·체결 자료 확보 전 보류 |

S01~S05의 EMA 기간, k, ER/z 경계, 회복 경계, 손절 거리, 최대 보유시간은 후보 등록 때 경제적 이유와 함께 한 세트씩 고정한다. 이 문서는 이미 최적 수치를 발견했다는 주장이 아니다. 기존 EMA/채널/평균회귀 구현의 수치는 역사적 기준 버전으로 보존하며 신규 제안과 혼합하지 않는다.

## 3. 순환매는 별도 재고 관리 축

동일한 적격 진입 목록 위에 M0 단일 진입, M1 제한 분할, M2 부분 익절 후 재충전을 적용한다. S04와 M2를 같은 의미로 부르지 않는다. 가격 신호와 물량 관리의 기여를 따로 측정한다.

- 공통: cycle_id별 최초 무효화 가격·최대 수량·최대 손실 예산·만료 시각을 고정한다. 손실이 커졌다는 이유로 한도를 늘리지 않는다.
- M0: 최초 수량 이후 추가 없음. 부분 청산 없는 단순 기준을 먼저 측정한다.
- M1: 사전 가격 단계별 추가 슬롯. 동시에 살아 있는 주문까지 포함해 위험 예약. 평균단가가 내려갔다고 최초 손절을 멀리 옮기지 않는다.
- M2: M1에 이익 실현 슬롯을 분리. 실제 부분 매도 체결이 있어야 재충전 가능 수량이 생긴다. 미체결 익절 주문을 매도 완료로 간주하지 않는다. 재충전 시점의 잔여 위험/순환 횟수/누적 비용/만료를 다시 검사한다.
- 롱·숏 반전: 기존 주기 종료와 주문 취소 확인 뒤 새 주기. 다른 전략의 반대 의도는 포트폴리오가 처리한다.
- 비교: 같은 최대 허용 위험뿐 아니라 실제 평균/최대 노출, 위험 사용 시간, 거래량, 하방 꼬리 손실을 보고한다. 같은 초기 1/3 물량만 맞춘 비교를 공정한 위험 비교라고 부르지 않는다.

## 4. 상태 전이

IDLE → ARMED(확인 대기, 해당 후보만) → ENTRY_PENDING → OPEN → REDUCING → CLOSED. 부분 진입은 OPEN 상태에서 미체결 진입 주문이 남을 수 있다. 상태 이름 하나로 주문의 부분체결 여부를 덮지 않는다. 모든 상태에서 RISK_HALTED로 갈 수 있고 신규 위험 증가 주문은 차단한다. 재개는 사전 명세의 조건 충족 및 원장 일치 후에만 허용한다.

한 시점에서 무효화와 재진입 조건이 겹치면 무효화가 먼저다. 보호 청산이 필요한 동안 신규 추가를 내지 않는다. 봉 내부 순서를 알 수 없는 경우의 처리와 민감도는 엔진 명세를 따른다.

## 5. 결합 후보의 제한

장세 선택기는 예측 시점에 이용 가능한 특징만 받는다. 실제 미래 상승/하락으로 만든 장세 표시는 사후 설명에만 사용한다. 구성 전략의 단독 통과와 선택기의 추가 가치는 별도 조건이다.

최초 비교는 적격 최선 단독, 적격 전략 고정 배분, 장세 선택 배분의 세 가지다. 같은 총위험 한도를 사용하고 반대 의도 상계·우선순위·미배정 현금을 공개한다. 최종 전략에서 하나씩 제거하는 검사로 기여를 확인한다. 모든 후보를 넣는 것을 최종 모델의 요건으로 삼지 않는다.

## 후보 구성 재검토

[후보 재검토와 확장 연구 지도](CANDIDATE_REVIEW.md): 기존 여섯 후보의 중복을 구분하고 S07~S13을 연구 목록으로 추가했다. 첫 후속 명세 대상은 S01/S02/S05/S07/S08이며 S04는 기존 대조로 유지한다. 추가 후보의 수익성은 미검증이고 현재 실행 등록은 하지 않았다.

## 최신 연구 방향: 매매 방식 제한 해제

사용자 요청으로 순환매를 필수 구성에서 제외했다. [방식에 제한을 두지 않는 탐색 계획](STRATEGY_DISCOVERY.md)을 따른다. 1,000 USDC·Binance BTCUSDC 실행 조건 아래 단독/복합 전략을 같은 기준으로 검토하며, 수익성이 검증된 방식은 아직 없다.
