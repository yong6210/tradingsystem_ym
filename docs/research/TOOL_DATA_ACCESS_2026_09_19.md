## 전달받은 사용자 정보와 적용 상태

1. 사용자는 maker **0%**, taker **0.025%**를 전달했다. taker는 편도2.5bp이며 실제 체결 명목금액에 적용한다. 계좌 직접 조회로 검증한 수수료나 과거 전체 기간의 실제 수수료로 표시하지 않는다. 프로모션 종료 조건은 미정이지만 같은 수수료를 다시 묻지 않고 사용자 제공 시나리오로 사용한다.
2. 연구용 데이터·도구 예산은 “잘 모르겠음”으로 답했다. 예산 상한은 미정으로 유지하고 무료 우선을 작업 원칙으로 선택한다. 특정 상품 결제 승인은 없으며 필요한 때 상품·금액·기간·해결할 연구 질문을 제시한다. 연구비와 지속 운용비는 구분한다.

[기계 판독 입력](../../configs/research/account_cost_context_20260919.json)에 원문·단위·적용 범위를 기록했다. 기존 기본 수수료5bp(0.05%)와 스트레스7bp(0.07%)보다 전달받은 taker2.5bp가 낮다. 기존 결과를 지우거나 수수료 차이만 더해 새 성과로 보고하지 않는다. 비용은 수량·최소 주문 적격성·후속 계좌 경로에도 영향을 주므로, 다음 비용 비교는 동일 신호/위험/슬리피지/펀딩으로 별도 등록 후 전체 계좌를 다시 실행한다. E022 예약에는 기존 동결 설정을 유지한다.

maker0%는 모든 지정가 주문이 무료라는 뜻으로 적용하지 않는다. 즉시 유동성을 가져가는 지정가 체결과 사용자가 요청한 지연 시 시장가 전환은 taker 비용 대상이다. 대기 주문의 maker 체결 가정은 별도 체결 근거가 필요하다. [Binance maker/taker 설명](https://www.binance.com/en/support/faq/detail/360007720071), [Futures GTX 안내](https://www.binance.com/en/support/announcement/detail/2164863753c14eebad14464a82419dff). 슬리피지·펀딩·실제 운영비도 maker 수수료와 별개로 남긴다.

불필요한 계정 비밀번호·API secret 전달을 요청하지 않는다. 향후 필요한 연결 권한이 생기면 해당 연결 경로와 최소 범위를 먼저 설명한다. 다른 자료를 요청할 때에는 실제 검증할 가설과 표본 기간·크기부터 정한다.

## 연구에서의 우선순위

E023 변경 보류와 E022 예약은 유지한다. 새 수수료 정보에 따른 별도 계좌 비용 비교를 다음 연구 입력 정리로 추가하고, 기존13대표 버전의 수익 원리/구현/자료 적격성 비교를 이어간다. 데이터 공급자를 발견한 사실만으로 S06 주문 흐름이나 S11 시장조성을 다음 최우선 전략으로 정하지 않는다.

L2 의존 가설을 선택한다면 다음 순서는 무료 자료 접근 해결 → 작은 표본의 schema/시간/호가 재구성·체결 원문 대조 → 필요한 연속 구간·자료 비용 검토 → 고정 가설의 실행 등록이다. 월1일만 있는 무료 표본을 시장 전체를 대표하는 성과 표본으로 삼지 않는다. L2 가격별 수량만으로 개별 주문의 대기열 순위와 지정가 체결이 완전히 관측되는 것도 아니다.

통계/검산 방법은 단일 축 대조, 과거 대조 재현, 비용·위험 분해, 미래 정보 차단, 가설/평가 기간의 사전 고정, 불확실성과 미확인 범위 공개를 유지한다. 효과가 없는 기간/필터 조합의 대량 탐색은 도구가 늘어도 재개하지 않는다. 장기 자체 수집 개발을 모든 전략 연구의 선행 조건으로 되돌리지 않는다.
