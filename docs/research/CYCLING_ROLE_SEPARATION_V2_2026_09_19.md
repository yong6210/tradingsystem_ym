# v2 — 주된 방향 입력과 운용 자리의 역할 분리

실제 자료에서 발견한 Z01 국소 이탈→주된 추세 전환→전량 종료 연결을 새 연구 경로에서 제거했다. `CyclingRoleEngine`은 v1의 주문·장부·수량 계산을 재사용하지만, v1의 A/B 구간 방향 판정은 사용하지 않는다. v1 경로와 이전 결과는 비교용으로 유지한다.

설정은 `configs/research/cycling_role_v2.json`에 별도로 고정했다. 기반 v1 설정 해시는 주문·수량 규칙의 출처이며 v2 방향 판정의 승인이 아니다. 두 설정을 모두 입력하고 v2 정책 해시도 검증한다.

## 실제 변경

- 초기 롱/숏 보유 가정은 검증된 주된 방향이 아니다. 주된 방향 상태를 `unassessed`, `assessed`, `uncertain`으로 따로 기록한다. `assessed`도 출처·역할을 갖춘 외부 연구 판단을 입력받았다는 뜻이지 시장의 정답을 증명한 상태가 아니다.
- 매물대 접촉·이탈만으로 최초 방향이나 반대 방향을 자동 확정하지 않는다.
- 주된 방향이 미확정/불확실하면 새 추가를 보류한다. 불확실성 입력 시 미체결 추가를 취소 요청한다. 기존 물량을 자동 전량 종료하지 않는다.
- 되돌림 총수량 절반 축소와 명시적 한도 초과에 대한 부분 축소는 독립적으로 유지한다.
- 주된 방향 입력은 등록된 근거의 존재·가용 시각·출처·역할·방향·설명을 검사한다. 국소 실행 근거를 주된 방향 근거로 사용하는 입력은 거부한다.
- 전환 입력에는 현재 채택한 추세 근거를 명시적으로 무효화하는 기록과 반대 방향 형성 기록이 필요하다. 두 역할의 출처 사건이 중복되면 거부한다. 단순히 동일 접촉에 이름만 두 개 붙인 경우를 제외하는 검사이며, 서로 다른 사건의 통계적 독립성까지 보증하지는 않는다.
- 전환이 입력되면 기존 주문 취소·대사 → 실제 잔량 종료 → 새로운 반대 방향 반응 대기를 따른다. 판단 입력과 같은 시점의 신규 진입도 보류한다.

## 같은 실제 자료에서 재검증

기존 BTCUSDC 48시간 자료, 동일 비용·체결·계좌 가정, 동일 구간을 사용했다. 사전 동결 자료에 검토된 주된 추세 형성/무효화 기록은 없으므로 빈 추세 근거 레지스트리를 사용했다. 그런 근거가 있는 것처럼 새로 만들어 넣지 않았다.

| 독립 초기 상태 | v1 | v2 |
| --- | --- | --- |
| 방향 미정·무보유 | 주문 없음 | 주문 없음, 주된 방향 미확정 기록 |
| 가정 롱 0.1 BTC | 추가 0.025 체결 후 0.125 전량 종료 | 추가·전환 보류, 0.1 유지 |
| 가정 숏 0.1 BTC | 0.05 축소 | 같은 시점에 0.05 축소 유지 |

롱 잔량 유지는 그 포지션을 계속 보유하는 것이 옳다는 결론이 아니다. 미확정 정보를 자동 전환 근거로 승격하지 않았다는 뜻이다. 이 자료에서 롱 축소 자리가 Z02 하나라는 기존 한계도 그대로 남아 있다. 수익성 개선을 목표로 그 가격을 사후 변경하지 않았다.

## 검증

새 역할 검사 10개를 포함한 cycling 76개, 장부 9개 통과. 기존 세 v1 실제 재생 기록과 리팩터링 이후 기록을 사건 단위로 비교해 동일함을 확인했다. 새 v2 세 경로도 이후 24시간 제거 시 앞부분 기록 불변성 및 별도 체결 장부 검산을 통과했다.

재현:

```sh
PYTHONDONTWRITEBYTECODE=1 .venv/bin/python scripts/replay_cycling_roles_v2.py
PYTHONDONTWRITEBYTECODE=1 .venv/bin/python -m unittest discover -s tests -p 'test_recovery_cycling*.py'
```

산출물: `reports/validation/cycling_roles_v2_20260919/summary.json` 및 경로별 JSONL. 이전 v1 산출물은 덮어쓰지 않는다. 실주문은 없다.

## 아직 해결하지 않은 판단

자동 주된 추세 분류기는 구현하지 않았다. 근거의 출처·가용 시각·선언된 역할을 검증해도 그 해석이 올바른지는 별도 검토해야 한다. 이를 해결했다고 표현하지 않는다. 중요 매물대 자동 선정, 보유 상태에 따른 여러 축소 자리의 우선순위, 새로운 추가 근거의 독립성도 남아 있다.

다음 작업은 추가 엔진 확장이 아니라, 사전 자료에서 주된 방향을 형성한 이동·구조와 운용 구간을 각각 설명할 수 있는 실제 판단 사례를 만드는 것이다. 그 사례로 주된 방향 분류와 중간 되돌림 축소 기준을 구체화한다. 4시간봉 고정이나 임의의 짧은 손절로 대체하지 않는다.
