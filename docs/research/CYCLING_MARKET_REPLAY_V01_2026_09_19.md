# 같은 방향 순환매 — 실제 자료의 첫 주문 재생

순환 주문 흐름은 연결됐지만 이번 시험 설정의 성과는 손실이다. 아래 결과는 사용자 전략의 수익성 판정이 아니라, 미확정 시장 판정식과 모의 계좌 설정을 결합한 개발 재생이다.

## 고정한 실험 입력과 실행 가정

설정: `configs/research/cycling_market_candidate_v01.json`. 이전 신호 후보의 4시간봉 고점·저점 방향과 60분 구간·1분 반응을 사용한다. 초기 평가액 10,000 USDC, 증거금 산식용 레버리지 2, 최대 수량 0.2 BTC, 최초 진입 시 예비 증거금 7,000 / 보유 중 추가 시 3,000 USDC를 입력했다. 역행 $2,000·$3,000 시나리오의 전체 운용 손실 한도는 1,000 USDC다. 모든 숫자는 시험 입력이며 사용자 승인 운용 한도가 아니다. 초기·추가 수량 자체는 고정하지 않고 제약의 최솟값으로 산출한다.

완료 봉에서 주문 의도를 만들고 다음 1분봉 시가에 스프레드 편도 0.5bp, 불리한 체결 2bp, 체결 수수료 4bp를 적용한다. 증가 주문은 기존 가격 한도 안에서만 체결하며, 다음 시가의 한 차례 기회 후 미체결 잔량을 취소한다. 이것은 주문 잔량 정책이며 보유 포지션의 시간 손절이 아니다. 체결 가능 수량은 직전 완료 봉 거래량의 1%이며 현재 봉 거래량을 미리 사용하지 않는다. 축소·전환 종료는 부분 체결 이후 남은 주문량을 이어간다.

펀딩은 제공된 실제 이벤트 시각과 마크 가격으로 당시 보유량에 적용한다. 봉 시작 직후 수 ms 뒤에 발생한 펀딩은 해당 시가 체결 이후에 처리한다. 미래 펀딩 예측은 없다. 종가 표본 평가액에서 사용 증거금을 차감해 여력을 계산하며 거래소 유지증거금·강제청산 모형은 없다.

반복 축소 방지 시험 규칙: 마지막 증가 체결 ID 하나당 되돌림 축소 목표를 한 번만 만든다. 새로운 증가 없이 같은 반응이 반복됐다는 이유로 잔여분을 계속 절반씩 덜지 않는다. 새 증가가 체결되면 새 순환의 최소 절반 축소를 허용한다. 시장 판단의 임계값과 이 신호 소비 방식은 여전히 연구 후보다.

## 검산과 한계

`scripts/replay_cycling_market.py`가 주문·체결·펀딩·방향 기록을 출력한다. 별도 집계로 체결마다 통합평단, 수량, 실현손익, 비용과 펀딩을 재계산해 장부와 대조했다. 증가 방향, 축소 목표 최소 절반, 전환 종료 사유 및 신호 이전 체결 부재를 확인했다. 실제 자료의 최종 체크포인트도 이벤트 재생 복원에 성공했고 재시작 잠금을 확인했다.

신규 재생 테스트 6개를 포함한 관련 총 48개 테스트 통과. 신호 종가 즉시 체결 방지, 다음 시가의 가격 한도, 직전 거래량 기반 부분 체결, 잔여 포지션 무조건 반복 축소 방지, 축소 잔량 처리, 펀딩·자료 끝 평가 처리를 검증했다.

결과 폴더: `reports/validation/cycling_market_candidate_v01_20260919/`. `summary.json`, `events.jsonl`, `config.json`, `checkpoint.json`과 실행 소스·설정·자료 해시가 있다. 실제 주문장·청산·접속 장애를 재현한 실거래 검증은 아니다. 다음은 특히 손실 전환 구간과 비용이 큰 반복 진입을 사례별로 검토할 단계이며, 이 결과를 보고 임의의 가까운 손절이나 시간 종료 규칙을 추가하지 않는다.
