# 무효화 이력 차이의 영향 검토 계약

확정 매매 원칙과 기존 구조 판정 규칙은 바꾸지 않는다. 7월 27일·19일 시작 경로가 8월 14일 08:00 UTC에 같은 숏 후보 63,945.6을 표시한 뒤, 마지막 무효화 이력의 차이(8월 11일 16:00 대 없음)가 실제 후보 심사에 영향을 주는지 확인한다.

## 비교 범위와 방법

종료는 기존 관찰 종료인 8월 17일 00:00 UTC다. 원래 구조 관찰기의 코드를 파일 수정 없이 계측해 매 완료 봉 시작 상태와 과거 근거 재사용(`inherited`) 분기의 입력을 기록한다. 계측만 한 결과가 원본 함수와 완전히 같은지 먼저 확인한다.

각 경로의 가격·피벗·현재 후보를 고정하고, 기준 시각 이후 첫 완료 봉에서 마지막 무효화 값만 상대 경로의 값으로 한 번 교환한다. 이후 실제 무효화가 발생하면 원래 코드가 값을 갱신하며 이를 덮어쓰지 않는다. 결과는 이후 후보 전체와 사건 목록으로 비교한다. 각 완료 봉에서 미래 가격과 아직 확인되지 않은 피벗을 제거한 재생도 대조한다.

후보 심사에 실제 사용한 이전 반응·돌파 대상·현재 반응의 가장 이른 형성 시각을 무효화 시각과 비교한다. 두 값 모두 같은 분기 결과를 만드는지 확인한다. 이는 고정 자료의 인과 대조이며 모든 미래 가격 경로에 대한 증명이 아니다.

## 일반 삭제를 막는 반례

기존 반대 구조 재접근 회귀 사례의 합성 가격을 사용해, 무효화 이력을 삭제하면 재접근 확인 없이 반대 후보가 먼저 형성될 수 있는지 확인한다. 합성 시점·가격을 실제 시장 사례와 섞지 않는다. 실제 한 구간에서 영향이 없다는 이유로 변수를 지우거나 초기 상태를 임의 정규화하지 않는다.

## 완료와 제한

- 계측이 원래 코드를 바꾸지 않았고, 한 값 교환 이외에 입력을 변경하지 않았음을 확인한다.
- 실제 분기 입력·미래 자료 제거·이후 사건의 일치 또는 차이를 기록한다.
- 동등성을 말할 수 있는 자료·기간·출력 범위를 한정한다.
- 최초 방향의 정당성·실제 전환·보유 종료·중요 매물대는 이 검사로 검증하지 않는다.

신규 노출·주문을 생성하지 않는다. 4단계 미통과 및 5·6단계 보류 상태를 유지한다.
