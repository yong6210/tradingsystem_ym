# 연구 기획서

작성일: 2026-09-17. 상태: 연구 설계 v1. 실제 운용 목표는 일부 미정.

## 1. 목표와 범위

최종 목적은 BTCUSDC 무기한에서 비용과 실행 제약을 고려한 수익 우위를 확인하고, 유리하지 않은 구간에는 위험을 줄이거나 거래하지 않는 모델을 만드는 것이다. 모든 시점·모든 장세에서 수익을 보장하는 모델, 과거 수익률 최고치를 만드는 모델은 성공 정의로 사용하지 않는다.

지금의 목적은 **현재 평균회귀 매매의 손실 원인을 진입·청산·재고·장세 선택·체결 비용으로 분리**하는 것이다. 연구와 실거래 운영을 분리하며, 이 기획은 주문 실행이나 자동매매 전환을 의미하지 않는다.

실제 운용에서 정해야 할 값:

| 항목 | 현재 상태 |
|---|---|
| 대상 | 사용자가 지정한 BTCUSDC 무기한. 거래소/계정의 정확한 계약·모드 미확정 |
| 목표 수익률 | 미정. 숫자를 임의로 성공 기준에 넣지 않음 |
| 허용 최대 낙폭·손실 예산 | 미정. 기존 연구의 1배·0.5%는 비교용 가정이지 사용자 위험 선호가 아님 |
| 완전 자동 / 판단 보조 | 미정 |
| 메이커 비용 | 사용자 가정 0. 거래소·계정·기간별 실제 적용 여부는 별도 확인 필요 |
| 시장가·펀딩·체결 | 기존 비용은 연구 가정. 실측 전 실거래 성과로 표시하지 않음 |

이 값들은 실거래 선택과 E002 이후의 위험 설계에 필요하다. 자본·청산 없는 E001 정보력 진단은 진행 가능하다.

## 2. 확인된 사실과 가설 분리

| 관찰 | 근거 | 가능한 해석 | 아직 입증하지 못한 것 |
|---|---|---|---|
| 현재 순환매 기본 매매는 추가 매수 없이도 네 평가 구간 모두 손실 | 기존 동결 결과 | 진입+청산+비용 조합의 우위 부족 | 진입 신호만의 무효 여부 |
| 같은 초기 진입 규모에서 재순환 허용 시 네 구간 모두 악화 | 제한형/재충전형 비교 | 불리한 방향 노출 증가의 보상이 부족 | 동일 위험 사용량으로 정규화한 순수 효과 |
| 일부 단독 스윙·돌파는 특정 기간 양수지만 조합은 손실 | 전략별 손익 귀속 | 손실 전략 배분·필터·거래 경로 변화 | 어떤 필터/충돌이 얼마나 기여했는지 |
| 회계·테스트 통과 뒤에도 손실 | 원장 검산·회귀 테스트 | 코드 정상 동작과 수익 우위는 다른 주장 | 시뮬레이터가 실제 체결을 정확히 재현하는지 |

근거는 `docs/STRATEGY_SELF_AUDIT_2026_09_17.md`, `docs/RECYCLING_PORTFOLIO_2026_09_17.md`, `docs/COMPLETE_BTC_2024_VALIDATION_2026_09_17.md` 및 각 문서의 원본 결과 참조. 특정 모델의 실패를 순환매/스윙 전체의 실패로 일반화하지 않는다.

## 3. 가설의 순서

- H1 진입 정보: 완료된 정보로 정의한 신호 뒤 가격 변화가 비슷한 시장 상태의 대조 시점보다 유리하다.
- H2 청산: 같은 진입에서 특정 청산이 정보의 이익을 비용 후 보존한다.
- H3 재고: 같은 최대 위험 예산에서 분할·추가·재진입이 단순 보유보다 효율적이다.
- H4 선택: 사전에 관측 가능한 장세 정보가 거래할/하지 않을 조건을 구분한다.
- H5 결합: 독립 검증된 구성요소의 결합이 단독보다 목표 위험 대비 이득이 있다.
- H6 실행: 실제 주문 제약에서도 앞선 효과가 유지된다.

H1이 약하다고 즉시 모든 신호를 폐기하지는 않는다. 비대칭적인 큰 움직임을 잡는 추세 전략은 평균·중앙값·분포가 다를 수 있다. E001은 우선 현재 손실 원인을 묻는 평균회귀 신호 하나에 범위를 고정한다.

## 4. 데이터·선택 편향 관리

현재 검증 자료는 2023-01~2026-08, 44개월, 1,928,160분이다. 원본 ZIP 해시·연속성·OHLCV 검사는 통과했으나 거래소 원본 진위와 BTCUSDC의 실행 적합성은 별개다.

44개월은 이미 결과를 살펴본 자료다. 이제 기간을 다시 나눈다고 완전히 새로운 홀드아웃이 되지 않는다. 향후 워크포워드도 이 자료에서는 **회고적 진단**으로 표시한다. 미관측 전진 검증은 동결된 명세 이후 새로 수집하고 연구 결정에 사용하지 않은 자료에서 별도로 수행한다. 현재 E001의 채택 근거를 실거래 승인으로 올리지 않는다.

모든 실험에 질문·반증 조건·변경 축·대조군·주 지표·부 지표·기간·제외·비용·코드/자료 해시·전체 시도 이력을 기록한다. 결과를 본 수정은 새 버전과 변경 이유를 남긴다. 중단·오류·음수 결과도 보존한다. 시험한 후보 전체 수를 모르면 모른다고 기록한다.

## 5. 판정 언어와 통과 기준

판정은 `지지`, `기각`, `자료/방법 불충분`으로 구분한다. 먼저 표본 수·대조군 중복·시간 의존성과 기간별 효과를 보고한다. 평균 양수 하나로 지지를 선언하지 않는다.

E001의 주 지표는 사전 고정한 60분 시점의 방향 조정 수익률 차이다. 신뢰 구간은 시간 의존성을 고려해 산출하고, 0을 포함하면 통계적 지지를 선언하지 않는다. 이 기준을 통과해도 실행 비용을 넘는 매매 우위가 입증된 것은 아니다. 기간별 불일치와 비용 규모를 함께 검토한다. 적정 효과 크기와 표본 정밀도를 판단할 수 없으면 `불충분`으로 남긴다. 더 유리한 부 지표로 주 지표를 바꾸지 않는다.

E002 이후의 구체적 채택 문턱은 각 단계 진입 전에 별도 설계한다. 아직 검사하지 않은 항목을 통과로 표시하지 않는다.

## 6. 개발 원칙

한 번에 하나의 질문을 해결한다. 공통 부분은 검증된 시점에 추출하며, 미래에 필요할 것 같은 프레임워크를 먼저 대량 작성하지 않는다. 기존 소스 해시와 결과의 연결을 보존하기 위해 과거 엔진을 바로 옮기거나 정리하지 않는다. 가독성 개선과 전략 의미 변경은 분리하고, 동등성 검증 없는 리팩터링을 과거 실험의 동일 엔진이라고 부르지 않는다.
