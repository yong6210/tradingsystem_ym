# 역행·추가·회복·종료 판단 명세 v0.1

작성: 2026-09-19. 명세 작성 당시 상태: 구현·시나리오 실행·수익성 검증 전.
후속 구현: [연구용 판단 엔진과 실행 안내](RECOVERY_CONTROLLER_IMPLEMENTATION_2026_09_19.md). 아래 원래 명세와 시험값은 보존하며 구현·합성 검증 결과는 후속 문서에서 구분한다.
사용자는 추가 방식에 동의하고 미정 세부 사항의 판단을 위임했다. 아래 시험 수치를 사용자가 직접 지정하거나 성과로 검증한 값으로 표시하지 않는다.

## 1. 확정 원칙과 적용 범위

- 시장 판단, 보유 포지션, 실행 상태를 별도 관리한다. 큰 상승 판단 중에도 무포지션 또는 근거 있는 단기 숏이 가능하다.
- 최초 주문 전에 기록한 분할 계획만 반응 확인 전 지정가 주문을 허용한다. 손실 후 새 주문을 원래 분할로 재분류하지 않는다.
- 새로운 손실 중 추가는 새로운 반응 확인을 필요로 한다. 평균가 개선만으로 추가하지 않는다.
- 추가를 위해 기존 무효화 조건을 불리하게 옮기거나 운용 손실 예산을 확대하지 않는다.
- 본절 전에 근거가 무너지면 종료한다. 본절 도달은 무조건 보유·청산하는 신호가 아니다.
- 고정 1/10 진입, 절반 축소, 최소 잔여 물량 의무 보유를 적용하지 않는다.
- 우선순위: 계좌·실행 복구 → 손실·노출 제한 → 근거 무효화 → 축소·익절 → 신규·추가.

이 문서는 이번 운용 흐름의 최신 설계 기준이다. 과거 명세의 고정 분할과 E057의 최소 잔여 물량 강제는 이 설계에 승계하지 않는다. 과거 코드·결과는 변경하지 않는다. 기존 자동 관측·실행 설정에 대한 변경 지시가 아니다.

## 2. 관찰 단위와 인과성 — 설계자가 정한 시험값

큰 흐름과 위치는 기존 1일·4시간·1시간·15분 정보와 다중 기간 구간을 사용하되, 모든 시간대 방향 일치를 강제하지 않는다. 이번 버전은 주어진 문맥·구간을 입력으로 삼으며 구간 탐색 알고리즘의 우열까지 확정하지 않는다. 문맥 불명확 상태에서는 새로운 추가를 보류한다.

타점은 완료 3분봉과 이후 완료 1분봉으로 판단한다. 3분봉은 UTC 00분 기준으로 정렬된 연속 1분봉 3개로 구성한다. 미완료 봉, 미래 고저점, 사후 형성 구간을 사용하지 않는다.

구간은 ID, 버전, [L,U], 형성·관측 가능 시각, 근거별 출처, 상태, 무효화 조건을 가진다. 추가 관찰 시작 시 스냅샷을 고정한다. 이후 새 구간은 새 버전이며 과거 진입을 정당화하지 못한다.

허용 폭 b = max(2틱, 관찰 시작 직전 완료 3분봉의 ATR14 × 0.10). ATR은 14개 TR 산술평균으로 정의한다. b는 해당 관찰 동안 고정한다. 자료 부족 시 신호 없음으로 처리한다. 이 폭은 재접근 판정용이며 기존 보호 손절을 넓히지 않는다.

## 3. 롱 추가의 정확한 상태 전이 — 숏은 부등호 반전

1. 관찰 시작: 유효한 지지 [L,U]와 완료 1분봉 가격 범위가 겹친다. 기존 보유 근거와 보호 손절이 유효해야 한다.
2. 회복 확인: 관찰 시작 이후 닫힌 3분봉이 해당 구간에 닿고 종가 C3 > U+b로 마감한다. 단순 양봉 또는 꼬리만으로 확인하지 않는다.
3. 재접근: 회복 봉 종료 후 9분 안에 완료 1분봉의 저가가 [L-b,U+b] 안에 들어오고 종가가 U 이상이어야 한다. 회복 봉 자체를 재접근 봉으로 재사용하지 않는다.
4. 유지 확인: 바로 다음 완료 1분봉의 저가가 재접근 봉 저가-b 이상이고 종가가 U+b보다 높아야 한다. 이 봉도 9분 기한 안에 완료돼야 한다.
5. 경제성·수량 확인: 추가 체결 예상가에서 다음 저항의 가까운 경계까지 비용 후 이익 / 추가 근거 종료 시 비용 포함 손실 ≥ 1.5여야 한다. 방향상 잘못된 목표·종료 가격, 비용 불명, 손실 분모 0은 추가 불가다.
6. 주문: 확인 이후 처음 이용 가능한 호가로 다시 계산한다. 봉 종가에 이미 체결된 것으로 기록하지 않는다. 모의 봉 재생에서는 다음 1분봉 시가와 비용으로 계산한다.

관찰 시작 후 5개 완료 3분봉 안에 회복이 없으면 관찰 만료. 회복 후 9분 내 유지 확인이 없으면 신호 만료. 보호 손절 도달, 전체 근거 무효화, 회복 이후 완료 1분봉 종가 < L-b면 즉시 추가 후보 폐기. 같은 시점에 만료·무효화와 추가가 겹치면 추가하지 않는다.

재접근 없이 급반등하면 추가를 생략한다. 새 관찰은 이전 이벤트 종료 후 완료 3분봉 하나가 구간 밖의 유리한 쪽에 마감하고, 이후 새로 구간을 방문해야 시작할 수 있다. 같은 회복·재접근 증거는 한 번만 소비한다.

## 4. 횟수·수량·손실 예산

시험 기본 경로는 반응 확인 후 추가만 사용한다. 사전 분할은 허용 원칙을 보존하되 별도 비교 경로로 검증한다.

한 운용 안의 새로운 손실 중 추가는 최대 2개 이벤트로 제한한다. 이는 사용자 원칙이 아닌 반복 물타기를 제한할 초기 시험값이다. 부분 체결 여러 건은 한 이벤트이고, 일부라도 체결된 이벤트는 취소 후에도 횟수에 포함한다. 축소 후 손실 상태의 재추가도 포함하며 횟수를 초기화하지 않는다.

운용 ID는 최초 체결부터 전량 종료 및 모든 관련 주문의 최종 상태 확인까지 유지한다. 부분 익절로 손실 예산을 늘리지 않는다. 전량 종료 후 새 거래라도 계좌 누적 손실·중단 상태는 유지한다.

회계 검토용 시험값: 운용 시작 평가액 E0의 1%를 해당 운용의 손실 예산 B로 고정한다. 새 추가 이벤트 하나에는 최대 0.25B의 신규 위험을 배정한다. 실계좌 권장값이나 실제 손실 보장이 아니다. 계좌별 더 엄격한 기존 한도가 있으면 함께 적용한다. 레버리지는 수량을 키우는 근거로 사용하지 않는다.

위험 사용량은 개별 실현 손실과 이미 지불한 비용, 각 잔여 물량의 종료 시 예상 손실·비용, 미체결 주문의 최악 허용 체결 위험을 합산한다. 실현 이익·미실현 이익으로 손실 예산을 재충전하지 않는 보수적 위험 장부이며, 실제 순손익 장부와 구별한다. 비용은 각 항목에서 중복 차감하지 않는다.

추가 수량은 (남은 운용 예산, 0.25B) 중 작은 금액을 추가 단위당 종료 손실·비용으로 나눈 값 이하로 한다. 증거금·계좌 노출·호가 유동성 상한도 함께 적용하고 거래소 수량 단위로 내림한다. 최소 주문량 미만이면 추가를 생략한다. 동시 미체결 상태가 불확실하면 수량을 확정하지 않는다.

추가분의 보호 종료 가격은 롱에서 max(기존 공통 보호 손절, 재접근 저가-b)로 고정한다. 예상 진입가 이상이면 추가하지 않는다. 추가 근거가 실패하면 추가에 귀속된 수량을 종료하고, 기존 물량은 별도 근거로 평가한다. 전체 근거 또는 공통 보호 손절이 무효화되면 전량 종료한다. 거래소 평균가와 내부 물량별 근거·원가는 별도로 기록한다.

## 5. 두 본절 가격과 회복 관리

선형 결제 상품 기준 d=롱 +1/숏 -1, 잔여 수량 Q, 평균가 A일 때:

- 잔여 포지션 본절: d×Q×(P-A) - 잔여분에 배분한 미반영 진입비·펀딩 - 예상 종료비용(P) = 0.
- 전체 운용 회복: 누적 실현 순손익 + d×Q×(P-A) - 아직 실현 장부에 반영하지 않은 비용 - 예상 종료비용(P) = 0.

비용 원장에 한 번 기록한 비용은 두 번 차감하지 않는다. 부분 체결·축소·펀딩마다 재계산한다. Q=0은 회복 가격 없음이며 확정 순손익만 표시한다. 해가 비정상적이거나 비용을 계산할 수 없으면 판단 불가로 표시한다. 다른 결제 구조에는 이 식을 그대로 적용하지 않는다.

본절 부근은 각 본절 가격 ±b로 정의한다. 이는 관리 알림이며 자동 절반 청산 신호가 아니다. 실행 가능한 매도 bid/매수 ask 및 예상 비용으로 평가한다.

회복 중에는 본절과 다음 장애물을 독립 관찰한다. 롱은 다음 저항 [Lr,Ur] 도달 시 아래 규칙을 사용한다.

| 관찰 | 시험 대응 |
|---|---|
| 본절 도달, 저항 미도달, 보유 근거 유지 | 기존 목표·종료 계획 유지. 본절만으로 확대하거나 축소하지 않음 |
| 저항 접촉 후 완료 1분봉이 Lr-b 아래 마감 | 거절 확인. 회복용 추가분 전부 종료, 기존분 위험 재평가 |
| 저항 안에 머물며 2개 완료 3분봉 동안 돌파 미확인 | 진행 둔화. 회복용 추가분 전부 종료, 기존분 위험 재평가 |
| 완료 3분봉 종가 > Ur+b, 이후 9분 내 재접근·유지 확인 | 돌파 유지. 기존 추가분을 남길 수 있으나 자동 추가는 없음 |
| 본절에 잠시 닿고 이탈 | 본절 이탈 자체로 무조건 종료하지 않음. 위 거절·둔화 또는 근거 실패를 적용 |
| 본절 전에 전체 근거 실패 또는 보호 손절 도달 | 본절과 무관하게 전량 종료 |

돌파 후 재접근·유지 확인은 §3과 동일하며 기존 저항을 새 지지로 평가한다. 확인 대기 중에도 기존 손절을 유지한다. 같은 시점에 거절·둔화와 돌파 확인이 충돌하면 축소가 우선한다.

거절·둔화 뒤 남길 기존 물량은 현재 근거가 유효하고 새 잔여 종료 조건을 설명할 수 있는 경우에만 허용한다. 회복 관찰 시작 직전 5개 완료 1분봉의 최저가-b와 기존 보호 손절 중 높은 값을 잔여 보호 종료 가격으로 고정한다. 이 가격이 현재 실행 가격 이상이면 잔여분도 종료한다. 이후 새 구조로 유리하게만 조정할 수 있다.

잔여분이 이 종료 가격에서 잃을 수 있는 추가 평가액은 min(0.25B, 남은 운용 위험 예산) 이하여야 한다. 현재 실행가에서 종료가까지 비용 포함 단위 손실로 허용 수량을 역산하고 초과분을 축소한다. 이 계산에서 현재 축소 비용도 반영한다. 최소 주문 조건으로 유효한 잔여분을 유지할 수 없으면 전량 종료한다. 보유 근거가 없으면 계산상 여유가 있어도 전량 종료한다.

남은 물량에는 보유 이유, 다음 목표 구간, 보호 종료 가격, 구조 무효화 조건, 재평가 시각을 기록한다. 목표 저항에서 다시 거절·둔화가 확인되면 남은 물량을 전량 종료한다. 더 먼 목표로 연장하려면 기존 목표 돌파·재접근 확인과 새로운 목표·종료 계획이 먼저 있어야 한다.

## 6. 주문·데이터 예외

기본 전제: 신규 주문 중단은 위험을 줄이는 주문까지 일괄 금지한다는 뜻이 아니다. 체결·취소 요청은 확정 상태가 아니다. 주문 ID와 거래소 체결 원장으로 멱등 처리한다. 아래는 구현해야 할 계약이며 현재 실행 보장이 아니다.

| 예외 | 신규·추가 / 기존 진입 주문 | 잔여 포지션 처리 | 재개 조건 |
|---|---|---|---|
| 급변으로 계획가 통과 | 중단·취소 요청, 추격 금지 | 손절은 첫 실행 가능 가격에 위험 축소. 계획가 체결 가정 금지 | 상태 확정 후 새 관찰 |
| 스프레드·유동성 악화 | 실행 상한 초과 시 중단·미체결 취소 | 보호 주문 유지, 필요한 축소는 체결 가능한 크기로 진행 | 사전 실행 한도 충족 및 상태 확인 |
| 부분 체결 중 반대 신호 | 잔량 취소 요청 | 우선순위에 따라 실제 체결량만 축소·종료 | 취소 최종 상태·체결량 대사 |
| 취소 요청 중 추가 체결 | 신규 중단 | 늦은 체결 포함 목표 잔여량 재계산 | 대사 완료, 중복 축소 없음 |
| 종료 직후 같은 방향 신호 | 이전 신호 재사용 금지 | 무포지션 허용 | §3의 새 관찰 및 계좌 여력 |
| 같은 구간 연속 국소 손절 2회 | 해당 구간 신규·추가 잠금 | 유효한 기존분만 보호 조건으로 관리 | 이후 완료 15분봉으로 새 구간 버전 성립; 기존 구간 이름만 변경 금지 |
| 펀딩 시각 통과 | 예상 비용 불명 시 추가 중단 | 실제 펀딩 반영 후 회복 가격·위험 재계산 | 비용·포지션 대사 |
| 최소 주문량·잔여 먼지 | 늘려서 최소량 충족 금지 | 필요 시 거래소 전체 종료 기능 사용, 실패는 복구 상태 | 실제 잔여 0 또는 유효한 잔여 관리 확인 |
| 데이터 지연·누락·단절 | 신호용 1분봉 마감 후 10초 내 미수신 또는 봉 누락 시 중단·진입 주문 취소 요청 | 거래소 보호 주문 유지. 전송 불가 시 취소·종료 성공으로 기록하지 않음 | 연속 3개 1분봉 수신, 누락 복구, 주문·포지션 대사 후 새 신호 |
| 재시작·기록 불일치 | 모든 증가 주문 잠금 | 거래소 수량 기준으로 위험 관리. 알 수 없는 체결 원가·근거는 복구 후에도 추가 금지 | 주문·체결·잔고·보호 주문 일치 및 근거 복원 |

보호 주문을 둘 수 없거나 위험 한도를 위반한 상태에서 거래소 통신이 가능하면 잔여분 종료를 우선한다. 통신 불가면 외부 조치 필요 상태와 실제 노출을 명시한다. 재시도 횟수로 체결 완료를 추정하지 않는다.

동일 OHLC 봉 안에서 추가·목표·손절의 선후가 불명확하면 거래 자료로 확인하거나 모호 경로로 분리한다. 수익이 좋은 순서를 선택하지 않는다. 보수 경로에서는 손절 우선, 같은 봉 추가 불허를 사용한다.

## 7. 시간순 시나리오 검토표 — 아직 실행하지 않음

| 시나리오 | 기대 판단 순서 |
|---|---|
| 지지 반등 → 저항 | 진입 근거 기록 → 저항 거절·둔화 시 목표 대응 → 무포지션 가능 |
| 역행 → 추가 → 본절 저항 거절 | 도달만으로 대기 → 회복·재접근·유지 후 추가 → 추가분 종료 → 기존분 위험만큼 축소 |
| 추가 후 추가 근거 실패 | 미체결 취소 → 추가분 종료 → 기존 근거 평가 |
| 추가 후 전체 지지 붕괴 | 추가 금지 → 모든 진입 잔량 취소 요청 → 전량 종료 |
| 축소 후 재지지 | 이전 신호 폐기 → 새 관찰 → 남은 횟수·예산 내 재진입 |
| 돌파 추격 실패 | 새 진입 자체의 근거 무효화로 종료, 큰 흐름 유지가 면책 사유 아님 |
| 큰 상승 중 단기 숏 | 독립 목표·종료 근거를 기록, 롱 청산만으로 숏 발동 금지 |
| 박스에서 추세 시작 | 기존 경계 무효화 → 해당 경계 반복 거래 중단 → 새 구조 관찰 |
| 일방 하락 지속 | 확인 없는 추가 0회 → 원래 보호 종료 실행 |
| 재접근 없는 급반등 | 추가 생략 → 기존 물량만 관리 |
| 취소와 늦은 체결·손절 동시 | 실제 체결량 대사 → 중복 없는 위험 축소 → 신규 잠금 |

숏 대칭, 정확한 경계값, 만료 시각, 데이터 누락, 비용 반영 후 본절 이동도 같은 방식으로 검토한다. 매 사건에 당시 정보, 근거 ID, 실제 보유량, 위험 장부, 결정 및 거절 이유를 남긴다.

## 8. 검증 순서와 남은 의존성

먼저 위 합성 경로의 판단·회계·주문 순서만 검토한다. 이후 동일 최초 진입·구간·손실 예산을 고정하여 추가 없음 / 반응 확인 추가 / 사전 분할을 비교한다. 수익률 외에 최대 노출, 손실 꼬리, 회복 전 종료, 추가 후 손절, 체결 실패, 본절 회복 시간, 최소량 장기 보유를 보고한다.

이번 0.10 ATR·9분·1.5배·2회·1%·0.25B 등은 사전 시험 가정이다. 같은 재사용 월의 수익을 보고 숫자를 재조정하지 않는다. 변경하면 새 버전과 이유를 먼저 기록하고 새로운 자료에서 검증한다.

전체 자동매매 명세의 완성을 주장하지 않는다. 문맥·구간 생성의 결정 규칙, 전체 근거 무효화의 거래별 값, 거래소별 최소량·보호 주문·실행 한도·비용·계좌 중단 정책은 재생 입력으로 명시되어야 한다. 없으면 해당 주문은 판단 불가로 차단하며 임의 기본값을 숨겨 넣지 않는다. 이 문서 작성으로 엔진 구현·실주문·실증 검증을 실행하지 않았다.
