# 4시간봉 고정을 벗어난 주된 방향 입력

`DirectionalCycling.set_direction`에 명시적인 `assessment` 입력을 추가했다. 이 경로에서는 특정 시간봉을 요구하지 않는다. `timeframe`은 출처 설명이고, 주된 방향의 근거·판단 종류를 별도로 받는다. `CyclingOrders`의 취소·전환·청산·재시작 흐름에도 같은 입력이 전달된다.

필수 입력은 `scope=main_trend`, `confirmed=true`, `kind=initial/maintain/reversal`, 중복 없는 `evidence_ids`, `invalidation_condition`이다. 반대 방향으로 바꾸려면 `kind=reversal`과 `prior_thesis_invalidated_by`가 필요하다. 방향의 최초 설정·동일 방향 유지·반대 방향 전환에 맞지 않는 종류는 거부한다. 미확정 판단과 국소 반응은 이 경로에서 방향 변경 입력으로 받아들이지 않는다.

이 필드는 외부 판단의 명시성·일관성을 검사하는 것이다. 근거 ID의 실제 존재·가용 시각·시장 타당성이나 추세 전환의 참/거짓을 검증한 것이 아니다. 현재 시장 관찰을 이 입력으로 자동 승인하는 코드는 아직 없다.

## 호환성과 주문 처리

기존 체크포인트·동결 시험의 재생을 위해 `assessment`가 없는 과거 4시간봉 경로를 유지했다. 다만 명시적 주된 방향 입력을 한 번 사용한 모델은 이후 근거 없는 과거 경로로 돌아갈 수 없다. 과거 4시간봉 신호 발생기는 별도 시험 코드이며 새 판단 경로로 자동 승격하지 않는다.

전환 요청은 입력을 검증한 다음 기존 주문 취소·체결 대사·실제 잔량 종료 절차를 사용한다. 부분 청산 상태에서 반대 방향 증가 체결은 계속 거부된다. 완전 청산 후에도 신규 진입 자리·수량 검사는 별도다. 방향 전환이 반대 주문의 자동 개설을 뜻하지 않는다.

입력 근거는 복사해 보관하므로 호출자가 원본 목록을 변경해도 진행 중 전환이나 저장된 판단 이력이 변하지 않는다. 체크포인트의 기존 사건 재생 방식으로 새 판단 근거를 복원하며, 재시작 후 계좌 대사 잠금도 유지한다.

## 검증

신규 테스트 6개: 4시간봉 없는 최초/유지/전환, 미확정·국소·근거 누락 거부, 전환 근거 필수, 중복·충돌·호출자 변경 격리, 기존 경로로의 후퇴 금지, 전환 중 저장/복원·부분 청산·완전 청산 전 반대 증가 차단.

관련 주문·재시작·신호·시장 재생·새 판단 입력 45개와 장부 9개, 총 54개 테스트 통과. 과거 실험 결과 파일은 재작성하지 않았다. 실제 추세 감지·실거래·수익성 검증 완료를 뜻하지 않는다.

다음은 관찰 자료의 근거 ID·실제 확인 시점을 새 방향 입력과 연결해, 확인되지 않은 자료를 `confirmed=true`로 잘못 전달하지 않도록 검사하는 단계다. 방향 판단식 자체는 여전히 미확정이다.
