# 약손절 뒤 역행 연속 구간 — 계산 전 계약

앞서 실제 가격과 근거로 확인한 추가 사례를 같은 시작점부터 2026-08-18 00:01 UTC까지 연장한다. 새로운 수익 결과를 보고 날짜·발동 기준·비율을 선택하지 않는다. 이미 본 개발 자료이며, **되돌림을 거친 동일 사례의 연장**이다. ‘추가 직후부터 되돌림 없이 역행하는 독립 사례’는 여전히 없다.

기존 국소 약손절 3개 정책과 기존 주된 무효화 이후 종료 3개 정책을 모두 교차 비교한다. 첫 구간은 기존 연구 재생기, 이후는 기존 전환 재생기를 재사용한다. 현재 총량, 평단, 비용 귀속, 누적 실현손익, 계좌 고점과 누적 DD를 그대로 이월한다. 신규 진입은 만들지 않는다.

연결 시각은 이미 확인한 주된 무효화 8/17 04:00 바로 전인 03:59다. 시각을 앞으로 옮겨 체결을 앞당기지 않는다. 연결 시 미체결·미완료 축소 의무가 있으면 해당 경로를 연결하지 않고 잔량·의도를 보고한다. 기본·0.003 BTC 체결량·5bp 슬리피지 대조를 동일 시작점부터 적용한다. 체결 불가 대조는 연결 전 미체결을 보존하며 연결 미실행으로 남긴다. 후반 수익은 생성하지 않는다.

주된 무효화 시 즉시 전량 종료, 절반 약손절 뒤 반대 근거에서 종료, 반대 근거까지 대기 후 종료라는 세 정책은 시험 대안이다. 어느 하나를 기본 정답으로 승격하지 않는다. 목표 축소는 이미 완료됐으므로 연결 뒤 같은 목표에 다시 닿아도 새로운 축소 의무를 만들지 않는다.

검증은 이전 약손절 구간의 모든 분봉 일치, 약손절 없는 대조군과 이전 전환 보고의 일치, 연결 전후 현금·장부 연속성, 원본 분봉·펀딩에 대한 별도 Decimal 검산, 분기 시점 이후 정보 제거로 한다. 각각의 구간만 성공했다는 이유로 연속 경로를 완료 처리하지 않는다.

이 검토로 알 수 있는 것은 앞선 노출 축소와 이후 종료 시점의 결합 효과다. 새 사례 일반화, 주된 반대 진입 승인, 실거래 준비 완료는 판단하지 않는다.
