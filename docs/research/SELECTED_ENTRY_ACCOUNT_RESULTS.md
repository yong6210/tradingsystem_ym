# 선정 후보의 실제 이후 시가 심사와 조건부 장부

고정한 8월 16일 16:09 숏 후보를 다음 시가에서 다시 심사했다. 기본 비용 가정에서는 **16:10 숏 0.006 BTC → 20:45 절반 축소 → 종료 시 잔량 0.003 BTC**였다. 슬리피지 5bp에서는 진입 전부터 목표까지의 순여유가 음수가 되어 거래하지 않았다.

[사전 설정](../../configs/research/selected_entry_account_trial.json), [결과표](../../reports/validation/selected_entry_account_20260920/review.md), [전체 판단·장부](../../reports/validation/selected_entry_account_20260920/review.json), [독립 검산](../../reports/validation/selected_entry_account_20260920/verification.json)을 보존했다. 실제 주문·운영 승인은 없으며, 이미 검토한 시장 사건을 다른 보유 시작 상태로 재생한 개발 사례다.

## 견적 후보와 체결 심사를 분리

후보 판단은 16:09 완료 분봉이다. 이 시각과 같은 시가를 쓰지 않고, 엄격히 이후인 **16:10 시가 63,063.3**을 사용했다. 그 시각까지 완료된 봉으로 현재 숏 지지를 다시 확인했다. 국소 반응 고점 63,068 아래인지, 실제 가격에서 수량 여력이 있는지, 고정 목표까지 비용 후 공간이 양수인지 재심사했다.

| 항목 | 16:09 판단 견적 | 16:10 시가 재심사 |
| --- | ---: | ---: |
| 원래 가격 | 종가 63,067.4 | 시가 63,063.3 |
| 비용 반영 숏 진입 가격 | 63,051.6 | 63,047.5 |
| 최대 요청 수량 | 0.006 BTC | 0.006 BTC |
| 고정 구조 목표 | 62,966.6 | 62,966.6 |
| 목표까지 전량 가정 왕복 순여유 | +0.226149 | +0.201555 USDC |

재심사를 통과한 뒤에만 장부를 만들었다. 과거 계좌의 이익을 이식하지 않고 무포지션·시험 자금 1,000 USDC에서 시작했다. 실제 체결가는 기존 스프레드·슬리피지·틱 반올림 가정이며 실제 거래소 체결을 뜻하지 않는다.

## 실제 시간순 판단표

시각은 UTC다. 목표 62,966.6은 확인된 구조 저점이며, 거래량 매물대나 본절 가격이 아니다. 주된 기준 63,945.6과 국소 반응 63,068도 별도 역할을 유지했다.

| 시점 | 판단·행동 | 보유 상태와 남은 판단 |
| --- | --- | --- |
| 8/16 16:09 | 숏 후보 선정 | 실제 체결 전 무포지션 |
| 16:10 | 이후 시가 재심사 통과, 조건부 숏 체결 | 0.006 BTC, 평단 63,047.5, 진입 수수료 0.094571 USDC |
| 16:12 | 두 번째 반응의 형성·확인이 첫 진입 판단 이전이므로 추가 불가 | 0.006 유지. 가격 역행만으로 추가하지 않음 |
| 17:00 이후 | 현재 주된 방향 지지가 불확실 | 추가 승인 없음. 기존 목표 축소와 계좌 한도 대응은 계속 확인 |
| 20:44 | 완료 분봉의 저가가 고정 목표 62,966.6에 도달·통과 | 현재 총수량 0.006의 절반 0.003 축소 의도 |
| 20:45 | 이후 시가에 비용을 반영한 62,998.5로 축소 가정 체결 | 잔량 0.003, 평단 63,047.5 유지 |
| 8/17 00:00 | 관찰 종료, 강제 청산 없음 | 잔량 0.003. 이후 종료 판단은 아직 남음 |

목표 도달 가격에 지정가가 체결됐다고 가정하지 않았다. 도달 확인 뒤 실제 다음 시가는 이미 목표 위였으므로 비용 반영 청산 가격도 62,998.5다. **목표 확인과 실제 가정 체결의 가격 차이**를 장부에 반영했다.

## 종료 시 계좌

기본 가정의 종료 종가는 62,820이다.

| 항목 | 값 |
| --- | ---: |
| 남은 숏 수량 | 0.003 BTC |
| 평단 | 63,047.5 |
| 누적 실현총손익 | +0.147000 USDC |
| 누적 지급 비용 | 0.141820 USDC |
| 잔량 미실현손익 | +0.682500 USDC |
| 평가 순손익 | **+0.687680 USDC** |
| 잔량을 가상 청산할 경우 순손익 | +0.593153 USDC |
| 여력 대용치 | 906.457680 USDC |
| 계좌 고점 대비 최대 종가 DD | 1.557971 USDC |

평가손익은 실현총손익 − 누적 비용 + 잔량 미실현손익이다. 대부분이 잔량의 미실현분이므로 전량 종료된 수익으로 보고하지 않는다. 관찰 종료는 정확히 00:00이며 이후 펀딩을 앞당겨 반영하지 않았다. 이 진입 이후부터 종료까지 포함되는 실제 펀딩 정산은 없었다.

기본 경로에서는 위험 한도 복구·계좌 중단이 발동하지 않았다. 여력은 기존 연구 산식의 대용치이며 거래소 증거금·청산가 검증은 아니다.

| 체결 가능량 0.003 BTC | 0.003 BTC | 0.002 / 0.001 | +0.246715 | +0.215206 |
| 체결 가능량 0 | 진입 취소 | 없음 | 거래 없음 | 거래 없음 |

슬리피지 5bp의 진입 시점 전량 왕복 여유는 **−0.025245 USDC**였다. 뒤에 가격이 유리하게 움직였다는 이유로 비용 조건을 무시하고 진입시키지 않았다.

부분 진입에서는 미체결 요청분 0.003을 취소하고 자동 재시도하지 않는 기존 단일 시도 가정을 유지했다. 이후 실제 보유 0.003의 절반은 0.0015지만 수량 단위 0.001에 맞춰 **0.002를 축소**하고 0.001을 남겼다. 원래 요청 수량 0.006으로 목표 축소량을 계산하지 않았다. 축소 의무의 미체결은 기존 재생기의 잔량·의무 보존 규칙을 사용하며 진입 요청 취소와 혼동하지 않는다.

## 결정한 것과 남은 일

- 이후 시가에서 방향·국소 가격·수량·비용을 다시 확인한 경우에만 조건부 장부를 생성했다.
- 실제 수량을 넣어도 16:12 추가는 오래된 근거 때문에 거절됐다.
- 이후 확인된 모든 숏 재접근 기회에서 추가 후보가 없는지 검토했다. 추가 후보가 생기면 축소 전용 재생으로 결과를 내지 않고 중단하도록 했다.
- 고정 목표 도달 뒤 실제 총량 절반 축소가 적용됐고, 잔량은 강제 청산하지 않았다.
- **주된 방향의 충분성·목표 중요도·약손절·전량 종료 정책은 여전히 미정이다.** 이 양수 평가손익을 전략 채택 근거로 쓰지 않는다.

다음은 새 장부의 남은 0.003 BTC를 초기화하지 않고 **이후 주된 기준 무효화와 종료까지** 이어서 확인하는 것이다. 기본 비용에서의 평가이익이 실제 종료까지 남는지, 진입이 불가능했던 비용 대조를 끝까지 거래 없음으로 유지하는지 함께 검토한다. 이전 62,900 목표 계좌나 누적 손익과 섞지 않는다.

4단계 개발 사례 검토이며 5단계 운영 연결·6단계 별도 자료 평가는 보류한다.
