# 통합 판단 시험 v1 — 합성 주문 흐름 검증

2026-09-19. `CyclingTrialEngine`이 완성 봉 관찰, 사전 등록 구간, 방향 상태, 명시적 수량 한도, 주문 컨트롤러와 실제 체결 장부를 연결한다. 연구 전용이다. 사용자에게 확인된 순환매 원칙과 시험판의 구간·반응 선택을 구분한다. 중요한 구간을 자동으로 올바르게 찾았다는 의미는 아니다.

## 구현과 검증

- 국소 진입 근거 이탈은 주된 방향 반전이나 자동 전량 손절로 바꾸지 않는다.
- 되돌림에서는 추가 물량만이 아니라 실제 총 보유량의 50%를 주문 단위로 올림한다. 6개 보유 시 3개, 5.5개 보유·0.1 단위에서는 2.8개다.
- 추가 주문 중 되돌림이 오면 취소 요청을 먼저 하고, 늦게 온 체결까지 대사한 뒤 실제 총량으로 축소 목표를 정한다.
- 이미 시작한 절반 축소는 부분 체결·취소 뒤 원래 목표의 미체결 잔량만 재주문한다. 잔량의 절반을 다시 계산하지 않는다.
- 약손절 시험 조건은 국소 근거 실패와 명시적 한도 초과가 함께 발생한 경우다. 한도를 회복하는 최소 실행 가능 부분 수량을 계산하며, 최소 주문 금액도 반영한다. 부분 축소로 해결할 수 없으면 미해결로 기록한다.
- 시험 추세 전환은 기존 주문 취소·대사 → 잔량 정리 → 새로운 반대 방향 진입 반응 대기 순서다.
- 체결 정보가 불명확하면 전환 종료 주문과 취소된 축소 주문의 재주문도 보류한다. 최소 주문 미달도 별도로 기록한다.
- 판단 봉 종가에 즉시 체결됐다고 가정하지 않는다. 체결은 판단 이후 시각의 별도 입력이다.
- 설정의 해시를 고정해, 비율·판정 설정만 바꾸고 구현이 이를 조용히 무시하는 것을 거부한다. 규칙 변경은 새 구현 버전 작업이다.

재현:

```sh
PYTHONDONTWRITEBYTECODE=1 .venv/bin/python scripts/verify_cycling_trial_engine.py
PYTHONDONTWRITEBYTECODE=1 .venv/bin/python -m unittest discover -s tests -p 'test_recovery_cycling*.py'
PYTHONDONTWRITEBYTECODE=1 .venv/bin/python -m unittest discover -s tests -p 'test_recovery_directional_cycling.py'
```

합성 통합 15개(명세 8장면과 경계 사례), 관련 cycling 66개 및 장부 9개 통과. 합성 통합 검사는 66개 안에 포함된다. `reports/validation/cycling_trial_engine_v1_20260919/scenarios.json`에 입력 봉·한도·판단·주문·체결 가격/비용·장부 사건과 결과를 기록한다. 테스트의 취소 확인은 시험 코드에 명시된다. 이 기록은 거래소 원본 사건 로그가 아니다.

확대 검사에서는 기본 가상환경에 pandas가 없어 두 모듈을 불러오지 못했다(324개 중 322개 통과, 2개 로딩 오류). 해당 두 모듈은 pandas가 있는 번들 Python에서 별도로 4개·14개 모두 통과했다. 번들 환경에서 전체 검색은 pytest 미설치 때문에 controller 모듈 로딩이 실패했다. 따라서 단일 환경에서 전체 애플리케이션 검사까지 완료했다고 보고하지 않는다.

## 남은 범위와 다음 단계

합성 주문 흐름 단계는 통과했다. 다음은 기존 실제 자료에 사전 시점의 구간·역할·한도를 명시하고, 같은 엔진으로 판단 이유와 보류 이유를 시간순 재생하는 것이다. 그 결과를 보고 규칙을 바꾸면 개발 자료 검토로 기록하며 새 자료 성과 검증으로 부르지 않는다.

통합 엔진 자체의 완전한 저장·재시작 복구는 아직 구현하지 않았다. 기존 주문 컨트롤러 체크포인트의 trim 주문 복원만 검사했으며, 그것만으로 구간 관찰 이력·대기 중 축소 반응·증가 주기를 복원할 수 없다. 새로운 엔진의 실행은 연속된 오프라인 재생에 한정한다. 펀딩은 외부 장부 사건으로 입력해야 하며 자동 수집되지 않는다. 합성 사례의 무마찰 비용은 주문 순서 검사 목적이다. 실제 수익성·실제 체결 가능성·자동 매물대 선정은 이번 결과에 포함하지 않는다.
