# 중복 접촉과 보유 상태 비교 연결

후보별 접촉 19개를 동일 가격·동일 봉 기준으로 17개 묶음으로 정리했다. 실제 발생 시각은 14개 분봉이다. 두 묶음은 각각 서로 다른 시간봉 후보 두 개를 참조한다. 나머지 근접 가격은 임의로 병합하지 않았으므로 17개를 독립적인 근거 수로 해석하지 않는다.

결과: `reports/validation/grouped_contact_positions_20260919/comparison.md`와 `comparison.json`.

각 묶음에서 롱 0.2 BTC·평단 63,050 또는 숏 0.2 BTC·평단 62,800이라는 독립적인 보유 가정에 유지·0.1 추가·총수량 절반 축소를 붙여 총 102개 결과를 계산했다. 실제 거래 이력이나 계좌의 연속 손익이 아니며, 거래 방향과 행동을 선택하지 않았다. 증거금은 2배 단순 산식, 수수료 편도 4bp, 반스프레드 0.5bp, 슬리피지 2bp, 펀딩 0 가정이다.

## 중복 사례

8월 15일 21:26 UTC, 63,038.5 구조 가격에 대한 15분·1시간 후보가 같은 봉을 참조했다. 종가는 63,051.4로 구조 가격 위였다. 이를 저항 반응 두 번으로 세거나 숏 추가량을 두 배로 만들지 않는다.

이 가격에서 예시 롱의 유지 손익은 −4.76 USDC다. 0.1 추가 시 −8.87, 절반 축소 시 −8.87로 비용 때문에 즉시 손익은 모두 감소한다. 하지만 증거금 여력 변화는 추가 −3,156.67, 축소 +3,148.47로 크게 다르다. 손익이 거의 같다고 노출이 같은 행동은 아니다. 숏 보유 가정은 별도로 계산했다.

## 구현과 검증

독립 묶음 함수는 원본 후보 ID·시간봉·확인 시점을 보존한다. 동일 기록의 재전달은 결과를 늘리지 않는다. 같은 후보의 충돌 기록, 같은 가격·같은 봉의 서로 다른 종가, 후보 확인 이전 접촉은 거부한다. 고점·저점 역할이 동시에 있으면 하나를 임의로 버리지 않는다.

신규 테스트 5개 통과: 정확한 중복 통합·재전달 멱등성, 근접 가격/다른 시각 분리, 미래 제외·원본 불변, 역할 보존, 충돌·조기 접촉 거부. 실제 자료에서도 입력 전체를 두 번 전달한 결과와 각 시점까지의 묶음 결과를 대조했다. 102개 비교의 실현·미실현·비용 합계와 동일 가격에서 거래 비용에 따른 손익 변화를 확인했다. 기존 계산기는 변경하지 않았다.

주문 생성 0건이다. 연구용 비교의 중복 제거를 구현한 것이며 실주문 엔진의 중복 발주 방지를 검증한 것은 아니다. 시장 방향·추가와 축소 자리 판단·실제 잔량 및 여력은 미확정이다. 다음 판단 단계는 이 14개 시각 중 근거가 충돌하는 사례를 골라, 당시 필요한 근거와 불충분한 근거를 하나의 의사결정 명세로 정리하는 것이다. 새로운 임의 지표나 수량 규칙을 늘리기보다 남은 판단 기준을 모으는 데 초점을 둔다.
