# U3 추가 근거 — 시간상 새로움과 시장 정보의 독립성

**두 추가는 새 고점의 확인·이탈·첫 재접촉이라는 기존 시험 조건을 충족했다. 그러나 서로 독립적인 시장 근거라는 사실까지 입증한 것은 아니다.** 특히 두 번째 고점은 직전 증가 뒤 생겼지만, 중간 축소 전부터 이미 알려진 가격이었다. 현재 규칙은 이를 허용하며 이번 검토에서 바꾸지 않는다.

[근거·원본 분봉·기존 장부 대조](../../reports/validation/addition_evidence_20260920/review.json)를 보존했다. 대상은 [이전 조건부 계좌](FIRST_CANDIDATE_CASE_TRIAL.md)의 두 추가다. 무포지션에서 시작한 새 선정 계좌와 분리하며, 기존 시장 판단·수량·목표·체결을 변경하지 않는다.

## 판단 시점부터의 순서

시각은 UTC다. 체결은 실제 거래소 체결이 아니라 기존 조건부 재생의 결과다.

| 항목 | 첫 추가 | 두 번째 추가 |
| --- | --- | --- |
| 직전 실제 증가를 만든 판단 / 가정 체결 | 8/15 18:14 / 18:15 최초 진입 | 8/15 22:49 / 22:50 첫 추가 |
| 새 고점 형성 | 8/15 21:45, 63,083.5 | 8/16 04:30, 63,068 |
| 좌우 두 봉으로 확인 | 22:15 | 05:00 |
| 확인 후 첫 완전 이탈 봉 | 22:16 | 05:01 |
| 이탈 이후 첫 재접촉까지 관측된 최저가 | 63,021.9 | 62,877.1 |
| 첫 재접촉·고점 아래 마감 | 22:49 | 16:09 |
| 이후 시가의 가정 추가 | 22:50, 0.006 BTC | 16:10, 0.006 BTC |
| 추가 직전 수량 / 평단 | 0.006 / 62,986 | 0.006 / 63,026.05 |
| 추가 이후 수량 / 평단 | 0.012 / 63,026.05 | 0.012 / 63,036.775 |
| 사이에 있었던 축소 | 없음 | 8/16 09:47, 0.012→0.006 |
| 당시 기존 계좌의 1시간 숏 보호 가격 | 63,925.9 | 63,070 |

각 고점의 실제 15분봉 고가와 좌우 두 봉을 원본 분봉에서 대조했다. 확인 이후 종가가 고점을 먼저 넘어버린 경우가 없었고, 이탈 뒤 첫 접촉 시점도 기존 기록과 일치했다. 미래 분봉을 제거해 계산한 접촉 목록도 같았다. 이탈 이후 최저가는 해당 접촉 시점까지 관측된 경로 요약이며 미리 알고 선택한 가격 목표가 아니다.

두 추가 모두 당시 가격이 평단보다 불리했고, 기존 Z01 목표 62,900까지 비용 후 공간과 여력 심사를 통과한 조건부 경로였다. 이 계산이 새 반응의 시장 타당성을 대신하지 않는다. 또한 이전 계좌는 별도의 1시간 구조 시험을 사용했으므로 두 추가를 현재 일반 주된 방향 규칙의 검증 사례로 승격하지 않는다.

## 두 번째 추가의 중요한 경계

고점 63,068은 04:30에 형성되어 05:00에 알려졌다. 이후 09:47 축소를 거쳐 16:09에 처음 재접촉했다. 따라서 다음 두 문장은 다르다.

- 직전 **증가** 이후 새로운 고점인가: 그렇다.
- 직전 **축소** 이후 새로 형성된 고점인가: 아니다.

기존 시험은 실제 체결된 증가를 만든 판단 시각을 기준으로 새로움을 검사한다. 미체결 증가 의도와 단순 축소는 그 기준을 갱신하지 않는다. 두 번째 추가는 당시 규칙대로지만, ‘축소 뒤 완전히 새로운 순환의 근거’라고 설명하면 부정확하다.

축소 뒤 형성된 고점만 허용하면 추가 기회와 위험이 함께 달라질 수 있다. 이 한 경로를 보고 조건을 강화하거나 완화하지 않았다. 어느 기준이 사용자 의도에 맞는지, 같은 움직임에 대한 반복 노출을 줄이는지는 별도 미정 사항이다.

## 16:12 거절 사례와의 대조

16:12에 참조한 63,107.2 고점은 8/15 03:30 형성·04:00 확인으로 오래된 근거다.

| 보유 입력 | 16:09의 의미 | 16:12 심사 |
| --- | --- | --- |
| 이전 계좌 | 보유 0.006에 추가하여 0.012로 증가 | 직전 증가보다 오래된 고점이므로 추가 거절 |
| 새 선정 계좌 | 무포지션에서 최초 진입 후보 | 그 최초 진입 이후 새로 생긴 고점이 아니므로 추가 거절 |

같은 시장 사건이라도 현재 보유와 마지막 증가가 다르면 ‘최초 진입’과 ‘추가’가 달라진다. 두 계좌가 같은 거절을 했다고 독립 시장 표본 두 개로 세지 않는다. 이전 `require_post_growth_landmark=false`에서 발생한 오래된 고점 추가 실패도 기존 보고서에 계속 보존한다.

## U3 시험 계약

| 판단 | 발동·필요 정보 | 금지 조건 | 정보 부족 시 대응 |
| --- | --- | --- | --- |
| 시간상 새 근거 | 고점 형성·확인이 마지막 실제 증가를 만든 판단보다 뒤이고 현재 시점까지 가용 | 늦게 재접촉했다는 이유만으로 오래된 고점을 새 근거로 변경 | 추가 보류. 실제 증가·주문 대사 기록이 없으면 임의 시각으로 대체하지 않음 |
| 별도 반응 사건 | 확인 이후 이탈하고 소모되지 않은 첫 재접촉에서 해당 방향 마감 | 같은 반응 재사용, 같은 봉 여러 가격을 여러 추가로 계산 | 사건 단위로 보류·묶어서 기록 |
| 방향·자리 적합성 | 현재 적용 중인 방향 규칙과 국소 근거·목표 공간을 별도 확인 | 가격 역행만으로 승인, 오래된 계좌의 방향 규칙을 현재 일반 규칙으로 간주 | 미확정 사유와 신규 노출 보류를 기록 |
| 추가 수량 | 실제 총량·평단·실현손익·비용·남은 여력·예약을 넣어 상한 심사 | 조건부 요청량 0.006을 항상 추가하는 고정 원칙으로 승격 | 수량 미승인. 기존 위험 처리는 별도 검토 |
| 이후 시가 재심사 | 판단보다 뒤인 시가에서 방향·국소 가격·경제성·여력을 확인 | 판단 종가의 승인이나 견적을 실제 체결로 취급 | 취소·부분 체결을 실제 증가와 구분해 이력 갱신 |

시간상 새로움은 사건 중복을 줄이는 조건이다. 같은 주된 움직임을 공유하는지, 새 정보가 추가 노출을 정당화할 정도인지, 증가·축소 중 어느 사건을 새 순환의 기준으로 삼을지는 아직 해결되지 않았다. 독립성의 충분조건을 얻었다고 보고하지 않는다.

## 결정과 다음 순서

기존 추가·거절 기록은 선언된 시험 조건과 일치했다. **판단 코드를 수정하지 않고 현 조건을 유지**한다. 새로움의 기준이 마지막 증가라는 점과 축소 이전 근거를 허용한다는 한계를 명시한다. U1 방향·U2 중요도·U3 독립성의 일반 검증은 미완료다.

다음은 예정된 **U4 축소 발동** 검토다. 같은 이전 계좌에서 추가 뒤 Z01 상단 접촉을 어떤 완료 봉에서 확인했고, 다음 시가까지 어떤 가격 차이가 생겼으며, 축소량이 당시 총량의 최소 절반이었는지 연결한다. 목표 접촉과 반응 확인을 구분하고 ‘최소 절반’ 원칙을 발동 시점의 정당성으로 확대하지 않는다. 현재 새 계좌의 최초 진입 후 축소는 별도 시험 확장으로 유지한다.

## 재현·검증 범위

```sh
.venv/bin/python scripts/review_addition_evidence.py
```

기존 결과와 입력 해시, 원본 고가·피벗 확인, 이탈·첫 접촉, 미래 자료 제외, 마지막 실제 증가와 중간 축소, 두 계좌의 오래된 근거 거절을 대조했다. 기존 장부의 수량·평단·여력 결과를 인용했으며 이번에 전체 계좌를 새로 재생하거나 수익성을 다시 평가한 것은 아니다. 실제 주문은 없고 5·6단계는 보류다.
