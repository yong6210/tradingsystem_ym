# 전체 연구·개발 상세 계획 v2

작성: 2026-09-17. 상태: 상세 설계 초안. E001/E003 탐색 완료. 최종 전략 미채택, 후속 비교 설계 중.

## 1. 목표와 완료의 정의

목표는 BTCUSDC 무기한에서 검증된 전략을 선택적으로 운용하고, 우위가 불명확하거나 실행 조건이 나빠지면 노출을 줄이는 시스템이다. 모든 장에서 수익을 보장한다는 의미가 아니다. 현금 대기 역시 정상 출력이다. 최소 5개 후보를 명세화하되, 숫자를 채우기 위해 탈락 전략을 최종 모델에 포함하지 않는다. 최종 채택 전략 수는 0개일 수도 있다.

완료는 다음 다섯 조건을 구분한다: (1) 명세 확정 (2) 구현 검증 (3) 회고적 경제성 검증 (4) 미관측 전진 모의 검증 (5) 사용자 운용 기준과 실제 거래 조건 충족. 앞 조건 통과를 뒷 조건 통과로 대체하지 않는다. 이번 작업의 산출물은 상세 계획이며 완성된 매매 시스템이 아니다.

## 2. 확정·가정·미정

| 결정 | 상태 | 처리 |
|---|---|---|
| BTC 내부 분할 매수·부분 매도·재진입 | 후보 방식 중 하나 | 최신 사용자 지시에 따라 최종 모델의 필수 조건에서 제외 |
| BTCUSDC 무기한 | 사용자 확정 | BTCUSDT 연구 결과와 종목 구분 |
| 메이커 수수료 0 | 사용자 가정 | 기본 연구 시나리오에 사용; 시장가·펀딩·체결 영향 별도 |
| 거래소·계정 모드·계약 규격 | Binance 확정, 공개 필터 확인; 계정 모드 미확인 | OPERATING_PROFILE.md 적용 |
| 자금·허용 낙폭·일간 손실 예산 | 1,000달러 확정; 위험 설계 위임 | 8% 중단 등 연구 초안, 최적성 미검증 |
| 자동매매 또는 판단 보조 | 완전 자동매매 확정 | 운영 전환 전 검증 필수 |
| 모든 장에서 반드시 수익 | 채택하지 않음 | 장세별 손실·대기·회복 시간을 보고 |

미정은 0이나 임의 기본값으로 저장하지 않는다. 연구용 초기 자본과 위험 예산은 experiment_assumption으로 표시하며 사용자 승인값과 별도 필드로 보관한다. 운영 값이 null이면 운영 진입을 거부한다. 연구는 계속 가능하다.

## 3. 기존 시스템에 대한 경계

기존 여섯 전략군은 지표 기반 후보이지 각 스타일의 최상 모델이라는 증거가 없다. 운영 기본 전략, 과거 v6, 다중 전략 연구 엔진은 서로 다른 대상이다. 이름이 비슷하다는 이유로 성과를 합치지 않는다. 영상 속 재량 판단과 현재 순환매 코드가 동등하다는 주장은 하지 않는다.

E001에서 현재 평균회귀 신호의 60분 우위는 근거 부족이었다. 이 결과를 출구 변경이나 추가 매수로 덮지 않는다. 다른 보유기간 또는 다른 신호를 연구하려면 새로운 질문으로 등록한다. E001 문서·코드·결과 해시는 보존한다.

## 4. 작업 순서와 단계별 종료 조건

| 단계 | 작업 및 산출물 | 통과 조건 | 실패/불충분 시 |
|---|---|---|---|
| P0 | 본 계획·요구사항 표·결정 목록 | 모듈과 검증 항목에 연결, 미정 표시 | 누락 명세 보완 |
| P1 | E001 대조군/계산 감사 보고서 | 독립 통계 재현·매칭 제외 편향·시간 의존성 범위 명시 | 기존 결론 신뢰도 하향; 숫자 개선 목적 수정 금지 |
| P2 | 후보별 진입 가설 등록 | STRATEGY_SPECS의 필수 값·주 지표·최소 효과·표본 목표 확정 | 미등록 후보 실행 금지 |
| P3 | 단위 가격 반응 진단 | 경제적 이유와 사전 기준에 부합; 불확실성 공개 | 지지/기각/불충분 기록 |
| P4 | 체결·원장 기준 엔진 | 손계산·재생·오류·시간 경계 검증 | 전략 수익 순위 계산 보류 |
| P5 | 고정 진입의 청산 비교 | 동일 입력, 비용 후 위험/수익 비교, 모든 시도 공개 | 복잡한 청산 추가 중단 |
| P6 | 분할·순환 관리 비교 | 동일 허용 위험·노출 정규화, 추가 위험 보상 확인 | 단순 관리 유지 |
| P7 | 선택·결합 비교 | 같은 위험의 최선 단독/고정 배분/대기 대비 추가 가치 | 조합 기각 가능 |
| P8 | BTCUSDC 실행 자료·전진 모의 | 동결 모델, 실측 실행 오차, 사용자 한도 만족 | 원인 기록 후 새 버전; 관측 구간 재사용 표시 |
| P9 | 운영 전환 설계 검토 | 운영값 확정·복구 훈련·중단 조건 충족 | 연구 상태 유지 |

P4는 P2/P3와 독립적으로 개발 가능하지만, 진입 정보가 약한 전략을 매매 결과가 좋아 보일 때까지 반복 조정하지 않는다. 추세 전략의 비대칭 수익 가설은 평균회귀 E001의 60분 기준을 그대로 강제하지 않고 사전 정의한 별도 기준을 쓴다.

## 5. 최소 비교 기준

모든 매매 실험에 현금 대기, 같은 입력의 단순 청산, 적격 단독 전략, 고정 배분을 관련 대조로 둔다. 매수 후 보유는 방향 노출 설명용이며 선물 전략과 위험·비용이 같다고 주장하지 않는다. 대조군이 적용되지 않는 진입 진단에 계좌 수익률을 억지로 추가하지 않는다.

총수익·최대 낙폭·회복 시간·최악 일/주·기대손실·노출·회전율·비용·펀딩·체결률·미실현 손익을 함께 본다. 높은 승률만으로 합격시키지 않는다. 비교용 같은 레버리지와 같은 실제 위험은 다르므로 별도 보고한다.

## 6. 변경 및 의사결정 절차

요청 → 결정 ID → 명세 변경 → 영향 받는 요구사항/검사 확인 → 구현 → 독립 검산 → 결과 등록 순서다. 성과를 본 뒤 수치·기간·지표·후보를 바꾸면 새 실험 ID를 발급하고 이전 실패를 남긴다. 과거 문서를 최신 설명으로 덮어쓰지 않는다. 실험에 등록된 소스를 바꾸면 새 실행 디렉터리와 새로운 해시를 사용한다.

계획상 상태는 planned, specified, implemented, verified로 구분한다. 연구 결론은 supported, rejected, insufficient로 별도 관리한다. verified가 supported를 의미하지 않는다.

## 7. 바로 다음 작업 패키지

P1 범위: 기존 E001 결과를 고정한 채 (a) 별도 구현의 블록 구간 재현 (b) 매칭 성공/실패 신호의 연도·방향·변동성 분포 (c) 대조군 재사용 및 신호 중첩 의존성 (d) 자료/시장 차이의 해석 한계를 보고한다. 새로운 전략 파라미터 탐색은 포함하지 않는다. 분석 전에 P1 명세를 별도 등록하며, 보조 분석은 E001의 주 판정을 소급 변경하지 않는다.

그 다음 P2에서 후보 한 개씩 규칙과 경제적 가설을 확정한다. 신규 데이터 확보는 거래소 확정 뒤 BTCUSDC 체결·호가·펀딩·마크 가격부터 시작한다. 현재 1분봉만으로 호가 대기열 기반 스캘핑을 검증 완료로 표시하지 않는다.

## 후보 구성 재검토

[후보 재검토와 확장 연구 지도](CANDIDATE_REVIEW.md): 기존 여섯 후보의 중복을 구분하고 S07~S13을 연구 목록으로 추가했다. 첫 후속 명세 대상은 S01/S02/S05/S07/S08이며 S04는 기존 대조로 유지한다. 추가 후보의 수익성은 미검증이고 현재 실행 등록은 하지 않았다.

## 추세 비교와 소액 운용 재설계

[상세 재설계](TREND_AND_CAPITAL_REDESIGN.md): 비신호 매칭을 동일 시간 정책 비교로 대체하는 새 실험과 최소 필요 자산 계산을 분리한다. 후속 자금은 1,000 USDC로 변경하고 0.5% 위험 비율은 유지한다. 설계 상태이며 미실행이다.

최신 운용 자금은 사용자 요청에 따라 1,000 USDC다. 문서의 E003/100달러 결과는 과거 실험의 조건이며 수정하지 않는다.

## 최신 연구 방향: 매매 방식 제한 해제

사용자 요청으로 순환매를 필수 구성에서 제외했다. [방식에 제한을 두지 않는 탐색 계획](STRATEGY_DISCOVERY.md)을 따른다. 1,000 USDC·Binance BTCUSDC 실행 조건 아래 단독/복합 전략을 같은 기준으로 검토하며, 수익성이 검증된 방식은 아직 없다.
