# 새 구조 후보와 기존 근거의 관계

기존 24시간 관찰에 새로 확인되는 고점·저점 후보의 출처 이력을 연결했다. 결과는 `reports/validation/structure_lineage_20260919/lineage.md`와 `lineage.json`이다.

시험 15분·1시간·4시간, 좌우 두 봉 추출법에서 새 후보 36개를 기록했다. 이 중 과거 또는 동시에 확인된 후보와 정확히 같은 가격인 기록은 10개, 확인 자료 구간이 겹치는 기록은 33개, 기존 세 범위 중 하나의 내부인 기록은 10개였다. 항목은 중복된다. 이 수치는 36개의 독립적인 진입 근거나 거래 기회를 뜻하지 않는다.

각 후보에 원본 봉 시각, 실제 확인 시각, 확인 자료 범위, 같은 가격의 기존 후보 ID, 자료가 겹치는 후보 ID, 기존 동결 범위와의 위치 관계를 남겼다. 등록 후에 생긴 구간을 과거 후보의 근거로 소급 연결하지 않는다. 동시 확인 후보끼리의 관계는 입력 순서에 영향받지 않는다.

자료 중첩은 동일 반응임을 확정하는 규칙이 아니다. 서로 다른 시간봉이 같은 가격 움직임을 포함할 수 있다는 점검 정보다. 같은 가격 판정도 정확한 값 일치만 다룬다. 근접 가격을 합치는 폭과 후보의 독립성은 아직 미정이다. 구간 밖의 가격이라고 추가를 승인하지 않으며 기존 구간이나 무효화 이력을 덮어쓰지도 않는다.

## 확인한 범위

신규 테스트 4개 통과: 미래 후보 제외·과거 기록 불변, 동시 후보 순서 독립, 미래 구간 소급 사용 방지·구간 밖 후보 자동 승인 방지, 중복 ID·잘못된 시각 거부. 실제 새 후보의 각 확인 시점마다 이후 봉을 제외하고 피벗을 다시 계산한 결과도 전체 기록의 해당 시점 부분과 일치했다. 입력·코드 해시를 기록했다. 주문 생성 0건.

이 단계로 새 후보의 자동 추출과 출처 연결은 구현했다. 아직 남은 것은 후보가 실제로 유효한 추가 자리인지 판단하는 기준이다. 다음은 후보 확인 시점의 가격 위치와 이후 최초 재접근을 연결해, 구조 확인 전에 일어난 반응을 새 후보의 거래 근거로 잘못 쓰는 경우를 구별하는 것이다. 주된 방향·실제 여력 판단과 약손절 기준은 여전히 별도 미확정 항목이다.
