# 시장 판단 우선 — 현재 작업 계약

사용자 요청에 따라 원칙 분리 → 실제 사례 → 판단 명세 → 서로 다른 시장 → 단일 엔진 → 동결 후 별도 평가 순서로 진행한다. 현재 판단과 검증 범위는 [통합 명세](MARKET_DECISION_CONSOLIDATED_2026_09_20.md), 바로 다음 작업은 [현재 우선순위](CURRENT_PRIORITIES.md)에 둔다. 기존 연구 문서의 ‘최신·다음’보다 이 계약이 우선한다.

## 사용자 확정 원칙

| ID | 확정 내용 |
| --- | --- |
| P1 | 주된 방향이 롱이면 롱, 숏이면 숏으로 순환한다. |
| P2 | 반대 방향 진입은 주된 추세가 전환됐을 때만 검토한다. |
| P3 | 4시간봉 하나로 방향을 강제하지 않는다. |
| P4 | 추가 후 되돌림에서는 축소 직전 현재 총수량의 최소 절반을 덜어낸다. 추가분의 절반이 아니다. |
| P5 | 평단·남은 여력·누적 실현손익을 함께 관리한다. |
| P6 | BTC 2~3천 달러 역행을 자동 손절선이나 무조건 보유 조건으로 삼지 않는다. |

## 미정 사항

U1 주된 방향 유지·불확실·전환, U2 중요 매물대·목표 선정, U3 최초 진입·추가 조건과 수량, U4 축소 발동, U5 약손절·전량 종료는 아직 확정되지 않았다. 각 규칙의 발동·금지·필요 정보·정보 부족 대응은 통합 명세에서 분리한다.

정보 부족 시 신규 노출을 승인하지 않는 것은 연구 정책이다. 이를 자동 보유 또는 전량 종료 명령으로 바꾸지 않는다. 매물대 구간·구조 고저점·포지션 본절의 역할을 합치지 않는다. 숫자·정책의 시험 지위와 계좌 입력의 출처를 표시한다. 특히 P4가 최초 진입만 한 경우나 약손절의 절반 비율까지 확정한 것으로 해석하지 않는다.

## 단계별 완료 기준과 현황

| 단계 | 완료 기준 | 현재 |
| --- | --- | --- |
| 1 | 확정 원칙과 시험 규칙이 섞이지 않음 | 분리 완료 |
| 2 | 진입·추가·축소 이유와 설명 불가능한 부분을 실제 순서로 기록 | 조건부 사례 기록 완료. 서로 다른 초기 보유의 계좌를 합치지 않음 |
| 3 | 동일 정보·상태에서 일관된 행동 결정 | 통합 시험 초안. 정책 선택과 일반 조건은 미완료 |
| 4 | 서로 다른 시장의 판단·대기·충돌을 설명하고 수정 시 과거 사례 재검토 | 미완료. 불확실 수 자체가 실패 기준은 아니며 행동 범위와 근거 충분성이 남음 |
| 5 | 채택 명세·실제 판단 기록·엔진 결과 일치 | 보류. 판단 일치·주문 정합성·계좌 계산을 구분 |
| 6 | 동결 후 미사용 자료에서 비용·체결 제약 포함 평가 | 미착수. 규칙 수정에 쓴 자료는 개발 자료로 재분류 |

주문·수량·장부 코드는 재사용하되 시장 판단 검토 전 기능 확장을 진행하지 않는다. 보고는 테스트 수 대신 결정한 내용·미정 사항·다음 판단을 중심으로 한다. 별도 평가 통과와 실거래 준비 완료는 구분한다.

[통합 전 계약과 경과 원문](MARKET_JUDGMENT_SEQUENCE_HISTORY_BEFORE_2026_09_20.md)은 보존 이력이다.
