## 개발 작업 카드 규칙

각 작업은 요구사항 ID, 입력/출력, 수정 허용 경로, 기존 결과 영향, 테스트 시나리오, 독립 검산, 완료 증거, 남은 한계를 기록한다. 명세만 만든 작업은 specified로 종료한다. 구현 없는 verified 표시, 수익 근거 없는 supported 표시를 금지한다.
