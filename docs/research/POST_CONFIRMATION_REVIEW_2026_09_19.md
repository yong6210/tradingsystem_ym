# 구조를 확인한 뒤 실제로 다시 접근했는가

후보 확인 시점의 가격과 이후 최초 접촉을 연결했다. 결과는 `reports/validation/post_confirmation_cases_20260919/cases.md`와 `cases.json`이다. 기존 후보 36개 중 19개에서 확인 이후 별도 접촉이 기록됐고, 17개는 고정 관찰 종료까지 별도 접촉이 없었다. 후보별 관찰 시간이 다르므로 미접촉을 실패로 해석하지 않는다.

19개는 후보별 기록 수이며 독립적인 반응 19회를 뜻하지 않는다. 접촉 종가는 후보 역할 기준 유리한 쪽 7개, 불리한 쪽 11개, 기준 가격과 같은 경우 1개였다. 저점 후보의 위 마감, 고점 후보의 아래 마감을 유리한 쪽이라고 이름 붙인 관찰이며 매매 성공률이나 계좌 수익률이 아니다.

## 실제 차이

62,830 저점은 15분 관찰에서 09:45 확인됐다. 그때 가격은 이미 62,932였다. 이후 관찰 종료까지 62,830 재접촉이 없었다. 앞서 저점을 만들며 반등한 구간을 09:45 이후 새 추가 근거로 사용하면 과거 정보를 소급해 거래하는 오류가 된다. 같은 가격이 1시간 관찰에서 12:00에 확인됐어도 별도 재접촉이 생긴 것은 아니다.

62,960.4 고점 후보는 10:30 확인됐고, 10:33 첫 별도 접촉 후 종가가 62,944.2로 아래에 남았다. 이 경우 저항 역할을 검토할 관찰은 생겼다. 하지만 당시 주된 방향·보유량 없이 숏 추가나 롱 축소를 확정하지 않는다.

63,038.5는 15분·1시간 후보가 모두 21:26 같은 봉에 접촉했다. 종가는 63,051.4로 고점 가격 위였다. 동일 가격·동일 봉의 사건을 저항 근거 두 개로 계산하지 않아야 한다.

## 구현과 검증

확인 봉까지의 접촉은 이후 재접근으로 세지 않는다. 확인 봉에서 이어지는 접촉과 한 봉 이상 떨어졌다 다시 닿은 접촉을 구분했다. 갭으로 기준 가격을 건너뛴 것은 실제 접촉으로 기록하지 않는다. 정확한 구조 가격을 진단 기준점으로 사용했으며 매물대 폭이나 주문 가격을 임의로 만들지 않았다.

신규 검사 6개 통과: 확인 전·확인 봉 접촉 제외와 연속 접촉 구분, 미래 자료 제외, 갭 구분, 고점의 역할 대칭, 누락 자료 거부, 미접촉 관찰 처리. 실제 각 최초 사건 시점 이후의 자료를 잘라도 같은 사건이 기록되는지 확인했다. 입력·코드 해시를 저장했고 기존 결과를 변경하지 않았다. 주문 생성 0건.

다음은 후보별 사건을 동일 가격·동일 봉 기준으로 묶어 중복을 드러내고, 그 시점의 보유 상태 비교와 연결하는 것이다. 단순히 접촉했다는 이유로 추가하거나 고정 손절을 도입하지 않는다.
