# Research Promotion Operating Loop Upgrade Plan

최종 갱신: 2026-03-23
상태: 전체 완료

## 1. 작업명
`research -> tested -> promoted 운영 루프 자동화`

## 2. 배경
- 현재 alpha research backlog, promotion governance, review/remediation/reopen language는 존재한다.
- 하지만 `research -> tested -> promoted`가 실제 운영 루프로 이어지는 연결은 아직 약하다.
- 다음 핵심 갭은 research 후보가 어떻게 test/shadow/probation/live로 흐르는지 실제 operating loop를 만드는 것이다.

## 3. 목표
1. research operating loop contract를 정의한다.
2. research candidate, shadow test, probation promotion을 하나의 loop language로 연결한다.
3. validation / dashboard / operator checklist가 같은 loop state를 읽게 만든다.
