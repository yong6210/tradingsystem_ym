# 프로젝트 점검 및 수정 기록 — 2026-09-08

현재 체크아웃의 구조와 실행·검증 경로를 조사하고, 재현 가능한 공통 오류를 수정했다. 표본 원본과 운영 DB, 실행 중인 서비스, 실거래 설정은 변경하지 않았다. 이 기록은 코드 점검 결과이며 전략 수익성이나 실거래 승인을 뜻하지 않는다.

## 수정한 동작

1. **캔들 확정 여부**: REST 응답을 항상 확정 봉으로 간주하던 처리를 종료 시각 기준으로 바꿨다. 진행 중인 봉은 미확정 상태로 저장된다.
2. **캔들 품질 검사**: NaN·무한대·비양수 가격을 차단한다. REST 파서에서도 OHLC 범위, 음수 거래량, 뒤집힌 시작·종료 시각을 거부한다.
3. **DB 갱신 일관성**: upsert 뒤 SQLAlchemy 세션에 이미 로드된 캔들도 최신 값을 반환한다. 확정 봉은 늦게 도착한 미확정 봉으로 덮어쓰지 않는다. SQLite/PostgreSQL 모두 충돌 갱신 조건을 적용했다.
4. **승인 캐시 유효기간**: 메모리 캐시의 120초 재사용 시간이 설정된 전체 TTL과 디스크 캐시의 남은 수명을 넘지 않도록 했다. 비정상 TTL은 기본값으로 처리하고 손상된 UTF-8 캐시는 캐시 미스로 처리한다.
5. **v6 호가 감사**: 잘못된 행 형태, 시각·방향, 비정상 숫자, 음수 비용·지연, 비양수 호가·깊이, 매수 호가가 매도 호가를 초과하는 표본을 실패로 표시한다. 해당 행은 유효 표본 수에서 제외한다. 기존 파일은 수정하지 않는다.
6. **v6 관측 JSON 저장**: 공통 원자적 쓰기를 사용해, 독자가 파일 교체 도중 잘린 JSON을 읽을 가능성을 줄였다.
7. **몬테카를로 계산**: 거래 순서 섞기와 임의 잡음 추가를 기존 `ZoneOutcome` R 환산값의 복원추출로 교체했다. 시드를 지정하면 재현 가능하고, 0 이하·비정수 시뮬레이션 횟수는 명시적으로 거부한다. 기존 환산값은 목표가 도달 여부를 이용하므로 거래소 체결·비용 기반 순손익과는 구별해야 한다.
8. **검증 방법 표기**: 기존 `walk_forward()`는 실제 학습/검증 분할이 없는 레거시 성과 요약이다. 반환값에 `method=empirical_outcome_summary`, `out_of_sample_validated=false`를 명시했다. 몬테카를로는 `method=iid_bootstrap_mean_ev`를 표시한다. 실제 역사 워크포워드 경로와 혼동하지 않도록 했다.
9. **테스트 이식성**: 개인 `.env`, 하드코딩한 작업 경로, gitignore된 생성 보고서 의존성을 명시적 테스트 설정·정적 fixture로 제거했다.
10. **시간에 따른 테스트 실패**: 과거 고정 날짜가 최근 조회 기간 밖으로 밀려 실패하던 테스트 3개를 테스트 시계 고정으로 수정했다. 운영 조회 기간은 바꾸지 않았다.
